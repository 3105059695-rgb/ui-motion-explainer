# 我的 UI 动效剪辑 · ui-motion-fusion

**新电脑或新对话直接把这个仓库地址交给 Codex 即可。** 仓库根目录就是 Skill，名称为 `$ui-motion-fusion`。当前版本见 [VERSION](VERSION)。

> 用 https://github.com/3105059695-rgb/ui-motion-explainer 里的 Skill 剪这段口播，沿用库里的审美和 UI。

**收到这句话的 Agent** 获取仓库，在本对话读取根目录的 [SKILL.md](SKILL.md) 和[当前审美](references/aesthetic-preferences.md)，依照[仓库接入步骤](AI-START.md)直接使用。用户只用发仓库地址和本期内容。以后也要通过名称调用时，用仓库自带的安装器登记同一个 Skill。

新窗口从整稿判断起步。选材、原声试剪、对照、带缺口的导出和单镜续修都记在同一份工程。[可运行的初剪与返修例子](references/edit-an-episode.md)

剪每个镜头时，Agent 可按原速播放该来源的原视频、保留工程或明确标注的手法重演，核对本句的动作与结果。使用 HyperFrames 时，已绑素材的镜头可以直接生成原生动效工程。导出后可把本期 MP4、对应动态参考和已认可正文并排回看。入口见 [SKILL.md](SKILL.md)。

**从 GitHub 只下载这一份即可调用。** 解压后安装 `ui-motion-fusion`，新对话输入「用 $ui-motion-fusion 剪这段口播」。32 条正向投稿参考各有独立的素材角色、构图、连续动作和可执行关键帧。普通制作先判断原句，再按用途检索所有条目，采用的每一镜都有取舍理由、观看依据与成片时码。6 条历史试样按反馈做纠错。下载、安装与渲染环境见[跨电脑安装](docs/install.md)。

**先理解口播，再从 `capabilities list/search/inspect` 选择已有能力并直接调用。** 当前默认 UI 仍是用户认可的「十款 Agent」正文外观及当前 A 配色；Fred、阿闰、秋芝与 AIGC 按各自认可范围参与参考，整个效果库继续开放。按口播的意思、上下文与情绪选择材料，让对象完成可看懂的动作，再用蒙版、聚焦、变形与转场接起来。人物身份和 AIGC 画风独立保存。具体偏好见[UI、AE 感、开头与禁忌](references/aesthetic-preferences.md)，流程见[唯一入口](SKILL.md)。

## 整个库怎样参与本期

新片的准备程序遍历来源目录与 UI 能力，在工程中保存每个来源的适用范围、候选段落和出处。32 条正向投稿各有可执行的动作和本期材料位，6 条历史反例用于纠错。镜头卡给出当前原句、所用参考、材料职责和关键帧。不同来源可以共同作用于同一段原声。技术核对以导出的实际可见帧为准。

## 换窗口继续剪

在新对话里给同一个工程目录，运行 `scripts/ui.py direct -- resume --project "本期工程"`。它恢复已保存的镜头，从下一处缺材料或时间的位置继续。全库索引、动作信号和逐帧证据存放在工程及 Skill 中。专门研究原片时才翻阅全文和图集。

## 已有制作能力

- 先把本期真实材料、AIGC 有效动作和结果剪入原声时间线，再精修 UI；缺材需补足或明确改选表达，不能悄悄用标题卡填满。
- Canvas 工程新增实际 `material_shots`：源内入出点、材料内部推近／裁切／返回、同源多时刻比较，与定制 UI 状态变化一起运行。每段可改变表面明暗与配色，源材料保留本色，强调紫按需使用。
- 实际音效文件可按动作与切点混入导出，保留原声时钟与增益；浏览器预览仍只含原口播，导出的 `preview.mp4` 才含事件音效。具体字段与限制见[素材剪辑和声音接口](references/director-plan-contract.md#实际素材剪辑与声音事件)。技术检查与实际观感、听审、用户认可仍分别记录。

## 持续保留的能力与范围

- 方木十款 Agent 已认可正文的颜色、实体质感与连续动作已提炼为[实际制作模块](assets/agent-editorial/README.md)。新连续 UI 工程通过 `new --engine fusion -- --custom-layout --canvas-story` 实际复制并加载代码；本期场景与事件按新口播设计，不内置排行榜。
- 有开头人物原片时保留完整原构图，特效裁剪到实测空白区并扣除人物、手势和字幕保护区；没有开头人物时按内容设计全屏 UI。旧开场源码继续保留为可选实现，旧读书样片不是当前质量基线。
- 完整效果目录独立于关键词前几名，中文标签接通参考检索，跨库调用保留实际源码绑定；阿闰新增参考一起保留。

- 整体 UI、账号身份、AIGC 画风分别处理。`user-ui`、阿刁、方木一起继承当前 Fred Talk UI、AE 感、开头与禁忌；旧“仅中段”、白淡紫档案及父目录工程设置不自动接管。明确的本期要求或指定旧工程续作只覆盖其范围。
- 摄影写实等本期 AIGC 要求独立记录原话与参考；不要求套女孩手绘绑定，不改变 UI，也不自动变成其他视频的新默认。
- 正式预检使用 `direct -- check --plan <计划> --production`。旧计划能做结构诊断，不代表可以生产；正式渲染继续检查当前绑定、稿件覆盖、素材及实际时间线实现。
- 按句意选择实际素材、对象动作与交接；参考配方和原语供实现，不以数量或填表证明效果。实际连续片段对照与技术检查分别记录。
- 既有动效、源码、230条历史参考索引、参考图片、场景例图与认可样片继续按各自范围保留。当前颜色、质感与认可范围以审美偏好为准，不能把几张旧图作为唯一 UI 标准。AIGC 图片作画风参考，本期按稿设计，不固定复用同一女孩或旧场景。

## 装好后直接使用

> 使用 $ui-motion-fusion，根据这份口播与素材，沿用已确认风格完成整片和可编辑工程。

账号工程接续身份与适用经验，整体风格、开头与禁忌继承当前统一要求；明确工程例外需有依据。普通换稿不重复确认基础审美，角色和声音不跨账号混用。

制作链是 **口播稿 → 声音克隆 → 数字人 → 剪辑成品**。本 Skill 主要承担最后一环；上游服务按用户请求、可用工具及授权调用，不伪称所有服务已自动打通。
