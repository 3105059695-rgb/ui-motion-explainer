## 安装后怎么剪

> 使用 $ui-motion-fusion，沿用阿刁风格。根据这份口播和素材自主判断怎么剪，保持口播原样。先做开头和代表性正文给我看，确认风格后完成整条。

其他账号换成对应风格名称即可；没有现成风格时，导演从素材和内容提出本期视觉，在样片中确认。

- **口播原样**：保留内容、顺序和原声，靠画面、转场与声音设计强化开头。前 5 秒要吸引人，正文节奏随内容起伏。
- **连续表达**：让触发、变化与结果接得上；阅读结果时保留轻推镜或局部高亮，克制且清楚，避免图片久停和机械换卡。
- **真实与示意分清**：具体操作用真实界面和有依据的操作；概念、逻辑可以重绘，标注“示意”。素材不足主动补齐并说明来源，新增费用另行确认。
- **先样片、后整片**：先交可播放的开头和代表段；本期风格确认后继续完整 MP4 和可编辑工程。已有明确授权或本次要求跳过样片时按请求执行。

本版同时合入乔木字库：**34 个字体文件**（含同一字体的不同字重，不是 34 种不同字体）、**12 套搭配**、**5 种可选 CSS 花字**、可换文字与拖动时间的交互预览、字体导出器。字体资源用于按语义选型，不自动替换已确认工程的字体。详见[本次升级与字体使用](docs/director-fonts-20261012.md)。
