## 本版修正

- 按本期口播分段检索方法、配方与源码，候选带来源例证和可用状态；Agent 阅读后决定采用、原创或保留人物，并说明理由。
- 正式导出核对稿件覆盖、当前 UI/AIGC 依据、实现文件和实际入口读取的时间线映射。无调用记录或只写一份与工程脱离的计划，不能再通过生产检查。
- 修复软件/参考文档断链与历史状态；恢复230条参考来源URL。已配置本机映射时自动接续原片和历史源码，无映射的公开安装明确区分已打包与未打包资源。
- 当前正文是 **Fred 黑紫质感**：深黑主体、醒目紫色重点、大字级、前后层次和连续状态变化。低对比淡紫、等宽小窗贯穿、逐句换卡不再作默认。
- 三张 UI 校准图、两张人物画风参考、八张场景例图、认可样片和必要源码随包。AIGC 图片只校准画风与方法，每期按口播设计新素材，不固定复用同一女孩、旧场景或首帧。
- 风格合同、版本与实际视觉资源进入检查；过期合同、缺图、被否定基线不能冒充当前风格就绪。
- 核心引擎从包内调用，旧目录不自动覆盖。已有项目、独立账号和本次明确要求仍优先。
- 视频寻帧的公共 HTTP 服务已补 Range 支持，避免素材一直停在首帧；完整样片和浏览器取帧实测见验证记录。
- 一个 `SKILL.md` 入口，内部代码和历史指南按四层维护。历史演示必须明确 `--demo`；统一生产导出检查当前计划与风格绑定，旧版计划也不能采用已否定基线。

## 装好后直接使用

> 使用 $ui-motion-fusion，根据这份口播与素材，沿用已确认风格完成整片和可编辑工程。

已有账号工程沿用其档案；没有覆盖时使用 `user-ui`。普通换稿不重复确认基础审美，角色和声音不跨账号混用。
