# 本用户的 B-roll 语义与镜头偏好

校准版本：2026-10-12 / v1。保存作者当前口播剪辑偏好，接收方可按自己的明确要求覆盖；本期明确要求、工程已确认设置和账号约束优先。方法可以跨题材复用，不能把一次选择变成所有句子的固定模板。

依据是用户两轮逐句标注、50 题中的 49 个已答选择，以及对规律总结的确认和写入 Skill 的明确授权。第 34 题未答；已答情绪题 9/9 选择连续漫画。这里记录的是**文字方案偏好**，未宣称这些方案已有通过的视频样片。完整文字证据见[标注案例](broll-calibration-cases.md)及[自包含问卷数据](evidence/broll-calibration-20261012.json)，不依赖旧聊天、原工程目录或本地问卷服务器。

## 先判句意，再决定载体与动作

按完整安装包中主技能的 references/script-visual-planning.md先读整篇，再结合段落目的、前后句和人物情绪分析。逐段回答：

1. 观众此刻需要理解哪个事实、关系或过程，或者感受到什么？
2. 原句在这里承担介绍、举证、操作、对比、解释、情绪、转折还是收尾？前句已经建立什么，下一句需要什么？
3. 人物的语气、重音、停顿和表情提供了什么依据？无音视频则记“待声音校准”，不把想象的情绪写成实听结论。
4. 应保留人物、切 B-roll，还是让二者配合？先写理由，再指定表现方式。态度、判断、停顿或有感染力的人物表演可以保留人物。
5. 对象由什么初态，经什么触发，产生什么变化和结果？它怎样进入下一句？最后才选特效、贴纸、声音和镜头路线。

语义连续可以通过同一对象、问题、人物或结果建立。不要按字幕行、关键词或固定秒数机械换素材。人物与原声的时间保持连续。

## 漫画要形成连续表演

用户明确要求“一张图多个动作”，再垫放、切换成几秒多图的动漫效果：

- 先把同一角色的动作序列画进一张分镜／动作素材，再拆出动作图用于剪辑；角色、服装、场景、物件和动作方向保持一致。
- 基本过程是起始状态→刺激发生→动作／表情改变→情绪落定。按语义与实际口播选择动作数量、景别、切换和叠帧，不把“3 秒／4 张图”固化成标准。
- 例如庆祝→读消息→僵住→双手放回桌上；攥手→松拳→呼气→肩膀放下。关键动作应接得上。
- 一张静态人物图持续推拉、几张互不连续的表情图轮播，不等于用户所说的漫画表演。
- AIGC 后续替换时保留段落任务与动作逻辑，按实际素材重新对齐；不是仅换成真人外观即算完成。

## 特效、贴纸与声音怎样选

先写它加强哪一个可见事件或意思：下落／撞击可表现负担；放大可进入一个想法；拖拽／变形可表达传递与损失；高亮可定位修改；停顿可承接情绪。删去某个效果也不影响理解、节奏或情绪时，不默认保留它。

这轮没有确定贴纸素材风格、贴纸频率、全片音效密度、具体运动曲线、漫画画风或 3D 写实程度。Q45 只说明简单点击可以靠镜头和原声表达，不推导为全片无音效。代码、3D、漫画与真实 UI 都是手段，不按某一种出现次数评定好坏。

## 记录与验证范围

把语义分析加入现有分镜／工程对照，不要求用户填任务卡或逐镜批准。至少让下一位制作者能知道：原句锚点与上下文、段落目的、人物情绪及依据、人物／B-roll 选择理由、对象与状态变化、素材来源及属性、动作落词和阅读停留、前后衔接。

文本阶段只核对“解释是否对应原句、是否遗漏语义、是否有素材依据”；实际样片阶段才检查动作连续性、漫画表演、界面反馈、可读性和音画落点。样片可先静音看能否传达核心动作与关系，再结合原口播看节奏；静音不能完整说明身份或抽象含义的镜头，不因此机械判失败。

将技术检查、实际观看／试听、用户文字偏好、具体样片审美认可分别记录。新句子的样片可以检验能否迁移，不因复述已标句子的方案就宣称已学会全部风格。不要求每次都重做 50 题。
