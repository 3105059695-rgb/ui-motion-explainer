# 2026.10.12.2：剪辑导演、风格档案与字体选择

本次在原有“我的 UI 动效剪辑”中合并两组升级：导演判断与真实返工经验，以及另一轮加入的乔木字库与花字。调用仍是 `$ui-motion-fusion`，GitHub 仓库地址继续使用 `3105059695-rgb/ui-motion-explainer`。不是新增一个需要单独调用的同类 Skill。

## 导演与风格分开

通用导演负责理解口播、选择素材与表现形式、安排动作和衔接。账号档案保存配色、字体气质、人物布局及已认可效果的适用范围。阿刁保留自己的黑白淡紫风格；其他账号可以使用不同外观。真实品牌与软件保留本色。

默认工作约定：

1. 保留原口播内容、顺序与原声，使用画面、转场和声音设计强化表达。
2. 前 5 秒抓人，正文跟着内容起伏；人物、实拍、图片、UI 和图解按段落需要选择。
3. 让触发、状态变化与结果连续发生；阅读结果时用克制的轻推镜或局部高亮，不用强烈特效干扰阅读。
4. 具体操作使用真实界面和有依据的操作过程；概念或逻辑可以重绘，明确标注“示意”。
5. 素材不足主动补齐，并说明来源及真实／示意属性；涉及新增费用另行确认。
6. 先交可播放的开头和代表性正文样片，确认本期风格后完成整条。用户明确跳过样片或本期已经确认时按授权继续。

这些是本 Skill 默认，可由本次明确要求覆盖。环境安装的检查样片，不等同于本期风格样片；一处局部修改得到确认，也不代表整条或其他账号均得到确认。

## 从返工里保留判断方法

完整包的 `references/editing-lessons.md` 记录真实问题、改法和适用范围，包括：

- 检查人物整段动作中的脸、手和前臂，不能只看初始帧的安全区。
- 先判断底板是否必要，再选择颜色与面积。某次亮背景里撤掉大黑底有效，不等于以后所有场景都禁用黑色。
- 图片、截图不能仅靠长时间停留承担叙事；让对比、聚焦和对象交接呈现口播中的关系。
- 阅读与运动可以共存，但文字要有清楚、稳定可读的状态；避免进出场文字叠影。
- 同一对象在镜头交接时保持合理的位置与尺寸，视觉修改不扰动原声音和源时钟。
- 将技术通过、实际观看、用户审美确认分别记录；“AE 感”不等于交付原生 `.aep`。

## 字体资源保留了什么

字体来源为 [joeseesun/qiaomu-cover-fonts](https://github.com/joeseesun/qiaomu-cover-fonts/tree/415ea71650d6ba896759a2d7fde05ac5317ca3d1)，固定提交 `415ea71650d6ba896759a2d7fde05ac5317ca3d1`。

- **34 个字体文件**：19 个中文项、15 个英文项，包含同一字体的不同字重；不等于 34 种不同字体。
- **12 套搭配**：标题、正文、英文／数字角色按主题选用。
- **5 种可选 CSS 花字**：`highlight`、`sticker`、`depth`、`outline`、`plain`；均为本技能整合的样式，不是上游字库自带视频效果。
- **交互预览**：可换文字、搭配和效果，并拖动预览时间，先看当前稿件的字形与动态阅读效果。
- **本地导出器**：导出选定搭配或全部字体，保留对应许可、来源和样式；不安装系统字体，不联网下载，不覆盖已有输出目录。

这些文件位于完整发布包 `工具/skills/ui-motion-fusion/` 下。仓库首页是安装分发入口，完整资源在 Release 的 `UI-Style-Windows.zip` 和 `UI-Style-Source.zip`；GitHub 自动生成的 Source code 不是完整运行包。

## 预览与导出

系统已有可用 `python` 命令时，可运行完整技能中的 `assets/qiaomu-fonts/预览字体.cmd` 查看交互预览。系统没有 Python 时，用 Windows 包内 `工具/runtime/python/python.exe` 的实际绝对路径执行 `assets/qiaomu-fonts/preview.py`；预览不需要额外安装包。

下面的命令从 `工具/skills/ui-motion-fusion` 目录运行。若系统没有 `python`，将其替换为完整包内 `工具/runtime/python/python.exe` 的实际绝对路径。

```powershell
python -X utf8 scripts/export_qiaomu_fonts.py --list
python -X utf8 scripts/export_qiaomu_fonts.py --pairing tech --out <新工程内的新字体目录>
python -X utf8 scripts/export_qiaomu_fonts.py --all --out <新的完整字体目录>
```

字体导出是独立脚本接口；不是 `ui.py fonts` 命令。导出后，HTML／React 等项目仍需加载 `fonts.css`、`pairings.css`，按需加载 `effects.css`，并连接当前后端的文字动效。文件复制成功不等于成片字体已经生效。

渲染前等待实际字体加载，使用本期文字检查缺字、回退、标点、英文数字基线和裁切。CSS 字体别名不修改文件内正式名称；CSS 样式不能直接当作 FFmpeg 字幕字体配置。花字按语义选，不按时间轮换，不自动替换已有确认工程的整套字体。

本次整合保持从指定上游取得的字体原字节和许可。上游可能已有格式转换或其他处理；不声称等同于字体厂商未经处理的原始发行文件。导出或分发时一并保留许可与来源记录，详见 [CREDITS.md](../CREDITS.md)。
