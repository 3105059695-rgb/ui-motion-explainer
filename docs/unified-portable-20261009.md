# 统一版与自动安装验证

版本：2026.10.09.2；Windows 10/11 x64 联网安装包。

## 本次变化

- 合并七个 UI 视频模块的入口，默认沿用黑白淡紫、真实感 UI、连续对象运动、手机与桌面因果联动。
- 单一 AI-START 入口：AI 自动完成私有运行环境安装、检查、样片导出；用户后续直接在当前工作文件夹发送素材。
- 成功状态记录相对样片路径与校验值；重复安装核验后复用，失败不伪报成功；不注册全局技能、不修改系统安全策略。
- 完整发布包自带嵌入 Python；完整源码附件保留脚本、模板、风格规则与第三方声明，仓库 main 提供当前入口与版本元数据。运行包与源码包通过 Release 分发。

## 尚未验证与边界

没有在全新 Windows 10/11 虚拟机分别验收，没有在 WorkBuddy 客户端实际完成端到端安装。不将隔离 PATH 测试说成完全空白系统验证。

样片是无声技术测试，未代表完整主观视听检查、所有预设验收或用户审美批准。历史 230 条参考目录不代表 230 个案例都已随包提供可运行工程；原参考视频、私人账号、音色与素材不在发布范围。

安装包版本固定，后续更新需读取仓库最新版 release 元数据并由用户请求更新，不自动覆盖现有工程或已安装技能。
