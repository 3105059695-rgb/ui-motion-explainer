## 包的区别与使用边界

`UI-Style-Windows.zip` 是自带嵌入 Python 的自动安装文件夹；首次安装联网准备其余私有资源。`UI-Style-Source.zip` 是完整规则、脚本、模板与资源源码附件，不含随包运行时二进制。GitHub 自动生成的 `Source code` 是仓库快照，不是这两份完整附件。

安装成功状态记录相对样片路径与校验值，重复安装核验后复用；失败不伪报成功。简单安装入口不注册全局技能、不修改系统安全策略，不覆盖既有工程。新对话应指向同一工作文件夹。

没有在全新 Windows 10/11 虚拟机分别验收，没有在 WorkBuddy 客户端实际完成端到端安装。不将隔离 PATH 测试说成完全空白系统验证。

样片是无声技术测试，不代表完整主观视听检查、所有预设验收或用户审美批准。历史 230 条参考目录不代表 230 个案例都已随包提供可运行工程；原参考视频、私人账号、音色与素材不在发布范围。

安装包版本固定。后续更新读取仓库最新版 Release 元数据，由用户请求更新；不自动覆盖现有工程或已安装技能。
