## 当前机器怎样查

Agent 从安装目录调用 `python -B -X utf8 scripts/resource_inventory.py --help` 查看资源清单与具体参考的查询入口；查到来源后使用统一入口 `study` / `select` / `inspect` 读取对应方法、原句与实现。操作细节见[选用流程](../references/selection-workflow.md)。这些是同一Skill的内部工具，用户不需要逐个调用旧Skill。

已配置的本机资源映射可以接续作者电脑上保留的原片和历史源码。公开安装不能声称拥有这些私有文件；有目录、有源码入口、已运行过、已完整视听和用户认可分别记录。来源URL已保留不代表当前网络或第三方站点一定可访问。

## 每次制作应看什么

同一导演计划保留原句、表达目的、采用或不用参考的理由、素材、动作与衔接，以及实际实现和成片时间。几句话可以共享一个连续事件，也可以保留人物口播。工具检索给候选，Agent负责看原例并决定；技术检查帮助发现漏项，最终表达和画风仍看实际成片。
