## nanda：嵌套步骤收起与展开

[原作](httpLOCAL_ASSET_NOT_DISTRIBUTED)，nanda / @nandafyi，弹层标题 nested steps，标签 AI Flow、UI Interaction。原片为 720×720、9.775862 秒，实际查看 12 个暂停状态。Edge 自动翻译曾将作者显示为“南达”，作者 handle 与原作链接从真实弹层读取；英文姓名沿用已核实的作者署名。

初态为浅色点阵画布：顶部 do 卡片向审批、两步 parseApi 子流程和 sleep 三路分叉，再汇到下方 write 卡片。parseApi 被橙色框选，其内部两个 do 步骤分别是获取 API 和解析结果。1.301520 秒可见 Enter 提示及第一次收合的中间过程；1.475056 秒内部步骤消失、两侧卡片向中间移动、底部卡片上移，既有连线随之缩短。3.195954 秒回到展开状态；7.736813 秒为第二次收起；8.821413 秒再次展开；9.775862 秒末态橙色选框和 Enter 提示已消失，节点与连线保持。

原片普通光标停在左侧，没有观察到点击组标题；Enter 是实际观察到的输入反馈。任务文字并不证明 API、审批、等待条件或写入已经执行，也没有观察到成功或失败结果。

`interaction-nested-step-toggle` 保留三路分支、两步嵌套及汇合关系，将方形构图横屏重排为 14 秒：2.1、4.9、7.5、10.0 秒分别开始收起、展开、收起、展开，每次过渡 0.72 秒；12.35 秒开始取消橙色选中。容器、端口、外部卡片、底部卡片和 SVG 路径一起移动，内部节点在同一裁剪视窗中收合。字体放大、底部写入短标签与阅读停留为独立编排；任务仍是可失败的计划步骤，没有执行接口。

`title` 替换顶部任务，`prompt` 替换第一个嵌套任务，`result` 替换底部写入任务。工程 JSON 还可传 `approval`、`wait`、`groupLabel`、`parseResult`；两步数量固定为 2。短节点标签建议不超过 10 个汉字，超长显示省略号；它们没有代码字符上限。若改成三步或改变分支数量，需改节点、端口、路径与时间轴。
