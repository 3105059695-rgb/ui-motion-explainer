# Collect UI 第三批：观察依据与制作差异

记录日期：2026-09-27。David Haz、Kris Puckett 与 Kopp 的浏览证据由主代理实际检查后转交，本文件负责整理；不宣称整理者亲自播放过。Alok 沿用前批观察，本批没有重新观察原视频。

本文件记录来源事实与制作差异；3个预设随后完成本地时间轴、画面和导出检查，实际范围见 [验证记录](../verification.md)，全站计数仍以coverage.json为准。

## David Haz · Tech Text

来源：[David Haz 的原作品](httpLOCAL_ASSET_NOT_DISTRIBUTED)。原片时长 14.5 秒；实际截图时间为 0.336、2.392、5.371、8.608 和约 13 秒。

实际可见：白色预览区域内有黑色大字 `the future`。光标悬停某个字母时，该字母呈浅灰或白色填充、黑色虚线字形，并出现蓝紫色尺寸框和锚点。顶部出现过 `59 × 141`、`101 × 115` 的尺寸标注。观察顺序为首字母 `t`、第三个字母 `e`、最后的 `e`；8.608 秒时光标离开，字母恢复全黑。以上尺寸是原片可见标注，不应被当作新预设必须固定采用的尺寸。

对应预设：`result-tech-text-inspect`。制作采用可编辑中文关键词，重建“光标定位单字 → 字形检查框与尺寸出现 → 移开恢复”的结构和交互机制。中文字体、具体字形、字号、框线位置和过渡曲线需要按本地实现设计，不能称为原字体的像素级复刻。验证结论另列于本包verification.md。

## Kris Puckett · Dynamic Island

来源：[Kris Puckett 的原作品](httpLOCAL_ASSET_NOT_DISTRIBUTED)。原片时长 10 秒；实际截图时间为 0.164、3.415 和 9.647 秒。

实际可见：奶油白色手机 App 顶部有一个较大的黑色胶囊区域；内部包含白色像素风跑马、浅绿色树、点状山脉或地面，以及少量星点。不同截图里，马与景物的位置发生变化，形成运行中的景物动画。没有观察到胶囊展开、任务完成或成果呈现，不能据此编造这些后续状态，也没有足够证据陈述精确帧率、运动曲线或循环周期。

对应预设：`ambient-agent-island`。它把胶囊运行氛围适配到 1920×1080 横屏软件演示；马和景物由本地代码自行绘制，不嵌入原片。手机到横屏的布局调整、像素造型和路径属于设计重建。若额外添加任务文案或状态，应明确属于制作适配，不能倒推为原片已观察功能。验证结论另列于本包verification.md。

## Alok · 转账确认（沿用前批证据）

来源：[Alok 的原作品](httpLOCAL_ASSET_NOT_DISTRIBUTED)。本批没有新的视频观察；依据来自前批已记录的机制与可见数值，本文件不补造时间戳。

已有可信观察：浅灰白背景、圆角白色转账卡与柔和阴影。初始 `$2500` 对应 `€2300`；金额修改为 `$4000` 后对应 `€3680`，随后滑动确认，卡片中显示 `Sent €3680` 与 `Successful`。

对应预设：`interaction-transfer-confirm`，代码声明时长 9.5 秒。该实现采用一张约 700×720 的居中白卡，演出点击、选中、替换金额与联动换汇；同一滑块拖到终点后才写入成功状态，保留结果阅读时间。默认数值复现已观察的数值关系，`0.92` 仅是这段演示的示例汇率，不表示实时汇率。

具体布局、字体、鼠标轨迹、输入节奏、阴影和运动曲线均为设计重建；未取得逐帧曲线或品牌外观依据。来源状态使用 `observed-reconstruction`，不宣称像素级复刻。语法、时间轴定位与视觉抽查分开记录于本包verification.md。

## Kopp · Navigation / Menu / Landing Page

来源：[Kopp 的原作品](httpLOCAL_ASSET_NOT_DISTRIBUTED)。已读取页面文字、作者与分类关联，但视频持续为 `readyState = 0`，无法取得有效 `duration`，也没有可见视频帧。

本件仅能保持 **queued**。不能根据 Navigation、Menu 或 Landing Page 标签推断其菜单展开方式、悬停效果、页面转场、视觉样式或完成状态；本文件不为它指派已观察机制或已复刻预设。

## 口播选择建议

| 用途 | 合适的口播与画面角色 | 选择限制 |
| --- | --- | --- |
| 技术文字检查 | “关键是这两个字”“把注意力放在这个细节”：用 `result-tech-text-inspect` 定位短关键词，依次显示单字检查状态。 | 不用来逐字处理长段字幕；口播不谈检查或重点时，不强加尺寸框。 |
| 任务运行氛围 | “它正在后台处理”：用 `ambient-agent-island` 作为运行中的轻量状态提示，周围保留真实操作或任务上下文。 | 不用跑马动画替代输入、执行证据或成果展示；不能暗示原片已有完成状态。 |
| 滑动确认 | “核对金额，再滑动确认”：用 `interaction-transfer-confirm` 展现金额修改、换汇反馈与明确的确认动作。 | 仅在确有滑动确认语义时使用；不把示例转账或示例汇率当成真实交易成功或实时金融数据。 |

以上是依据本批机制提出的编排建议，不是对原作者作品使用场景的事实陈述。后续若调整预设实现，应继续区分原片观察、设计适配与实际验证结果。
