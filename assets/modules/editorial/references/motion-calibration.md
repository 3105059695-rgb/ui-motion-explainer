# V3 连续动作校准

用户在 V1、V2 后均指出整体不像。因此该工程只作为持续校准的候选样片，不能把技术检查与打包成功当成风格已被认可。

## 不只匹配静帧

为每个主对象记录进入、触发、动作峰值、落稳和退出五个时间点，并检查其间的轨迹。静帧有相似构图但发生在错误时间，仍会改变整体气质。本次开场海报特写应在约4.1秒发生，不能挪到2.8秒；曲面屏要让菜单、侧栏、代码、选区一起变形，不能只弯文字。

同一个 URL 从页面被复制到聊天框时，只让背景与容器转变；保留 URL 的可追踪位置、内容和运动方向。点击、加载、成功、复制和逐字输入要各有清楚的前后状态。优先交付一段连续10–25秒对照，而不是用好看的静帧证明动作准确。

## 材质与对象层

真实皮革、金属、细密网页或像素头像，不能用大色块替代后靠阴影宣称还原。可采用用户参考中独立裁切的物件纹理；必须分清位图素材与原生几何、文字、相机、遮罩、状态和时间函数。保留可替换入口或原生替代，不允许以整帧原视频覆盖画面冒充可编辑重建。

独立位图保留了来源材质，但不能从未出现的视角生成真实三维。运动跨越明显透视变化时，需要对应视角、源模型或明确的近似说明。

## 文字与字幕

先按画面观察建立字幕句子，再参考 ASR 对齐声音。ASR 断句不等于视频字幕分段；不要让“脱颖而出”单独短句替代原片持续显示的完整句子。中英文混排按字形宽度计算占屏，不能把每个 ASCII 字母都当一个中文字宽。

字幕尺寸、底距、圆角和强调色也参与风格。本例后半底距约61逻辑像素，常规23px、长句约19px，白底圆角与少量绿色重词；这些是本片校准参数，不是所有题材的全局默认。

## 交付状态

分别报告：源画面观察、原生重建、来源纹理、替代项、已渲染／已解码／已抽帧查看、完整连续审片、用户审美反馈。不要使用虚构的相似度百分比，也不要在用户否定后把候选样片写成既定范式。
