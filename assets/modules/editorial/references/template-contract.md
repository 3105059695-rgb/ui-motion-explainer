# 模板合同与最小验证

## 文件与 Composition

本包的 `assets/remotion-template` 是可运行 Remotion 工程。新工程脚本复制到独立目录，然后用 `npm ci` 按锁文件安装。

| Composition ID | 用途 | 修改入口 |
|---|---|---|
| `FullReplica` | 按参考结构制作的完整复现样片 | 对应场景组件和时间轴 |
| `MechanismShowcase` | 较短的可复用机制展示 | 对应机制编排组件 |
| `RefinementPreview` | 约 21.9667 秒的无声校准预览，随当前组件更新 | 三段源帧映射与对应精修组件 |
| `ScreenshotStage` | 用户截图的完整展示、聚焦和包装 | `public/user-content.json` 与对应组件 |

实际项目源码是实现的依据。添加新的场景机制应有可运行代码和可定位时间，不把文档里的名称数量当成已完成组件数量。

## 校准预览（V2起建立的源帧映射）

`RefinementPreview` 默认无声，30 fps、659 帧，拼接下列三个范围（帧号均从 0 起，两端包含）：

| 预览帧 | 原片帧 | 对照范围 |
|---|---|---|
| `0..221` | `56..277` | 开场三份参考与代码镜头 |
| `222..469` | `684..931` | 文档、九宫格搜索、代码与内容替换 |
| `470..658` | `2968..3156` | 高质量网页与手机场景 |

```text
npx remotion render src/index.ts RefinementPreview out/refinement-preview.mp4
```

对照时按此映射取源帧，不能用预览秒数直接查询原片。该预览用于整体尺度、素材密度、背景和转场校准；它的生成不证明 FullReplica 已重渲染，也不包含完整原声复核。当前用户未认可 V2 的审美相似度。

## 快速验证

1. 新工程执行 `npm ci`，运行 `package.json` 中已有的类型／代码检查；若无统一检查脚本，使用 `npx tsc --noEmit`。
2. 用 `npx remotion compositions src/index.ts` 确认需要的 Composition 可加载；截图项目确认用户图片已加载而不是默认素材。
3. 查看起始、主要动作中间、阅读稳态、转场中间与尾帧。检查中文溢出、截图比例、焦点坐标、对象交接和任何遮挡。截图焦点相对于 456×425 展示面板，需确认高亮覆盖制作人指定区域，而不是 contain 留白。
   复刻任务先验证代表性 10–25 秒，在映射后的同一时间点逐帧比较标题边界框、主物体占屏比例、背景 RGB、网格／瀑布流密度、转场起止与圆内内容。比较表保留源值、复刻值和仍有差距的项，不能用单张漂亮关键帧替代。
4. 用户要成片时渲染对应 Composition，并检查视频尺寸／时长、完整解码及预期音轨。音轨不存在时不能声称已检查声画同步。

公开输出中只报告做过的检查。“渲染完成”“抽帧检查”“完整连续观看”“用户审美认可”是不同结论。局部通过不代表整片逐帧复刻，也不证明截图中的业务真的执行过。

用户已否定 V1、V2 的相似度。lint、类型检查、渲染、解码通过只能说明技术可用，不把尚未获认可的整体气质标为最终可复用审美模板；每一版的实测与反馈需单独记录。V3 的连续运动规则见 `motion-calibration.md`，新主题仍须换内容并重新校准。

## 新工程脚本行为

- 目标不存在或为空目录时才允许复制；非空目标返回明确错误并保留其中所有内容。
- 排除 `node_modules`、`out`、`dist`、`build`、`.git`、`private`、`source-media`、`local-reference-props.json`、依赖缓存、`.env*`、日志和符号链接，避免带出私有媒体引用。
- 不复制完整参考视频或原声音轨；允许复制模板内独立裁切纹理及来源清单。它们不是纯代码图形，不能以“未带原片资产”概括。脚本不安装依赖、不启动服务、不渲染、不上传；以上按当前任务需要在生成后执行。
- 模板缺失、截图不存在或扩展名不支持时，在写目标目录之前报错。
- 可选 `--focus X Y WIDTH HEIGHT` 设置面板归一化焦点；校验有限数字、四项范围、正宽高与右下边界后才复制工程。未指定时使用演示／用户截图各自的默认区域，不宣称自动识别重点。
- 脚本相对于自己的路径定位模板，不依赖固定磁盘、用户目录或其他已安装技能。

## 交付内容

通常给成片、工程路径和一条运行／渲染命令；需要复用时再给 Skill 路径与截图入口。说明仍存在的具体近似：字体、三维物件、截图文字、复杂镜头或音频。无需重复一整份制作过程。
