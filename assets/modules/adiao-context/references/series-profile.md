# 阿刁系列最新制作经验（2026-09-30）

适用于阿刁；不把它的音色、人物和配色强加给王哥、方木等账号。此文可随公共技能分发，不含私人人物 ID、密钥或本机工程路径。

## 2026-10-04 补充优先

用户已确认 Agent 先复述 v2 的整体感觉，并要求记住本窗口风格。制作前读取 [最新已确认规则](approved-style-20261004.md)：UI 风格延续、开头每期创新、丰富且语义匹配的真实素材与漫画、人物安全区、连续对象变化。它覆盖本文较早的 Q 版使用判断与固定版式倾向。v3 品牌集结开头已交付但尚未获得明确审美确认；不要把该连招固化为后续模板。

## 优先级与接续

当期明确要求 > 当前工程确认设置 > 本文 > 旧 defaults／示例。旧 400px 是圈内构图测试，260–320px 是一般布局起点；最近 1080p 工程正文用 174px。区分裁切取景和画布上的圆径，不把某个数值固定给所有视频。

同机有 `adiao-series-guide` 时，接续旧片读取它的工程与认可状态索引；公共安装没有它也可按本文和本期素材制作，不因作者电脑路径缺失停工。

先识别本期范围：视觉能力展示可先视觉再口播；有最终声音直接后期；新声音先试听，再开头短片，已完成的确认节点不重复。用户明确许可延后口播或让人物与素材换位时按该期处理，不把常规规则当绝对禁止。

## 开头：同一视觉语言，不同主事件

- 白／微灰白、近黑、紫色重点，中文字体扎实、清楚。第一眼能知道主题，产品 logo 或真实界面尽早出现。
- 按本期写“对象 → 触发 → 状态变化 → 可见结果”再做动作。单一主视觉持续存在，资料多也不默认乱堆卡片。
- 不反复“大数字＋漂浮卡片”，不一张 PPT 停几秒再换页，不让标题、文件、人物、桌面同时做不同方向的入场。
- 否定重复数字卡片模板，不等于删掉“五个技能”的数量承诺和具体身份；需要数量时用新的叙事机制清楚建立。
- 人物开头保留原构图，用右侧空白展示产品、素材和连续动作；不能只加字幕或挡脸、手。
- 冲击感靠铺垫、速度变化、匹配构图、景深、遮罩、短时运动模糊与声音落点。停稳后可读，不持续抖动、闪白或乱飞粒子。
- 多种真实 PPT 成果穿行后聚合到工作入口，是可选机制；双窗口对比→相册→播放→大人物→小圈，是某期指定顺序，都不是所有片固定模板。
- 开头通常 10–20 秒完整钩子句；本期素材、完整声音和明确长度优先。约 7.64 秒的某期短片不变成通用默认。

## 正文：让观众看到怎么做

- 不要标题、列表、截图轮播配口播。讲 PPT 技能仍可展示真实 PPT 成果，重点是操作、对比和检查。
- 实操教程优先真实录屏：入口→点击→完整选项→输入→计划／过程→结果→核对。只显示 Auto、只放聊天框教不会新手。
- 缺依据时重建 UI 并标“示意”；未发送提示词、未保存草稿、只打开说明不能称真实完成。
- 录屏正常速度，允许剪等待，不加速假装响应快。点击前留定位线索，之后留结果阅读时间。
- 源片不够要补录或补有依据的素材，不能自动冻结尾帧撑正文。同一文件、字段和数值跨状态保持身份。
- Mac 框架、顶栏、红黄绿按钮、柔和桌面和适量 Dock 衬托操作，主界面仍须大而清楚；包装不代表产品在 Mac 原生运行。
- 正文小圆圈在左下，头肩胸像、无桌子，不遮挡。大人物退出与小圈进入有交接，不能双脸或重播声音。
- Q 版素材曾在阿刁部分片中被否定为丑且挡内容，不默认加入；其他账号明确要手绘时服从其当期要求。

## 素材、文字和动作实现

- 助手找官方 logo、官网／文档、真实 GitHub、README、演示及成果。不是让用户重新找风格和全部录屏。
- 材料记指定用途和使用区间：开头限定、正文限定、讲到再出现、技能对应或弃用。选精华并记源内时码，不能所有附件从头塞进全片。
- 示意文字、操作指令优先中文，真实产品界面、仓库名和品牌保留规范名称。口误别名只有本期证据明确时映射，不能找错产品。
- 按最终显示像素选择源素材，重采细节，不拉糊缩略图。1080p 编码不证明内容清楚；品牌色保留，旧价格／Star 当期再核实。
- 原创简化 3D 用于解释关系，不用于伪造品牌界面、统计或研究证据。
- 字体实际加载／嵌入，子集覆盖全部动态文字与字幕。缺字修复，不只改 font-family；符号用 SVG 或合法备用字库。
- 深紫用于白底重点，渐变用于短词或数字，不能所有正文都染紫。
- 一个确定性时间轴支持回拖，不靠随机数、Date.now、setTimeout 改帧内容；不同动画不争同节点 transform。
- 外框、滚动、透明物件、阴影与遮罩分层；避免透视白矩形、截阴影、闪空卡。模糊只采动作状态，源视频和字幕时钟固定，内部更新清理旧副本。
- 检查转场中间帧：长句交叉淡化会重字，横向替换可能拼出半新半旧错句；用整行或上下遮罩解决。
- 约 0.35–0.8 秒主过渡、0.04–0.12 秒错峰只是调参起点。逐字用于输入框和短关键词，长字幕稳定可读，不把长口播同时贴满主画面与字幕。

## 音频、版本与交付

- 已保存的阿刁克隆声音；开头 Avatar V，正文 Avatar III，已接受生成后本地圆形 alpha。已有素材直接剪；服务、授权、引擎和费用在实际调用时核对。
- 默认不新增 BGM，明确要求原 BGM 时保留。要求“哗一下”、点击、转场 SFX 时适度加入；旧 sfx=false 不能覆盖新要求。
- 一条连续母带与真实字幕轴，不重复开头、不重播人物时钟。没实际试听就不称全片试听。
- 改稿使配音、人物嘴型、字幕和时序失效；只改 UI 不自动重生声音／人物。确认针对实际展示版本和用户原话，“继续”“文案与#”不批准另一未展示版本。
- 局部改开头复用锁定正文、有效缓存；长片分段渲染，源文件与旧版保留。
- 交付可发布 MP4 文件夹、预览和可编辑工程；网页、素材准备和技术通过不等于成片或用户审美认可。
- 已交片上下文的“文案与#”默认发布配文和5个最关键标签；完整口播按明确请求另发。审核驳回原因未知时如实记录，用户要求的局部打码不扩大为全站素材规则，也不保证过审。
- 公共包是可运行底座，不是一键理解任意稿子并自动生成优质整片的服务；不自带私人形象、音色或 API 授权。

## 其他技能的边界

`apple-kinetic-promo` 的蓝色、短宣传片长度、默认音乐不覆盖阿刁规则。`ai-ui-director` 是可选动作库，取连续交互机制，不直接改成黑黄／深色整套 UI。被用户暂停的库扩充只使用现有资源，不擅自恢复。
