# 如何做出接近原片的复刻

## 观察与时间码

1. 读取当前案例 JSON，获取完整 video 而非 preview，确认画幅、时长与音频。`toolkit.py video <slug>` 优先使用已有原片缓存。
2. 看完整原片。先按 0.5 秒或指定 BPM 的一拍取样：`toolkit.py analyze --slug <slug> --out <新目录> --bpm 120`。默认最多约 96 帧，长片会自动稀疏采样；细看某段时使用原视频播放器或截取区间后更密采样。
3. 将接触表中的候选变化点与真实视频对上。变化量高可以是移动、闪光或换镜头，低也可以有缓慢持续运动，不能用自动阈值冒充语义分析。
4. 记录真实字体、字号、物体尺寸、位置、屏幕占比、镜头锚点、时间长度、过冲量、文字阅读停留和声音峰值。参考不清楚的细节标 `uncertain`，继续观察；不要杜撰来自作者的参数。

## shot-plan.json 推荐字段

每段至少包含 `start/end`、`subject_id`、`from/to`、`trigger`、`camera`、`content`、`audio_cue`、`reference_frames`。例如：

```json
{
  "start": 2.0,
  "end": 2.5,
  "subject_id": "main-shape",
  "from": {"width": 280, "height": 100, "radius": 50},
  "to": {"width": 520, "height": 320, "radius": 30},
  "trigger": {"type": "cursor-click", "time": 2.03},
  "camera": {"anchor": [720,720], "scale_from": 1.1, "scale_to": 1.0},
  "reference_frames": ["frame-004-002.000s.jpg"],
  "parameter_origin": "measured estimate; not original author code"
}
```

## 运动必须可重放

使用闭式弹簧、预计算路径或可寻址时间线，使相同 `t` 总是得到相同画面。一个多目标属性可以叠加每次目标变化的弹簧响应。液态标签/开关可让前后边缘有不同延迟和弹簧刚度。直接拖拽区间由光标位置决定属性，释放时从释放位置连续回弹。光标位置、点击压缩、触发的状态切换也要有相同时钟。

内容换入换出与容器尺寸变化有独立的遮罩/模糊窗口。容器大变形过程中，旧文字不会与新文字叠在一起。相机围绕当前阅读中心缩放，鼠标和阴影随同一场景空间变化。跨场景同一对象传递用统一 subject_id 和连续几何，不能用一张卡片消失、另一张卡片出现代替。

## 素材与音频

用户未提供素材时先用参考资料观察构图，公开产品用实际可获得的品牌素材，原创示例素材明确标注。SVG 示例照片只能说明动作，不等同原摄影素材。需要原片级别的风景、真人、墙面视频或音色时，在授权范围内取真实素材；如某个必需资产不可得，保留可替换入口并报告影响。

从分析目录的 reference-audio.wav 测量节拍/事件峰值，必要时用 FFT 或波形，不能仅凭 prompt 写着 120 BPM 就假定原成片准确。复制音乐或作者 SFX 的权限独立于动效重写；用户提供音源时遵照其用途。纯代码案例可以合成自己音轨，但声音重建的差异必须记录。

## 相似度验收

技术验证只证明画面能生成。对照应覆盖开头、每个变化的前/中/后、读字停留和结尾，重点看：

- 对象：形状、颜色、边缘、大小、相对位置、元素数量；替换内容是否保留构图。
- 运动：发生时间、速度曲线、过冲/回弹、轨迹、对象身份连续性。
- 相机：推拉、锚点、旋转、景深/模糊、画面中心。
- 文字：字重、字宽、换行、遮罩、颜色、可读区间。
- 声音：节拍、落点、动态、事件音和原片的停顿。

`python scripts/toolkit.py compare --reference <原片> --rendered <成片> --out <新目录>` 生成左右时间码接触表，不自动评分。画幅不同、品牌文字替换和摄影素材差异会影响像素差，像素相近也不证明动作语义相同。

工程的验证记录应包含实际测试命令、输出尺寸/时长/帧数、seek 重复结果、解码结果、实际检查过的参考区间、观察到的差异、声音与用户认可状态。不把 `reference-collected`、`starter` 或 `technically-verified` 写成“全站已经复刻”。
