HOW TO REBUILD

复刻一个具体案例

  1. 选定原片打开详情，看原视频与完整提示词。
  2. 准备工程让 Codex 使用 $prompt-motion-replica，指定案例名称或链接。
  3. 逐段重建读取原片帧、镜头、字体、状态和音轨，编写可编辑源码。
  4. 导出与对照渲染 MP4，按相同时间点比较原片与复刻结果。

视频与原提示词归各自作者所有。本库保留来源，仅作为个人复刻参考。模板为独立重实现，原片与模板分开标注。
