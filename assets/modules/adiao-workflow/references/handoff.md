# 配音与人物交接：当前可用路线

状态基于2026-09-21实际调用和用户确认；下述测试不是新一期授权或当前余额查询。后期统一读 [post-production.md](post-production.md)。

## 当前路线

确认的阿刁配音 → 上传HeyGen → 按角色指定人物与引擎 → 保存任务ID → 获取已完成视频 → 正文按确认比例裁圈 → 开头/正文合成。用户已接受后期圆形路线，原生圆形模板与网页连接不再是前置条件。

自动识别开头钩子，目标10–20秒、优先约15秒，按确认配音实际完整句结束点拆音频。开头段用 Avatar V 大画面，余下正文段用 Avatar III 左下胸像圆圈；记录两段母带时码，避免漏字/复读。读取 [heygen-identity.json](heygen-identity.json) 中两个人物ID和 defaults.json 中 avatar_roles，不用单一人物替代两套。人物ID本身不包含圆形裁切；不能只设置ID就声称原生圆形。

## Fish / voice-clone

- 技能和脚本：[voice-clone](../../voice-clone/SKILL.md)，scripts/voice_clone.py。音色参考固定 LOCAL_ASSET_NOT_DISTRIBUTED
- profile中的旧“调试中，待用户选择”标签不覆盖用户已选阿刁这一事实；不能覆盖原参考。每期生成的配音仍需用户试听确认。
- 当前Windows用户已配置DPAPI加密凭据，独立进程读取与新音频合成已实际成功。先调用 auth-status 自动解析已存凭据，不因环境变量空而反复索要Key。
- 不读取其他任务消息找密钥，不把凭据写入Skill、项目、导出包或日志。实际密钥由 voice-clone 的 credential resolver 管理。
- 当前测试走 s2.1-pro-free；免费路线失败不自动切付费。合成脚本已有短暂TLS故障重试和Windows代理继承；鉴权失败与网络失败分别报告。
- 先 --dry-run 核对分段与参数。锁定实际音频文件及hash，分段speed与全局rate分开记录，不重复加速。新链路验证不能拿旧音频充数。

## HeyGen 调用

MCP已实际读写可用。create_video_from_avatar 暴露 engine、audioAssetId/audioUrl，可使用外部克隆配音；没有原生圆形/半径参数。明确传 avatar_iii 或 avatar_v，不使用人物绑定音色重新TTS。上传依工具返回的规格执行，不在Skill硬编码易过期的上传URL。

调用前读取当前工具schema与当期用户授权。先核对声音版本和音频时长，再提交；保存返回videoId并按工具规定显示播放器。长任务不重复创建；是否查询状态遵循当前工具说明和用户请求。生成完成先检查声音、时长、人物身份，再裁切，不把processing写成完成。

API-ready模板最近查询为空，网页控制最近报 nodeRepl.fetch request failed；这是原生模板分支的状态，不影响当前MCP生成加本地裁切路线。不要自动要求用户去建模板。

## 圆形裁切与字幕交接

脚本 `scripts/circle_presenter.py` 要求 --crop X Y W H，不覆盖已有输出；复制原声并检查解码、时长。确认源片1920×1080的示例裁切为270 0 800 800，圆径400、距左/底48。坐标只适用于该源片，新源片检查头部位置和动作极值再适配。现有示例头顶轻微截断已说明，不能声称后期修复缺失图像。

脚本输出带近白整幅背景的预览。完整UI需在渲染器直接使用源片与圆形alpha，不把整张预览白底叠到UI上。角色切换跟实际钩子句结束点，不硬编码秒数。

## 无法接入时

保存已经完成的声音和已提交任务，明确哪一步失败。只在确实需要时给用户准备音频、口播、时长、人物与模型说明用于网页交接；人工回传不标为API自动完成。重试之前检查旧任务，避免重复计费。正式片声音与口型一旦换版，按 [工作流](workflow.md) 失效相应依赖。
