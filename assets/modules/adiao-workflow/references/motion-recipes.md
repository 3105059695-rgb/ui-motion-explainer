# 同一 UI，不同运动：阿刁动效配方

这是选择与实施指南，不是用户逐条认可的新增效果清单。认可范围见 [历史证据](history.md)。每个语义段选一个主动作，动作前后稳定状态先完成排版，再补速度、景深和遮罩。节奏跟口播重音，不依赖BGM。

## 每期独立设计开场（2026-09-24）

用户明确要求：“每次开头都是不同的这种ae感觉”。执行原则是 **统一 UI 语言，每期独立设计 AE 感开场**。延续已确认的白底黑紫、字体层级、人物规则和纯口播；从当期核心内容重新设计主视觉事件、镜头路线、素材出场顺序和转场组合。

- 开工时对照最近可取得的两三期开头记录，说明本期主动作与最近一期开场有什么实质不同。没有历史记录就如实记录，不能虚构看过旧片。
- 新意必须体现在运动结构：例如从结果倒推过程、穿过字形进入真实界面、沿同一对象连续追踪、画面匹配接管。按语义选择，不按效果表机械轮班，也不只换文案、图片或标题。
- 这次获认可的胶片曲线、字形开口、时间线组装、翻页可以进入可复用动作库，但不能成为以后每期的固定连招；其他历史成功开头同理。
- AE 感由加减速、镜头与前后层级、短时运动模糊、形状匹配和遮罩交接共同完成。首几秒建立清楚的视觉事件，运动落定后保持素材、品牌和关键字可读；人物原话从 0 秒持续。
- 在当期剪辑表或工程说明简记“开场概念、主动作、与最近一期的区别”。只在用户评价后记录认可范围；索要文案或接受交付不代表自动批准全部效果。

用户是在确认长期制作偏好时，更新规则即可，不自动重剪已交付视频、重生人物或配音，也不额外增加风格审批。

## 按材料选主动作

| 家族 / plan family | 输入和重点 | 连续运动与落点 | 易错点 |
|---|---|---|---|
| 证据纵深 / evidence_depth | 多张真实截图、帖子、仓库 | 后层低对比错位，主卡推到清晰焦平面；下一张沿同一轨迹接管；收向品牌锚点 | 不是五个方框同时乱飞，背景长文不用硬读 |
| 品牌与重音 / type_reveal | 短句、产品名、数字、价格 | 主字从遮罩内揭示，快速到位后减速；同一字组缩成下一页小标题 | 单独一个大5无法替代五项材料；Logo不用普通字体伪造 |
| 成果接管 / material_takeover | 网站、影片、PPT成果 | 当前素材焦点推近，轮廓/运动方向成为下一素材遮罩，稳定后正常播放 | 避免硬方块裁剪与整页淡入淡出；不能为炫技把成果加速 |
| 页面聚焦 / repo_focus | GitHub、文档、软件操作 | 保留页面锚点，镜头移到关键文件/字段；选中高亮→动作→结果停留 | 仿制页面标示意，真实数据不随意改写 |
| 同物交接 / object_handoff | 工作流、多技能串联 | 同一个文件/任务离开上一容器进入下一步骤，内容改变而身份可追溯 | 每一环弹张新卡看不出流程，不要连线乱接 |
| 对比与因果 / cause_compare | 机制、成本、结果差异 | 对照同尺度，灰化无关项，沿因果关系改变状态，结论留读 | 不以3D大小差代替准确数字；结果需来源 |
| 场景到图解 / scene_bridge | 职场、生意、生产、资料处理 | 具体场景先建立理解，抓一个动作/物件接入图解，解释其关系 | 任意库存办公视频不能说明所有口播 |

`hold` 可用于读文件、看演示结果的稳定镜头。不是每一镜头都要转场，更不能按顺序轮用上表凑数量。

## 把“丝滑”落到镜头参数

以下是新镜头的调参起点，不是死板时长：主过渡通常0.35–0.8秒，强调冲击可更短，视口播落点调整；同镜头错位入场约0.04–0.12秒。动作快段用于转移注意，减速后给可读帧。长段说明优先停稳，不持续漂移。

- **锚点连续**：记下被接管的对象/词/鼠标焦点以及前后屏幕位置。新镜头从这个位置接续，而非每镜重新从画外飞入。
- **景深连续**：主材料始终清楚；退到后层才逐步模糊并降低对比，接回前层时恢复。不要给整屏加长期模糊。
- **运动模糊**：快速平移/推镜用时间采样或渲染器支持的模糊；落定帧恢复锐利。拖影只发生在运动阶段，不保留描边重影。
- **透视克制**：倾斜表达前后层级，阅读时回到近正视；不能让截图长时间斜到读不出名字。
- **遮罩有形状依据**：窗口边缘、字形、物件轮廓或连续曲线接管画面。禁止随机碎格、消消乐和无来源全屏闪光。
- **人物与界面换位**：人物源片/遮罩独立，主材料在安全区域内从后层成为主角；素材可以短暂占主画面，人物声音持续。入正文才切到确认胸像构图，不用每期横移人物出画。

## 字体的动态层级

产品字标、主标题、说明、字幕各自承担一个角色。渐变紫用在一个关键词或数字上，正文近黑保持可读；不要把所有字都加粗染紫。标题不靠横向拉伸显粗，不靠复制一层描边制造体积。

同一词从主标题变成栏目标签时保留字形和颜色，通过尺寸、位置与行距变化衔接；进入下一概念才替换文字。小文字放大应放大真实矢量文字或高分辨率内容，截图不足时换更清楚源片，不能宣称插值恢复了细节。

## 2026-09-23 复盘：AE 感要贯穿语义段

用户希望正文也有更多 AE 感，但这不是在每张卡片上重复一个透视飞入。先从口播里找连续的对象：例如同一份资料如何变成方法文件、如何进入验证、反馈又怎样修改原规则；在一个长段内安排多个真正改变信息状态的动点。实物或真实界面建立情境，遮罩、焦点和前后层级把该对象带入讲解，落定后让内容清晰可读。数量由口播决定，不能机械规定每段必须有几次转场。

技术上不要把带白底和阴影的整块截图直接做矩形透视变形。未交付试验的中间帧出现了方形裁切边、截断阴影；较长的透明淡入还会在白背景上闪出空卡。后续应将对象、背景和阴影分层，用对象 alpha 或贴合轮廓的遮罩及边缘羽化交接；入场首帧要能看到主体，运动模糊只在运动时出现。验收要看动作中间帧和源/目标交接，不只看静止联系图；人物与字幕的避让也要检查整个运动轨迹。
