# 剪辑验收：技术可用与画面好看分别检查

检查由代理完成。用户仍只主要确认配音和开头；这张表不增加逐段用户审批。没有实际查看或试听的项目写“未检查”，不以脚本退出码代替观看。

## 开头交样前

- 首帧就有人物与口播，钩子句没有截断；本期产品Logo/界面尽早可识别。
- 展示的是对应真实材料或明确标识的演示，主要对象一眼可辨，不是孤立巨字加通用空卡。
- 标题字形、粗细、行距、紫色和品牌字标在最终导出里正确；声纹、字幕、卡片不挡关键字与脸。
- 每个主过渡看动作前/中/后帧，必要时看连续播放；对象去向清楚，快段与停稳交替。只看联系图不能宣称动态丝滑。
- 保持大画面人物阶段的构图；手和脸没有被未经设计的裁切/遮罩吞掉。

## 全片交付前

| 检查 | 实际验证方法 | 不足时怎么处理 |
|---|---|---|
| 时间与版本 | 检查剪辑表、配音hash、开头确认文件；核对整片时长与配音 | 修时间轴或失效依赖，禁止旧配音冒充新版本 |
| 素材对应 | 对照每个语义段，查看具体场景与焦点 | 空泛库存片或纯字幕段补有解释作用的素材 |
| 材料清晰 | 在交付尺寸与常见播放器缩放下看仓库名、操作、结果 | 换源片/裁到重点，分层重建说明但标示意 |
| 阅读停留 | 关键文件/PPT结论落稳后读一遍 | 拉长阅读段或减少同屏信息，不能一味加速 |
| 转场 | 查看所有切点附近和各类动画的中间状态 | 修曝光跳变、空帧、硬方框和突变位置 |
| 圆形人物 | 首/中/尾及最大动作幅度帧检查脸、肩、上缘与桌面 | 按当前源片适配裁切，保留用户确认胸像比例 |
| 字幕 | 逐段文字与锁定口播一致；检查长句/英文字段/底部安全区 | 调行宽和换行，不缩成小字，不与标题重复堆叠 |
| 音画 | 实际试听开头、人物切换、拼接和片尾，观察口型 | 无BGM/SFX；避免重复音轨、漏字、复读、漂移 |
| 编码 | ffprobe尺寸/fps/时长/音轨，ffmpeg完整解码 | 修报错；如只局部验证，明确范围 |
| 工程恢复 | 确认本地素材、字体、时间轴、渲染入口可定位 | 补缺失映射；不能只有临时URL或播放器网页 |

不把现有测试源片的已告知轻微头顶截断升级成“完整修复”。新素材有同类问题先调整可用源片/构图；需要重新付费生成时按用户授权处理。

## 本地检查工具

`scripts/check_edit_plan.py <edit-plan.json> --report <new-report.json>` 检查素材与音频hash、时间覆盖、演示标识、素材区间及表中播放速度。技术报告包含它无法判断的限制。`--no-probe`只供结构调试，交付前默认使用ffprobe。

成片解码可用 `ffmpeg -v error -i <final.mp4> -f null -`；媒体信息用ffprobe。具体抽帧使用 [现有抽帧工具](../../ui-motion-explainer/references/production.md)。无需为轻微文案修改重渲染整片，也不默认启动独立审查代理。

检查报告保存证据文件/时间点和实际范围。例如“0–12秒连续预览，6个切点抽帧，全片解码通过；其余口型未逐秒检查”。不写无法证明的“全链路无问题”。
