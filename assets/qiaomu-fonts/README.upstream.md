# 乔木封面字库 · Qiaomu Cover Fonts

[乔木封面设计（Qiaomu Cover Design）](https://github.com/joeseesun/qiaomu-cover-design) 的默认字库：一套随插件交付、装好就能用的封面字体。不追求数量，**中文 19 款、英文 15 款**，每一款都在封面上有明确的位置；全部 [SIL Open Font License 1.1](https://openfontlicense.org)，中文覆盖《通用规范汉字表》8105 字，共 30.7 MB。

The default font library of Qiaomu Cover Design: 34 curated open-licence fonts (19 Chinese, 15 Latin, 30.7 MB) that every cover can use out of the box, all under the SIL Open Font License 1.1.

## 先说结论

1. **不需要装进电脑系统。** 插件自己把字体载入画布，导出的图片里字已经是像素，换台电脑看也一样。
2. **门槛是“打包权”。** 只有 SIL OFL 开源字体允许随产品分发、并为了体积做子集化；大厂“免费商用”字体多数禁止修改或单独再分发，不能放进默认包。每一款都读过字体文件里的授权声明，并核对了保留字体名。
3. **第一次打开静默下载。** Obsidian 插件商店只安装 3 个文件，所以字库从这里分发：插件首次打开时在后台下载，默认模板要用的字优先，用到哪款就立刻下哪款，逐个校验 SHA-256，之后离线可用。
4. **模板只用字库里的字**，新用户第一次看到的就是设计稿原样。
5. **以“字体搭配”为单位排版。** 标题、正文、英文数字三个角色一次定好，AI 也按搭配来设计。好的排版靠层级和搭配，不靠字体多。

## 授权分级

“免费商用”只说明你能用它做设计，不代表能把字体文件随产品分发。

| 级别 | 代表字体 | 条款要点 | 在乔木封面设计里 |
|---|---|---|---|
| ✅ 可打包 | 本仓库全部 34 款 | SIL OFL 1.1：可随软件再分发，可子集化；保留字体名出现在字体名中的（抖音美好体）只提供原文件 | 默认字库 |
| ⚠️ 可打包但不能改 | 鸿蒙黑体、MiSans | 允许随软件捆绑，但禁止修改，只能放完整文件（每字重 6–8 MB），MiSans 要求软件内注明 | 字体库按需下载 |
| ⛔ 只能按需下载 | 阿里巴巴普惠体、阿里妈妈数黑体 / 方圆体 / 刀隶体、优设标题黑、钉钉进步体 | 禁止转换、拆分或单独再分发，或授权说明不清 | 用户一键从官方源下载，模板不依赖 |
| ⛔ 不建议 | 京华老宋体、汇文明朝体、个人免费类字体 | 授权来自作者声明或仅限个人，商用边界不清 | 字体库标注“商用请自行核对” |

## 没有收录的字体

| 字体 | 原因 |
|---|---|
| 霞鹜新晰黑 | 实为 IPA 授权，子集化后必须改名；原文件 7 MB |
| Playfair Display | 字体名为保留名，只能放未修改的可变字体，画布上无法稳定取到粗体 |
| 站酷小薇体、龙藏体、刘建毛草 | 笔画细或是草书，信息流缩略图里认不出 |
| 卢帅正锐黑体 | 缺少英文字形，标准字表覆盖 81% |
| Lobster、Pacifico、Bangers、Bungee、Righteous | 招牌字与漫画字的气质过时，容易显廉价 |
| Montserrat、Oswald、Abril Fatface、Lora、Dancing Script | 与 Inter、Anton、Fraunces 等重叠 |

以上字体仍可在乔木封面设计的字体库里按需下载。

## 处理方式

- 中文字体子集化为《通用规范汉字表》8105 字 + GB2312 + 常用标点，转为 WOFF2；英文字体保留 Latin Extended-A 与常用标点。原字体本身没有的字（如抖音美好体只含 GB2312 的 6763 字）显示时回退到系统字体。
- 每个字体的版权声明与完整 OFL 文本在 [`licenses/`](licenses/)。字体按 OFL 随软件分发，不单独出售。
- 生成脚本：[`scripts/build-font-library.py`](https://github.com/joeseesun/qiaomu-cover-design/blob/main/scripts/build-font-library.py)，会检查每款字体内嵌的授权与保留字体名，不符合的直接报错。
