# 可运行的开头与正文

四种机制共用白/近黑/紫色视觉和完整中文字体，不是每期强制使用的模板。

| 模式 | 查看导出 | 机制 |
|---|---|---|
| hero | [人物右侧](previews/hero.mp4) | 同一窗口输入、文件曲线进入、遮罩替换 |
| desktop | [Mac 相册](previews/desktop.mp4) | 桌面比较、Dock点击、相册、缩略图播放 |
| timeline | [时间线](previews/timeline.mp4) | 镜头回溯、文件进入轨道、成果聚焦 |
| body | [正文工作台](previews/body.mp4) | 输入、回应、文件交接、右侧预览 |

本次公共演示不使用任何个人肖像/音色。几何人物只是安全区占位，正式作品请用你提供的真实视频或改成无人版。壁纸和两张插画是原创SVG，不是苹果官方壁纸、真实用户成果或真实产品录屏。

项目底座：`index.html`、`studio.css`、`studio.js`、`project.json`、`fonts/`、`art/`。`new_project.py`会复制它们；没有作者机器路径。修改配置后用技能包的 `render_portable.py` 渲染；也可 HTTP 本地打开自动循环预览，不能直接file://读取JSON。

`media`为相对路径图片/视频，真实视频按1×采样。`presenter`为自己的人物原片；`audio`可指定单独口播，没有则尝试人物源音轨。`captions`填真实时间对齐的`start/end/text`数组，输出时同时写SRT；脚本不会凭空推测字幕时间。`safeRight`、`circle`按新源片调整。源片短于项目时画面最后一帧会保持，不能用于掩盖未准备的完整人物素材。渲染前核对所有时长。

`heroHandoff`启用开头尾部向左下圆窗的交接；`presenterCrop`是以1920×1080归一化源画面表示的正方形取景框，要先按脸/头肩实测，不能照搬默认。`sourceOffset`让人物视频与其音轨从同一个源时间开始，单独的`audio`默认已对齐本段0秒。正文模式使用相同裁切框可以保持衔接；非16:9源片应先合理适配，不拉伸人脸。

时间轴在JS内，默认10秒是演示长度。脚本不会自动把长口播合理剪成10秒：代理必须改实际语义节奏，完整视频按段编排。本工具不会自动克隆声音或生成数字人。
