# 参考片竖屏模板

在口播动作库首页选“参考片竖屏模板”，按片名、原句用途或编号查找。每条保留参考片、源内起止秒数、可编辑图层和本期素材位置。原片对照表列出 Skill 当前登记的参考片，以及每部片实际转进这个目录的镜头。一个模板可以借鉴多部片，按片名筛选时会交叉出现。

## 取一个镜头

1. 点卡片，拖动模板时间条，看主体如何出现、动作由什么触发，以及结果停在哪里。点“播放原片这一段”，可以用原片时间核对那次变化。
2. 展开“换成本期内容试播”，修改标题和三句字幕。“落点”是三句在镜头总时长里的比例。在完整参数的 parts 中改组件文字、项目或定位坐标；在 keyframes 中改各拍实际显示的值，例如让剩余额度从 8 变成 5 再到 0。素材栏会列出本镜头使用的图片或视频槽。
3. 选用编号后，剪辑窗口可用 `direct -- options` 或库内 `入库.py take` 取完整实现。离线镜头文件夹包含可播放的网页、`绑定.js` 和原片时码。使用 `render` 导出 9∶16 画面。手动导出的镜头另配本期原声。

## 来源

Fred 专项镜头使用定稿组件库内 20 个带原片时码的组件。每个组件有自己的图层和状态，例如定位引线、操作聚光框、容量线、原声剪选和终端回执。组件样片中的月面照片、压缩副本与操作截图沿用定稿 UI 的本地 NASA／Squoosh 材料。作品示例中的《神奈川冲浪里》沿用原动作库的馆藏素材及出处。

秋芝、Fred、阿闰的逐段镜头对应 Skill 的 `references/source-study-methods.json`，阿闰横评还对应 `references/evidence/arun-membership-study/reproduction.json` 的具体章节。手绘、实物交接、作品、界面及其他参考片对应影片对照表中各自的来源记录。画面的定稿字体、边框、颜色与字幕继承同一套 UI，源片时钟和剪辑模板时钟各自独立。示例里的字幕和数据用于预览，制作时填写本期内容。

这台电脑上有原片的条目提供对照播放。部分实拍和手绘镜头在个人目录里还带低分辨率的动作预览。正式制作可换成本期原素材，导出使用替换视频的原始帧。随包版本保存可编辑图层、时码与素材槽，个人原片仍由持有人提供。

## 随剪辑更新

已有同一镜头时复用原编号。遇到新的镜头结构，把对应参考片、有效源内区间、起态、口播触发、结果、与下一镜如何连接和可替换图层一起登记。打开成品尺寸试放，再计入可选镜头。单独改变颜色、字幕或产品名沿用原编号。

剪辑工程沿用已有的 motion-additions 入口。新的 9∶16 成套镜头可以在 motion.json 加入 adaptation 值 portrait，以及 references 数组。例如 #M193 的原片记录为 [{"video":"fred-weekly","start":33,"end":39}]。请按所用片段填写真实秒数。未登记的片名还可以一并填写 sourceFilms，含 id、name、duration 和 evidence。已入库镜头补充其他参考片时，用 reuseId 加 references 即可沿用原号。续剪时会把来源写回同一个目录和原片对照表。
