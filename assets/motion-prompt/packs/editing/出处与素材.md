# 本机动作与素材来源

本批 M001–M145 来自本机 ui-motion-fusion 的 `assets/rebuilt-library/execution.json` 及其指向的逐镜场景。每条在目录的 `sourceFile`、`sourceKey` 和 `sourceHash` 保留原始位置、标识与文件摘要。对应的可编辑镜头程序在 `programs/M编号.json`。画面沿用项目中根据连续参考拆好的运动路径、镜头时间和物件关系，按定稿 UI 使用颜色及边框。

M146–M192 取自同一 Skill 的 `assets/semantic-motion/manifest.json`、`semantic-motion.js` 与 `demo-fixtures.js`，包含 32 个组件动作和 15 个组合。目录里的 O、R 标识对应原机制。可将同一动作连接到本期的 DOM 或 SVG 元素。

示例素材按需嵌入 `materials.js` 以便离线预览。流程、交接和拆分示意来自镜头工程自带的 SVG。界面示例包括用同一张图操作 Squoosh 的本机真实截屏。地出摄影为 NASA / Bill Anders，人物示例使用本机制作库保存的比尔·安德斯照片。木版画来自大都会艺术博物馆公开馆藏。项目实拍和实测读数可在同名素材槽中替换。[Squoosh](https://squoosh.app/) · [NASA《Earthrise》](https://science.nasa.gov/resource/apollo-8s-iconic-earthrise/) · [葛饰北斋《神奈川冲浪里》](https://www.metmuseum.org/art/collection/search/45434)
