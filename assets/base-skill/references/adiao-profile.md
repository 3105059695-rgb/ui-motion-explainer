# 阿刁专属入口

本文件只负责路由，不再保存一份会过时的阿刁规范。仅用户明确制作阿刁系列或使用本窗口阿刁风格时应用；其他账号继续使用本技能通用规则。

- UI、字体、人物构图：[唯一阿刁视觉规范](../../adiao-workflow/references/ui-adiao.md)。
- 口播到素材、开头到正文：[阿刁后期流程](../../adiao-workflow/references/post-production.md)。
- 根据材料选择不同特效：[阿刁动效配方](../../adiao-workflow/references/motion-recipes.md)。具体实现仍从本技能动效库按需读取。
- 哪些获认可、哪些被否定：[历史证据](../../adiao-workflow/references/history.md)。

阿刁专属规则覆盖通用默认：纯口播，不继承历史BGM/SFX；开头大画面人物，正文左下胸像圆圈；真实材料优先，示意明确标注。用户已同意 Avatar III 生成后自动裁圈，不再要求原生圆形模板。确认比例由 adiao-workflow/defaults.json 维护。

字体、颜色和小窗数值仅在对应主规范维护。全流程从 [adiao-workflow](../../adiao-workflow/SKILL.md) 进入；已有口播和人物时直接进入后期，不重复生成。


## 2026-09-25 可移植后期补充

新制作可同时读取 [独立制作入口](portable-production.md)、[近期构图与动效](series-style.md) 和 [相册/右侧/正文配方](editing-recipes.md)。它们不依赖账号接入。当前项目的明确布局和声音要求优先：已要求保留BGM就保留；小圆窗按当期已确认尺寸，不能自动恢复旧400px。仅更新公共方法，不改阿刁音色、人物服务和密钥。
