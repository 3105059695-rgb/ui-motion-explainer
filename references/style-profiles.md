# 参考画风与本期素材

本文件只维护参考用途、素材身份与局部覆盖边界。当前 UI、AE 感、开头与禁忌统一读[审美偏好](aesthetic-preferences.md)，不要从旧账号档案推导另一套默认。

## Fred Talk 默认与效果库的分工

用户最新明确[“喜欢的视频风格就是 Fred Talk 的风格”](evidence/fred-default-correction-20261020.json)。整体视觉与剪辑语言跨窗口沿用；效果库提供实现，选用时保持这一方向。其他库可以贡献适用的结构与动作，但不能借选库重新决定审美；源码存在也不等于该条目已获认可。

普通新稿不从目录名或旧 `profile` 换肤。Fred Talk 默认不等于固定原片的人物、对象、镜头顺序、时长或把“黑紫”当全部风格。原工程续作保留已确认范围；用户本期明确改风格才覆盖对应范围。此前[逐图解释](evidence/library-entry-correction-20261020.json)中的取消 Fred 默认结论已被最新原话纠正，其原始记录仅作历史。

## AIGC 画风已有明确参考

[女孩样片与场景例图](../assets/approved-girl-sample/README.md)保留为柔和手绘画风参考，供制作同类画风的新图片与视频；这项选择不扩大为该片 UI 的当前认可。每期按句意新设计人物、场景、道具和动作，不把参考图库当成固定素材菜单。

本期明确的画风或工程已选 `aigc.style_set_id` 优先；无其他选择时使用注册的统一 AIGC 画风参考。摄影等本期未注册方向继续使用已有 `aigc.direction_override`，字段见[计划接口](director-plan-contract.md)。画风、素材身份和 UI 设计互不冒充。

## 本期身份与历史兼容

数字人视频、原声、字幕及当前明确固定 IP 保留在本期工程，不因账号视觉路由取消而丢失或被女孩替换。生成新角色不自动继承参考图人物；明确固定 IP 的连续镜头保持身份。

`references/profiles/`、本机 `registry.local.json`、原片和原始认可记录保留供历史查询。旧 `--profile` 和工程账号字段不再给普通新制作指定 UI 外观。`styles list` 可查旧资料，`direct prepare` 的正常制作上下文使用效果库。

历史材料的认可日期与范围按[历史](history.md)查证，不将安装、接线或入口整理视为新成片认可。
