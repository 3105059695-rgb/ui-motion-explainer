# 口播驱动扩展 · X09–X20

X09–X20 是 12 个原创扩展，与三条参考中观察到的 O01–O33 区分。完整库包含 **33 个观察动作 + 20 个扩展**（X01–X20）。用户要更多口播特效，或文案包含追问、因果、纠错、类比、步骤和总结时，按这里的语义选择动作；不靠匹配某个词机械添加特效。

## 示例入口

[72 秒示范](../assets/narration-demos/preview.mp4) · [逐项预览与工程说明](../assets/narration-demos/README.md) · [可编辑 HTML](../assets/narration-demos/index.html)

示范每段 6 秒用于比较动作。新片按真实口播调整时长，不必沿用示范内容或遍历全部效果。

## 动作选择

| 编号 / 名称 | 适合讲什么 | 动作配方 | 使用边界 |
|---|---|---|---|
| X09 重音接力 | 一句里的两三项关键点 | 先保留完整句 → 当前关键词放大/紫色强调 → 上一个归位 → 完整句停留 | 强调短语，避免每个字都跳动；主次要清楚 |
| X10 追问递进 | 从表面问题追到真正需求 | 第一层建立 → 缩成已知条件 → 第二层追问 → 最深层问题接管中心 | 问题要有递进关系，不能只是三个无关问号 |
| X11 因果传导 | 原因如何一步步导致结果 | 原因建立 → 单个焦点沿连线推进 → 中间状态改变 → 结果最后点亮 | 有因果依据才画因果；仅相关时改用并列结构 |
| X12 误区纠正 | 纠正常见说法，给出替代方法 | 疑问形式呈现旧说法 → 划去错误关系 → 在同一位置建立准确说法 | 不故意编造误解，不用羞辱性的动效标记 |
| X13 句子拆步骤 | 将口头说明转成行动清单 | 原句完整出现 → 原短语逐一移动 → 对齐编号槽 → 完整三步留读 | 保持文字与对象身份，不能三张新卡覆盖后就称为拆解 |
| X14 层层剖开 | 解释概念的内部组成 | 整体外壳 → 内部层错位展开 → 当前层拉开 → 回看整体关系 | 层应代表结构组成；先后流程优先用步骤/时间线 |
| X15 类比变形 | 用熟悉物件理解抽象对象 | 文档 → 同色接力棒 → 跨过交接点 → 下一人的文档 | 类比只表达相关属性，不把比喻当事实证明 |
| X16 数值尺量 | 数量、比例、步骤变化 | 可数单位展开 → 括尺标原值 → 单位收起 → 括尺回缩标新值 | 数据要真实或明确标示为例子；单位与标签必须一致 |
| X17 时间折叠 | 现在做什么、哪些按需处理 | 当前节点保留 → 后续流程折成分组 → 保留数量/名称 → 按需再展开 | 折叠表示暂不展开，不等于这些工作消失或已经完成 |
| X18 证据落点 | 让结论可追溯到原文 | 结论脚注出现 → 连接到文档 → 定位一句 → 只高亮对应原文 | 来源内容与结论必须一致，不能伪造出处或借高亮误导 |
| X19 首尾回扣 | 讲完例子后回到开头问题 | 问题建立 → 收为书签 → 中段例子 → 书签拉回 → 回答原问题 | 整段保留同一问题标识，避免结尾偷换问题 |
| X20 结论拼句 | 从多个要点得到一句总结 | 关键词分散建立 → 移向句子位置 → 连接成完整观点 → 完整结论留读 | 新句要忠实概括前面内容，不凭空追加结论 |

## 以声音为时间依据

本示例每段含三句配音，[实际时间表](../assets/narration-demos/assets/narration-timing.json) 记录各句的全局起止秒。工程用 `at(id, 0/1/2)` 在对应句开始时触发主动作。

配音为 **本地合成演示配音**，使用 Windows 标准中文声 Microsoft Kangkang，未克隆参考作者声音；详见 [配音说明](../assets/narration-demos/assets/narration-info.json)。

- 句子起点只是初始落点。新口播如果把关键词放在句中，应进一步对齐到那个词；替换配音后重新测量音频，同时更新动作和字幕。
- 入场通常 0.35–0.55 秒；变化最迟应在该段结束前留出可读状态。
- 主体画面提炼结构，字幕承接口播；不要把同一段长文字同时铺满两处。
- 重要结论宁可延长停留，不靠无限加快配音来挤进动画。

## 组合例子

**原理讲解**：X10 追问 → X11 因果 → X14 结构剖开 → X20 结论拼句。

**操作教学**：X13 拆步骤 → 原有 O30 真实录屏聚焦 → X17 按需折叠 → X19 回答最初问题。

**观点说明**：X12 误区纠正 → X15 类比 → X18 证据落点 → X19 首尾回扣。

这组 72 秒样片是逐项演示合集。实际成片按内容选择所需动作，不要求每条视频都放入这 12 种。
