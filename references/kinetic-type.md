# 动态文字与声音节拍

第三层「可用效果库」的动态排版与声音事件模块；制作钩子、概念转换、步骤标题、关键结果和片尾时读取。选型见 [效果总目录](library.md)。文字与操作共享同一条叙事，不将整段讲解改成独立文字卡轮播。

## 主题与范围

主题与规则优先级统一按 [风格档案](style-profiles.md)。本模块只规定文字的层级与运动方式，不设阿刁或其他账号的全局配色。

用户点名「苹果风」时，取克制留白、结实排版、精准节拍和连续对象交接，不自动改用蓝色或固定为 30 秒。继续一个已确认的苹果风项目时，该工程已确认的配色、画幅、帧率、时长和声音设置优先。

母带、时长与制作范围统一按 [制作流程](workflow.md)；人物位置、音色和已有声音设置从当前工程与账号接续。

## 先写认知任务

先完成 [语义规划](script-visual-planning.md)，再用下表把已确定的认知任务转成文字动作。

| 认知任务 | 文字与 UI 的配合 |
| --- | --- |
| 提出问题 | 一个短问题进入，随后成为搜索框或任务标题 |
| 指出错误 | 原界面停在错误位置，关键词定位原因，不另开无关警告卡 |
| 完成翻转 | 保留同一词或对象，通过拆分、换序、变形引出新含义 |
| 解释方法 | 标题交给真实操作，步骤词跟随相应状态变化 |
| 证明结果 | 从产物中抽出关键数字或结论，仍能看懂来源 |
| 收束价值 | 明确交付物或下一步，把前文核心对象收为片尾 |

每镜只承担一个主要认知任务。主标题给结论，辅助文字补条件和证据；口播完整内容进入音轨与字幕，不全部铺满画面。

## 字体与版式

- 正文、字幕和操作信息优先清楚易读；标题和重音词可从[乔木字库与花字](qiaomu-typography.md)选择符合内容气质的字体搭配。已确认工程保持其字体设置，局部花字不接管整套字形。
- 用字号、字重、疏密、位置和裁切建立层级；避免所有文字同尺寸同字重。
- 超大字可出画形成构图，但关键结论应有完整可读状态；不要裁掉必须理解的字。
- 小字优先正常字重，按最终观看尺寸判断清晰度，不能只看缩小拼图。
- 强调色只落在当前重音、状态或关键节点；按所选主题的明暗关系建立主体层级。
- 标题、辅助文字、字幕与来源分区，移动路线也不能穿过人物和关键 UI。
- 一行文字拆分后，保留统一基线和合理间距；重组结束时恢复自然阅读顺序。

## 动效的选择与连接

优先采用这些能解释内容的动作：

- **遮罩揭示**：从相关窗口、输入区或对象边缘露出文字，交代归属。
- **拆词重组**：在概念翻转或步骤拆分时，让原词连续成为下一结构。
- **重音落位**：重音词短促到位，其他文字保持稳定，结束后留出阅读。
- **镜头推拉**：围绕关键词或操作区域推进，随后回到完整上下文。
- **字形与 UI 交接**：标题缩为窗口标签，结果数字从表格原位放大，流程词成为节点。
- **景深与透视**：只用于进入和焦点转移，读字时回到清晰、可读的平面。

每次强调应有起因。优先增加共享对象、镜头路线和字形变化，不堆随机飞字、持续抖动、过量回弹、无信息粒子或每镜一个模板转场。

光标只在真实操作或清楚的示意动作中出现；文字包装不需要漂浮指示球持续抢夺视线。线条仅表达关系、进度或路径。

参考中的重音逐次落位、标题缩为章节标签、原容器揭开下一场、共享底座收成结论，见[本地配方 R01/R02/R05/R16](local-video-design-distillation.md)。触发点取当前口播，旧内容与新内容分窗交接；参数是重建起点，未恢复作者源码。

## 声音与视觉事件

有口播时先确定词义重音、停顿和结果落点；有音乐时再观察实际节拍，不把每句话都强塞到鼓点。

1. 标记口播重音与关键操作，再标记音乐强拍、转折和结束点。
2. 把强拍分配给文字落位、强调色出现、镜头到位或一次场景交接；一拍不同时触发所有层。
3. 入场可以短促，正文阅读保持稳定；没有音乐时依靠语义停顿和操作反馈组织节奏。
4. 音效对应点击、展开、确认等实际事件，强度服从人声；不为每个字配冲击声。
5. 配乐给口播让位，转折可保留动态起伏，片尾自然淡出；不凭视觉时间线声称音频已混入。

使用 HyperFrames 时接入真实音频轨、预加载和明确音量／音量自动化；仅设置 GSAP 对象的 `volume` 不代表已接入声音。其他引擎也应检查最终文件的真实音轨。

新音源和原声的使用范围按 [制作流程](workflow.md)；用户未要求声音的新动效示范可以无声，但需明确说明。

## 本模块的检查重点

- 文字与 UI 的交接有可追踪的共同对象，概念变化能从画面看懂。
- 每个知识点都有完整阅读窗口；强卡点不压缩必要信息的阅读时间。
- 按最终尺寸查看重音、辅助文字与字幕，检查裁切、遮挡和字形边缘。
- 实际播放检查文字落位、声音事件和口播同步；静态帧不能证明节奏自然。
- 声音验证与实际试听范围按 [制作流程](workflow.md) 记录，不由静态帧推断听感。
