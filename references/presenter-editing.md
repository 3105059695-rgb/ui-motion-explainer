# 人物讲解、真实素材与语义剪辑

第三层「可用效果库」的人物与素材合成模块；当前段落包含人物、实拍、B-roll 或漫画时读取。选型见 [效果总目录](library.md)，外观与开头继承[当前审美](aesthetic-preferences.md)，人物身份与历史范围见[参考使用](style-profiles.md)；不在本页另设身份、固定尺寸或生成服务。

## 接入现有母带

先按 [制作流程](workflow.md) 锁定母带、源片覆盖和时间映射。人物模块读取该映射，不另建声音或素材时钟；具体后端采样方式见 [引擎合同](engine-routing.md)。

## 按口播含义安排画面

先按 [口播理解与素材选择](script-visual-planning.md) 与 [本用户 B-roll 偏好](broll-preferences.md) 决定保留人物还是插入材料。本页只组织已选画面的合成与接续；需要最终动漫表演时接 [动漫视频生成](anime-video-generation.md)，漫画分镜与动漫视频的适用条件由该模块和用户偏好管理。

同一导演计划沿用素材、事件和时间记录，分清两项：**素材怎么剪**（源内入出点、关键区域、全貌与近景、切点、结果停留），**UI 补充什么**（标注、聚焦、状态变化或关系）。源码的卡片入场不能替代材料里该看的细节与过程。实际字段与 Canvas 接口见[计划合同](director-plan-contract.md)。

## 围绕素材组织观看

| 素材剪法 | 观众应该新增看懂什么 |
| --- | --- |
| 全貌 → 局部推近／重新裁切 | 先辨认对象，再看清当前按钮、字段、错误点、接触或结果细节；焦点必须位于实际材料内 |
| 局部 → 返回全貌 | 看清细节属于哪里，或发现局部变化怎样影响整体；保留原位置线索 |
| 中景 → 接触近景 → 结果 | 真实操作或 AIGC 先交代双方和对象，再证明动作发生，最后展示后果；剪掉无效等待而非关键动作 |
| 同尺度并置对比 | 同一条件下的前后状态或两种结果可直接比较，不把无关画面拼一起凑内容 |
| 人物 → 材料 → 返回人物 | 原声继续推进，材料展示事实、过程或证据，人物承接判断；不重复播放原声 |
| 对象／动作匹配切换 | 前后镜属于同一事件时保留物件、方向或动作线索；不要求每次强制接力 |

按口播确定“何处聚焦、何处展示结果、何处返回”，用有效素材时间与取景区域驱动。`viewport-focus`、`focus-mask`、`match-handoff`、`compare`／`comparison-reflow`、X03、X07、X22、F01、F08、F-M03、F-M10 等是可选的不同宿主实现；先查接口再接本期素材，不把名称当调用证据。结果停留按阅读需求安排，不强制每段用完这些手法。

| 语义 | 适合的主要画面 | 推进方式 |
| --- | --- | --- |
| 产品是什么、从哪里进入 | 官方名称、真实 Logo、官网或应用入口 | 从可辨认身份定位到具体入口 |
| 怎么操作 | 真实界面与有依据的录屏；截图只证明实际可见状态 | 定位→点击→完整选项→输入→执行→结果 |
| 文件、任务或结果怎样流转 | 真实材料与 UI 对象 | 同一对象跨窗口保留身份、位置或方向线索 |
| 为什么会卡住、如何解决 | 文档、对照、漫画情境 | 问题→关键动作→反馈→理解 |
| 工作、客户、生活中的具体场景 | 与句子相关的 B-roll | 展示具体行为，再接回 UI 中对应的对象或结果 |
| 困惑、惊讶、完成 | 短暂表情或角色反应 | 由语义触发，避开主要阅读区域 |

材料接力与阅读节奏见 [动效编排](motion-direction.md)；不另设固定换镜间隔。

## 人物与 UI 的构图

- 先检查人物整段的脸、头发、手、前臂和主字幕范围，再决定图形工作区。面板、阴影及入场路径都要避让，不能只按首帧空白摆放。
- 有开头人物原片时保留完整原构图与全屏场景，材料在实测空白处展开，移动过程也避开人；无人物原片才按内容设计全屏材料或 UI 开头。可识别对象尽早说明主题，动作是否交接按事件需要选择。
- 不为了塞更多界面把人物和材料一起缩到看不清；先减少并列信息，再调整景别。
- 大人物转入画中画时保持源时钟连续，让位置、比例或遮罩变化可追踪。
- 圆窗、横窗、全屏材料都按当前内容选择；圆窗不是所有账号默认，尺寸也不是历史常量。
- 主阅读中心保持一个；人物自然口播不能被点击光圈、浮层或装饰反复遮挡。
- 透视只服务短暂空间交接，正文读字回正；检查遮罩白边、被裁阴影和界面边缘。
- 修订开头构图后，正文承接的共享对象从同一位置、尺寸与状态起步；同时检查交界前、交界点与交界后。

## 素材真实性与清晰度

素材来源记录、实操证据、真实／示意标注及播放速度统一按 [制作流程](workflow.md)。外层包装遵循[当前审美](aesthetic-preferences.md)；真实品牌和系统界面可保留原色，也可按准确内容重绘，不以统一紫色覆盖材料。
材料必须足够大且清晰；低清截图放大或套精致外框仍是低清素材。
优先重新采集高分辨率材料，或推近关键区域并保留必要上下文。

## B-roll、漫画与表情包

选材的句意、情绪和适用条件集中在 [用户 B-roll 偏好](broll-preferences.md)。合成时保留漫画的全景、细节、反应和结果关系，可以多镜推进，不规定固定四格。
从漫画或实物接回 UI 时，保持解释内容有联系；可用同一文件、任务、动作或结果承接，也可直接切换，不强制每镜对象接力。
表情反应进入次要阅读区，不占据关键按钮或字幕；回到主画面时交还阅读中心。

## 账号接续与历史来源

阿刁任务从 [阿刁档案](profiles/adiao.md)、方木任务从 [方木档案](profiles/fangmu.md) 读取人物、原声、原素材与历史范围，不能据此切换当前默认外观；不将任一账号的私人身份、音色、人物 ID 或构图复制给其他账号。

阿刁的历史证据仍保留：[早期确认规则](../../adiao-series-guide/references/approved-style-20261004.md)、[项目指针](../../adiao-series-guide/references/latest-project.json)、[构图与材料细则](../../adiao-ui-editing/references/creative-direction.md)。它们用于查来源；本期配置由当前档案和已确认工程确定，旧指针先核实实际文件与日期。确需生成该账号声音或人物时，再按档案接 [账号生产链](../../adiao-workflow/SKILL.md)，不并行加载旧编辑入口的通用流程。

## 本模块的检查重点

检查人物整段安全区、交接前中后的几何连续、嘴型与字幕对应、双脸、遮罩白边、阴影裁切和素材清晰度。声音事件见 [动态文字与声音节拍](kinetic-type.md)，导出、试听范围、确认状态与交付统一按 [制作流程](workflow.md)。
