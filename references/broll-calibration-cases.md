- 题目与选项来自原问卷；答案只采用用户在聊天中粘贴的答案，不采用测试导出或自动填入的答案。

- 后续改进依实际视频和用户反馈进行；技术检查通过、文案分镜认可、实际画面认可分别登记。

## 先理解讲解，再选表达方式

用户明确要求：以后剪辑先分析口播的句意、上下文和人物情绪，再决定哪些地方放什么 B-roll、怎么动。句子在整段中承担的任务、语气与停顿也要保留；人物继续讲、自然停顿、无需插入素材，都是有效选择。

参考判断路径：这句要观众理解/感受什么 → 本句与前后文怎样连接 → 人物此刻的情绪和作用 → 留人物还是切 B-roll → 用哪个对象表达 → 对象怎样发生变化 → 如何接到下一句。现有素材必须先核对；拟真重绘不得冒充真实产品操作，概念衔接标示意。

## 漫画的明确补充定义

用户原话：**“漫画代替aigc是一张图多个动作，然后垫着来出那种几s多图显示那种动漫的效果来的。”**

按此准备一份包含同角色多个连续动作的漫画素材，再拆分/裁切为动作图或分镜，通过几秒内逐个切换、叠放、局部推进形成动漫式表演。人物、场景与动作需要接续；单张不变姿势加推拉，不能当成已经满足这项要求。动作数量、每格时长与绘画风格仍依句子和样片调整。

已答情绪案例：攥手→松拳→呼气（Q31）；自信→皱眉→歪头→揉脸（Q32）；庆祝→读消息僵住→手放回桌上（Q33）；读夸奖→抿嘴笑→抱手机→再看（Q35）；手指/眼神/时钟加速切换→提交停住（Q36）；欣赏别人→看自己→缩回椅子关电脑（Q37）；捂作品→掀一角→推出草稿坐直（Q38）；忍耐→攥鼠标→重按→后靠（Q39）；勾选→放笔→伸腰→轻快离开（Q40）。

## 明确的修正与冲突处理

1. **反复改答案：采用后续 Q16 作为该语境当前优先方案。** 早期 A2 提出“答案逐版出现＋特效/音效”；之后 Q16 明确选择“固定一份答案，只替换修改的句子、短暂显色，版本记录增加”。不要继续自动堆答案、每版放音效，也不要删除早期方案：以后强调版本数量或有新要求时仍可重新选择。
2. **连续动作不等于禁止切镜。** 同对象交接与真实过程很重要；Q47 的直接切回、Q50 的重放同样是直接选择。以能否帮助理解为准。
3. **名词没有统一出场模板。** WorkBuddy 启动、Skill 用途先给效果、可修改项目用结构示意、参考网站先看作品，分别对应不同的句子任务。
4. **“正常”保留为有效答案。** 首轮 F4、A6 等说明用户不要求句句复杂动画；人物表演、停顿和简洁拆分也能完成表达。

## 后续实际视频如何补充

为每条新反馈保留：原口播与前后文、人物语气/情绪、实际视频版本与时间码、原先判断、用户具体反馈、调整后的做法、适用条件和验证状态。一次明确反馈优先更新对应语境，不立即扩展成所有视频的禁令。

状态分开登记：用户句子标注 / 问卷选择 / 归纳规则 / 实际样片已做 / 技术检查 / 用户对该版本认可。未做的视频不写成样片通过；未选题、不确定画风与强度继续保留未知。用没标注过的新句子做实际样片，检查是否能迁移，而不只复述本页案例。
