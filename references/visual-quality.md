# 统一视觉与质感

第三层「可用效果库」的通用质感基线；制作文字、图形、人物合成、截图或设备效果时读取。外观选择与模式优先级统一见 [账号风格](style-profiles.md)，阶段及验收见 [制作流程](workflow.md)。选择 Remotion 后端本身不等于选择暖白或糖果配色。

统一质感覆盖文字、图形、转场、镜头、人物与实拍合成，也覆盖截图和设备界面。下面的软件与手机细节只在对应画面出现时适用；完整剪辑可以由人物、图形或动态文字主导。

## 用实际样片校准

优先查看当前账号已认可的实际片段，校准字重、层次、材质和运动，同时理解信息与情绪怎样起伏、一个对象如何交给下一个对象。需要基础实现时，可查同机 `ui-motion-explainer` 或包内 `assets/base-skill` 及其 `assets/approved-demo/contact-sheet.jpg`／`preview.mp4`、`references/style-system.md`；它们提供实现能力，不预定本期构图和镜头路线。

从样片提炼“为什么有效”：实物细节是否支撑内容，运动是否引导阅读，停顿是否给情绪或理解留出空间。沿用的是这些判断与账号外观，不把具体道具、四卡构图、转场顺序或时长变成后续视频的固定模板。
认可样片是审美依据，不要求新片长得一模一样；被否定的版本用来识别假、廉价、单调的具体成因。新题材可以采用另一种构图、素材和动作，既有代码仅用于实现已经选定的表达。
按[本次用户反馈](evidence/creative-judgment-feedback-20261014.json)理解“创造同样的感觉”；忠实复刻仍保留原片约束，继续工程也不因此获得重剪已认可片段的授权。

黑白淡紫的具体值保存在[阿刁档案](profiles/adiao.md)。其他账号遵循自己的已确认外观；模板 tokens 或历史 CSS 不能悄悄接管本期主题。真实产品素材保留自身颜色。颜色比例根据人物场景和信息层级安排，不把配色名解释成必须铺满某种颜色。

自然材质、可信行为和相关生活细节能增强真实感；摄影背景本身不能保证真实，泛办公室场景也不能代替选材。UI 应与素材中的内容、操作或证据发生关系；是否需要摄影、AIGC、复杂组件或纯人物，由本段表达决定。
网感通过熟悉的阅读逻辑、具体处境、重点出现的时机和疏密变化形成，不以热词、组件数量、特效密度或固定剪辑频率衡量。

## 从低保真到可信界面

- 使用符合主题的软件结构：窗口、侧栏、当前路径、工具栏、主内容、输入区和结果容器各有职责。手机保留对应系统的状态栏、机身比例、应用结构、键盘和手势条。标题、段落、图标都使用实际内容。
- 字号、字重、行高按阅读顺序分层；使用可随工程交付的中文字体。代码名和元信息降低权重，主要内容在导出尺寸下可读。长内容重新排版或局部聚焦，不挤成小字。
- 标题、重音词和数字可按内容选用[乔木字库与花字](qiaomu-typography.md)中的本地搭配；花字服务强调，正文保留清晰阅读，真实应用内的字体仍以对应界面为准。
- 边距以共同基线和视觉对齐确定。嵌套圆角协调，按钮、输入框和图标描边一致；光学位置优先于机械居中。图标用清晰的 SVG／真实资产，避免混用风格和用方块假装应用图标。
- 顶栏／当前项／结果区通过主题中的结构色建立层级；亮色历史样例采用近黑结构与浅灰次级分区，深色或其他主题按当前档案适配。边框轻而清楚；阴影范围与距离对应对象位置，不靠大片发光。
- 先判断容器是否必要。大片空黑底在亮人物画面里会显得沉重；可直接利用原背景，用局部小浮层承载信息。删除底板、缩小有效面积与改善层次，比机械把黑底换白更能解决这类问题；深色场景仍可按需使用黑底。
- 截图与视频按最大显示尺寸选择源清晰度，保持等比。窗口变化优先调整遮罩和外部容器，正文避免非等比拉伸。导出为 1080p 不会恢复低清素材细节。

## 连续运动与注意力

同一对象持续：输入框提交后成为同一任务；文件到达新容器后展开对应内容；手机始终保留方向与位置线索。既有状态在过渡中让位，新状态从明确来源进入。

动作起步干脆、减速柔和；强调的变化幅度与语义重要性匹配。阅读阶段允许静止，需要引导时才轻推镜或局部高亮，字幕与重要句子保持稳定、清晰；不同时叠加多种循环效果。快速位移可用短运动模糊，清晰读字阶段关闭；弹跳和透视只在需要时使用。

镜头推近当前操作点，其他内容让出注意力；完成后回到总览或交给下一对象。一个镜头与一个窗口内层不要同时独立放大同一内容。不要把每句话都改成新标题卡，也不要只给静态截图缓慢放大就当作完整 UI 交互。

## 内部设计关口

先检查本段需要观众看清的状态：字体与素材是否清楚，明暗层级与材质是否协调，主要区域是否有与口播相关的实际内容；有操作过程时再检查前后状态与连接。不要强迫情绪或纯人物段凑齐“总览、操作、结果”。
观看一小段连续变化，对照认可样片的阅读负担、材质可信度、情绪起伏和衔接自然度；既检查“为什么这样呈现”，也检查中途是否出现重叠、空转或注意力跳失。关键帧好看不能代替连续观看。
实际导出后检查对应片段的节奏、可读性与合成；只查预览或解码成功不能宣称审美达标，未听审则不声称声画体验已通过。按发现的问题修正，不设强制评分、素材配额或新的独立审批。
这些是内部创作判断，样片阶段与交付验证仍统一按 [制作流程](workflow.md) 执行；风格已明确时由 Agent 完成判断，不让用户反复点名素材和效果。

用户说“质感差”时，结合连续画面定位素材与句意是否相关、生活细节是否可信、结构是否完整，以及字重间距、明暗对比、强调色、阴影和中间运动是否有效。仅换色、加模糊或堆组件不能修正表达问题。通用改进写入本规范，账号特有偏好写入对应档案。
