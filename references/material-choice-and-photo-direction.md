# 找本期素材与写实生图

单独交付配图时，按相关原句和上下文取材。剪视频时，通读全稿后用同一段原句并行选动作、找素材。两边共用可见目标，有原声时还共用时码和触发词。比如“放下笔去接电话”，就找能看见放笔和接听先后的实拍，同时查能引导观众跟住这只手的动作。多人取材时，把实际看过的片段、文件和选用理由登记在同一工程。

## 由剪辑者决定从哪里取

| 这句需要什么 | 去哪里取，取到什么算对 |
| --- | --- |
| 已有原声人物、同一文件或前段已建立的案例 | 先查项目与素材库。打开对应编号，核对当前有效区间能看见哪一下。原片表情、停顿或一个连续镜头已交代清楚时，沿用这一段。 |
| 点名人物、产品或版本，引用言论、事件或实际结果 | 用 Ego 查官网、发布者原帖、原访谈或演示。也可从 X、小红书、抖音、B站等找线索。看源页和实际片段，保存可剪的本地文件，记原始链接、作者、日期和已知使用范围。肖像支持认人，实际发言及上下文支持引语。 |
| 软件里从哪儿点、点后变成什么 | 若已有同版本、同任务、全过程清楚的演示，取有效区间。否则用实际产品和示例输入实录，录到动作前、真实触发、系统反馈和结果停稳，并看一遍。实物操作按同样原则拍。 |
| 普通生活瞬间、假设人物的处境、比喻中的场景 | 可以生成。剪辑者自己把这一帧写成拍摄指令，并保存实际使用的完整提示词。真实产品结果、实名人物原话或具体历史现场仍到原始来源取证。需要动作如何变化时，选择连续视频或有可辨顺序的状态组。 |
| 假设账号、抽象数量或机制需要准确文字 | 用定稿 UI 制作可编辑示意，把范围、数字、前后状态对准原句。可把同一张场景图放进缩略图。具体账号的作品数则需该账号在对应时间的真实记录。 |

## 生图前，把这一帧说给摄影师听

由 AI 根据本句填写。不同画面只保留真正有用的细节。

1. **拍哪个瞬间。** 写人正在做什么、作用于哪个具体物件、按下快门时动作到了哪里。例如手已握住相机握柄，机身仍落在包装托里。观众一眼能认出“拆箱”。
2. **东西靠什么支撑。** 写接触点、遮挡和视线。夹起食物时看筷尖是否夹住食物，相机搁在盒里时看托盘和机身是否接触。多余的人手、镜面和道具尽量不入镜。
3. **拍摄者站在哪里。** 写与现场相符的机位、景别和光源。比如朋友站在桌边从胸口高度略向下拍，左窗是主要光源，纸浆托、金属网和棉袖分别呈现各自的表面。保留情境原色，包装 UI 另行叠加。
4. **这张照片怎样剪。** 写主体在横竖屏里的位置、下一镜要接的物件、字幕要避开的脸或手。如果同一件东西要出现两次，优先沿用同一张图的局部；需要另拍时传同一参考，保持道具、光向和衣着。
5. **只写和本镜有关的排除项。** 例如普通公寓拆箱可排除商业展台布光和摆拍式指物。避免用“超写实、8K”、统一胶片颗粒、强虚化或满屋杂物代替对现场的描述。

可复用句式为“在【地点】，从【机位】拍到【主体对物件做的那个瞬间】。【接触、遮挡或重量】能看清。现场光来自【方向和光源】，【材质】在这个光下应有【可见表现】。用【画幅和取景】保住【关键细节】，为【字幕或下一镜】留出位置。”

## 写实配图怎样算合格

打开原图，先看是否拍对这句话，再看是否像现场能拍到的瞬间。按这张图最重要的细节判断，例如手是否确实握住物件、机身是否有支撑、光从哪里来、材质是否自然。关键部位明显失真就针对那一处修。**单独要图时，原图真实自然、贴合口播，即可交付图片文件。**

## 用进视频时怎么检查

模型结合前后句决定保留全景、聚焦细节还是切换素材。放回时间线后，以最终尺寸和正常速度看触发词、主体、字幕与转场。需要交代“拿起又放下”时，选能看出先后过程的材料。生成情境在库中记录为“情境示意”，可能被误认作真实案例时，在相应镜头注明。

## 入库与接镜

需要入库时，保留稳定 ID、实际文件、原句、可见用途、真实来源或完整生图指令。视频记**素材自身的有效入出点**。实际剪进镜头后，按每次使用登记**原声时钟的起止、触发词、动作编号和图层**，待用图片的镜头时码留空。一张图可在不同时间承担实景和同一作品的封面，两次使用共用一个 ID。缺材料时写明缺的具体变化，再选来源或调整表达。

跨期查库时，`prepare` 或 `resume` 返回的 `confirmed_workflow.material_library.indexes` 列出本机已登记的素材索引。先按对象、用途和可见细节检索这些索引，再打开文件核对。要把本期留给之后的窗口，在本机 `references/resources.local.json` 的 `files` 里追加 `"material-index:本期简称":{"path":"本期 materials-bindings.json 的绝对路径"}`。同一素材编号按所属索引区分。本机只登记路径，移交工程时连同素材文件和索引一起交付。

从项目运行 `materials record`、`check`、`export`，生成 `materials-bindings.json`。编号动作表单可用 `"assets":{"media1":{"material_id":"GEN-001"}}` 直接取用；把 `media1` 换成该动作实际提供的槽名。外部合成按同一索引绑定 ID，保留可编辑工程，再输出带原声的小样。把素材文件、索引和逐镜用法交给下一个窗口。[命令和记录字段见素材入库用法](../assets/material-sourcing/README.md)
