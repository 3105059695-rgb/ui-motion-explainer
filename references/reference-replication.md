## 先选复刻方式

模式和外观优先级统一按[当前审美](aesthetic-preferences.md)；明确“阿闰整片、当前 UI”时采用上面的指定组合，不继承原片配色。以下通用方式仅在用户明确选择其他复刻范围时使用。

- **严格逐帧复刻**：保留参考配色、字体、画幅、动作顺序、时长和镜头路线；差异逐项记录。
- **动作风格融合**：提取对象关系、动作、运镜和节奏，沿用当前账号／项目外观；替换内容后重排文字和阅读时间。
- 用户同时明确要求换品牌、素材或文案时，落实指定替换，并说明其对构图或时序的影响。
- 不从以前项目自动带入人像、音色、人物位置，也不把黑白紫强加给严格复刻。

## 得到足够的参考证据

1. 确认完整原片的画幅、时长、帧率和是否有音轨；海报、短预览和 prompt 不能代表完整运动。
2. 查看整段，再按时间码定位动作前、中、后及阅读停留。细微运动和快速切点需加密查看。
3. 记录对象大小、相对位置、屏幕占比、字体、字重、换行、镜头锚点、轨迹和减速方式。
4. 记录光标落点、触发时间、内容更新、遮罩区间及声音事件；不把变化量峰值直接解释成转场。
5. 不清楚的细节标为待确认，测量得到的估计参数注明是重建估计，不冒充作者原参数。

逐镜记录可写入 `shot-plan.json`：`start/end`、`subject_id`、`from/to`、`trigger`、`camera`、`content`、`audio_cue`、`reference_frames`。每段应能回答「谁发生了什么变化、由什么触发、镜头跟谁移动」。

## 对象与运动的重建方法

- 同一窗口、手机或文档保留稳定的对象身份；跨场景交接连续计算几何，避免消失后换一张相似卡片。
- 镜头围绕当前阅读中心推拉，光标、阴影和内容服从同一场景坐标系。
- 拖动时由光标轨迹决定对象位置；释放后的弹簧从释放位置连续衔接。
- 多次目标改变可叠加闭式弹簧响应；需要不同前后沿速度的形变，分别计算边缘延迟与刚度。
- 容器变形、旧内容退出、新内容进入分别设时间窗口，避免两套文字在形变中重叠。
- 快速运动时才用轻微模糊；停稳后清晰。玻璃折射、三维材质等需要匹配实现，不能以普通透明框替代后声称一致。
- 使用闭式函数、预计算路径或可寻址时间线；随机量固定种子，同一时刻得到同一状态。

具体对照方法见[本期计划与实际实现合同](director-plan-contract.md)。这些规则也适用于用户本地视频，不要求原片来自某个网站。

## 素材与声音

照片、真实界面、设备边框和图标决定质感。优先使用用户素材或当前任务可用的产品素材；原创占位只说明机制，不能当成原片级还原。

- 检查素材在最大推近时的有效像素和细节；导出分辨率不会补回低清截图的信息。
- 素材不可得时保留替换入口并说明影响，不用无关图片填补后宣称完整复刻。
- 从实际原音轨观察节拍、停顿和事件峰值；提示词写着某个 BPM 不证明成片正是该节拍。
- 声音复制权限与动效实现分开处理；使用当前任务允许的音源或自制声音。
- 无声导出只代表视觉版本，不能称为完整有声复刻。

## 按需使用案例和引擎

已有目录、源码和媒体的实际状态见[资源登记](resource-registry.json)。先检查当前文件，不把历史验证或源码数量当作现有可播放成片。

只读取当前案例及其相关资源，不自动恢复全站批量下载或渲染。查找、原片分析、创建与对照的真实命令见[当前引擎入口](engine-routing.md)；需要已有工程时使用其实际复制入口，在新工程内修改。

| 参考的主要机制 | 实现方向 |
| --- | --- |
| 窗口变形、菜单、滑块、光标、内容交接 | 确定性 HTML 或可寻址 GSAP |
| 真实应用组件、复杂排版与产品发布 | 读取获准的应用源码，按工程选 Remotion / HyperFrames |
| 手机、相机、真实三维光影或复杂玻璃 | Three.js / WebGL 或与参考匹配的专用实现 |
| 真人录屏和较长素材剪辑 | 时间线剪辑，保留源素材时序与真实操作速度 |

统一接口见 [引擎合同](engine-routing.md)，案例专用方法保留在 [实际场景模块](../assets/reference-films/arun-membership/README.md)。先复用兼容环境，缺失时仅安装当前工程所需依赖；不为统一入口降低效果。来源、许可证及固定版本见 [来源研究索引](source-study-sources.json)。

HTML 复刻工程通常使用 `ready()`、`seek(t)`、`duration`，可另设 `getState()`；进入导出模式后停用自动播放循环。统一导出入口应适配真实接口，不把其他项目的 `render(t, mediaTime)` 直接当作同一合同。

## 对照与状态

- 优先按相同绝对时间或对应音乐拍点比较；归一化时间接触表仅用于粗查，快速切镜可能错位。
- 对照开头、每次变化前中后、读字停留、结尾；比较对象几何、文字、镜头、运动、声音。
- `--check-repeat` 检查乱序跳转后同一时刻一致；`--check-seek` 还要求首尾一致，仅适合参考本身循环的工程。
- 工程状态保留原复刻工具的 `starter`、`implemented`、`technically-verified`、`reference-compared`、`user-approved`；按 [效果总目录](library.md) 的证据维度理解，不以解码通过代替相似度或用户认可。
- 通用交付与实际观看／试听记录按 [制作流程](workflow.md)；复刻任务另附对照结果和未还原差异，不能以下载的参考视频代替自己的渲染结果。
