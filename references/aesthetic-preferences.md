# 剪辑时沿用的审美

整体沿用 Fred Talk 用真实材料讲清口播、用动作引导注意的剪法。「十款 Agent」正文、Fred 三条原片及其他已认可参考的适用范围见[逐项记录](aesthetic-details.md)。具体 UI 采用用户本轮确认的组件库。

## 1. 统一视觉与用色

[基础样式](../assets/approved-ui/style.json)保存可直接读取的颜色、字体、线框与字幕数值。[组件目录](../assets/approved-ui/catalog.json)按用途列出 128 种组件和各自状态，20 种 Fred 演化组件另带示例口播、原片及起止秒数。[全部组件与状态图层](../assets/approved-ui/index.html) · [20 种 Fred 实样](../assets/approved-ui/fred-components.jpg) · [竖屏上屏对照](../assets/approved-ui/portrait-examples.jpg)

| 对象 | 定稿画法 |
| --- | --- |
| 字体与数字 | 全片共用 Noto Sans SC 可变字体。以 1080×1920 为参照，字重／字号依次为标题 800／88、正文 550／42、标签 700／38、字幕 700／60、数字 850／104、单位 700／40。 |
| 用色 | 白底 `#FFFFFF`，主字、外框及字幕底用近黑 `#0B0B0F`，说明字用灰 `#62616C`，深窗内沿用 `#393840`。浅紫 `#D6C2FF` 用作深底当前读数或重点标签底，浅紫标签配近黑字。照片、产品界面、品牌标识和实拍保留原色。 |
| 边框与标注 | 1080 像素短边下，窗口外沿 24 像素，卡片边和标注线 8 像素。窗口、卡片、字幕圆角分别为 32、24、10 像素。其他分辨率按短边等比换算。内容需要真实手机或软件窗口时，先用本期真实外形与界面定位。 |
| 竖屏与字幕 | 1080×1920 下左右各留 80 像素，内容宽 920 像素。字幕距底 250 像素，最多两行，左右内边距 21、上下 11、行间距 5 像素。按语意断句并在手机大小、正常速度下检查可读性与遮挡。 |

剪辑时先看原句，再选组件的用途和状态。例如“它只给了建议，还在等确认”可先展示建议内容，停在待确认状态。读数、文字和真实截图换成本期材料。需要学习动作时，再到[参考图集](../assets/reference-atlas/index.html)定位来源并查看连续片段。新片的选择原则与本机互动库入口见 [Skill 入口](../SKILL.md)。

## 2. 正文画面、AIGC 与取材

通读本期原稿。产品和操作优先用本期真实界面或录屏，先交代对象，再放大具体操作，保留看清结果的停顿。比较用同一标准，材料各有对应的出处。人物可全屏、同框、退场或返回。阿闰提供整片叙事与比较的做法，秋芝及问卷 D 提供柔和手绘、主体动作和结果的参考。角色、道具与场景跟随本稿，明确固定 IP 时沿用其身份。问卷 L/M/N/O 同时认可设计和动作，包装色沿用本期 A 配色。

## 3. 动作、开头、节奏与声音

开头保留人物完整原构图、手势、字幕和原声。按人物动作全过程量保护区；没有开场人物素材时可从全屏 UI 开始。先在实测空白区让本期材料错峰出现，必要时让素材全屏。用裁切、遮挡、聚焦、展开或返回帮助观众跟住变化，看清结果后再切。音乐有存在感，动作音效与节拍服务口播，原声始终清楚。已有明确的局部修改沿用当期范围。

## 4. 反馈与原片依据

实景做主画面时保留原色，让动作占主要面积，去掉资料编号、模板边框和栏目角标。按手机大小检查整段动作的活动范围。主画面有人脸时收起人物小窗。主画面没有脸且口播表情有用时，才把小窗放到主体和字幕以外。企业、项目、动作都有可核对的出处时才用现场画面作证。实景缺证据就留口播。

动效按原句里的关系编排。列举技术层级时，每说到一层才出现一层，说到重点后让焦点停在那一层。讲协作时要看得出谁向谁交付什么，以及接手后发生的变化。可执行例子见[逐镜验收](shot-acceptance.md)。

当前镜头用 `direct -- resume` 取回对应参考的动作与时间依据。指定复刻、用色冲突或需要原话时查[逐项依据、原片范围与对照](aesthetic-details.md)。
