> 2026-10-26 配色更新：用户看过三条 Fred 原视频取色对照后确认“对的，其实a是很好的，修改一下这个skill把”。当前主强调紫采用 A 色 `#D6C2FF`，替代旧默认 `#8750FF`；这是视频画面近似取样，不声称作者工程的原始色值。此前已接入的实际制作源码、质感与整个效果库继续保留。授权升级不等于未来成片已获认可。

2026-10-28 补充：用户要求按审阅意见强化“具体材料、实际过程和结果”；统一质感同时增加内容驱动的取景、明暗与场景颜色。下面原有颜色选择继续有效，不以单一紫色或固定容器代替丰富的画面内容。

本页是新窗口的审美入口。当前依据是 [2026-10-21 实际图片/视频问卷与后续纠正](evidence/aesthetic-interview-20261021.json)，与此前 Fred Talk 整体方向一起使用；新回答优先于旧问卷选项的笼统解释。原始回答保留，不把片段偏好变成所有题材的固定规则。

## 1. 统一视觉，开放整库动作

**整体采用用户确认的 Fred Talk 颜色关系与 UI 质感；素材库里的整套动作积累都保留为创作候选。** 颜色与质感主要依据用户提供的 Argon、AI 周报、JEV 三条原片的跨段落观察，不凭单张截图定义风格。用户明确说：“我觉得素材库里面的那些动作都是我很喜欢的，所以不要以偏概全的设置来”。

- 黑白灰建立有分量的明暗结构：正文反复出现明亮外背景，承载近黑窗口、白色实体卡与真实材料；章节、开头和全屏素材也可改变底色。不同表面要可分辨，不固定全片黑底或白底。
- 当前主强调紫为 **A 色 `#D6C2FF`（RGB 214, 194, 255）**，可在近黑窗口、胶囊等暗表面突出关键字、数字、进度和选中状态，不要求每个场景出现。浅紫实色按钮搭配近黑文字；白底小字和细线保持深色，或用深色承载面托住浅紫，避免浅紫小字直接压在白底上。对照中的 B 色未被指定为默认；按内容和对比安排用量，不把所有表面染成紫灰。复用历史源码时，所需的主强调紫使用当前选择，不回退旧 `#8750FF`。
- 质感由清楚的实体边缘、适合对象的圆角、柔和投影、局部厚度与遮挡共同构成。胶囊、资料卡、视频窗和手机框保留各自形态；不能只给统一矩形换色或加细边。
- 粗字、大数字、主体尺寸、留白与前后虚实共同组织重点。当前对象清晰，次要材料可暂时退后；构图、材质、景别和动作随内容变化，不固定左侧大标题、右侧大窗口或某条片的道具与秒点。
- 问卷的 A/B/L/M/N/O 等只是定位样本，不构成动作白名单。完整参考、连续段落或多个动作组合都可使用，以最后好看、讲得清楚为准。
- 把**动作、外观设计、配色**分别理解。L/M/N/O 的设计和动作都喜欢，按本节的 Fred 视觉关系适配；早先 M/O“只喜欢动作”的粗分类已被用户纠正。具体演示整体不喜欢，也不能推出同类动作禁用。
- 原真实产品、截图、网页、品牌色和红绿状态可以保留，也可以按准确内容重绘后融入本节视觉关系；两种方式都允许，按画面效果决定。重绘不能虚构数据、操作或执行结果。
- 画面丰富度来自有用的材料、可观察的动作、差异和结果；可用真实场景自然色、手绘 AIGC 场景色、明亮阅读舞台、深色结构界面及清楚的辅助状态色。同片随材料改变景别、构图与明暗，统一排版层级、材质和动作质感，不把整片固定成同一底色、同款容器。
- 历史账号档案补充人物、原声、原素材和当时认可范围，不切换新片默认风格。当前明确的新模式或指定续作要求只覆盖其声明范围。

从 [完整效果目录与检索](selection-workflow.md) 找能力。中文候选只是发现辅助，未命中仍可查整库、换用能描述所需视觉事件的检索词，或直接 inspect 已定位条目；不能把排名前几条当作仅有能力，也不要求每个视频都用遍库。

### 新增动效参考：阿闰会员对比（2026-10-21）

用户明确说“我很喜欢这个的动效设计……除了颜色，其他都很喜欢”。[原片、完整视频工具分析与逐句证据](evidence/arun-membership-study/index.json)及[具体拆解](evidence/arun-membership-study/动效拆解与迁移.md)接入当前方法目录，来源 ID 为 `arun-membership`。这是对运动、构图、材料层次和解释设计的新增参考；配色仍按上方 Fred 默认，原片蓝/绿/棕舞台不继承，也不因原片无真人而取消本期真人要求。

重点继承：对象保持身份，会员卡/作品/标识相互交接；主图腾位让真实证据放大；总览缩成导航继续工作；消耗、卡住、等待、返工、独立额度用不同状态变化解释；进入短促有力度，落位后稳定可读；结论更新已建立的对象关系。布局、原声时窗、材料和声音按每篇内容设计，不固定排行榜、三张卡、黑箱或原片镜头顺序。

完整源视频工具报告、全音轨机器转写、顺序视觉及关键动作采样已记录；未完成正常速度全片人工音画听审，具体音效和原作者精确曲线不作已确认事实。本轮是参考学习与接入，未制作或认可新的复刻视频。

### 已认可正文风格：方木十款 Agent，开头除外（2026-10-21）

用户明确纠正：“这个是我很喜欢的一个例子，以后按照这种风格来，开头除外，这种风格颜色ui动态都很好”。**后续方木正文以本片作为直接视觉参照，颜色、UI 外观和动态三项一起继承。** 不是只保留动作，也不把认可范围放在开头。[原话、精确版本与源码](evidence/fangmu-ten-agents-body-style-20261021/index.json)对应[成片](evidence/fangmu-ten-agents-body-style-20261021/index.json)的 **15–300.04 秒**；15 秒只是这个工程的取样边界。

正文保留本片的明亮白色主舞台 `#FFFFFF`、轻灰分区 `#F3F3F5`、有分量的近黑实体窗口/文字 `#0B0B0F`；重点与状态的紫色按 2026-10-26 最新选择采用 `#D6C2FF`。历史源码中的 `#8750FF` 仅记录原片当时实现，不再作为新工程默认。真实产品材料保留本色。连同粗字层级、圆角实体 UI、投影、清楚的主次与可读尺寸一起参考，不归纳成全片黑底紫字或只换一种强调色。

动态参考正文中材料展开/收拢、主图腾位、局部聚焦、状态变化与结论归位，保留利落进入、连续变化和重点停稳的节奏。具体对象、布局、镜头及秒点按新稿设计，不固定十款榜单或一直复用同一个框。主要实现是 [film.js 的 mainBody](../assets/agent-editorial/source/film.js)、[body-a.js](../assets/agent-editorial/source/body-a.js)、[body-b.js](../assets/agent-editorial/source/body-b.js)，细节见[制作手册](../assets/agent-editorial/source/制作流程与动效心得.md)。

本对话随后[明确授权将这套实际制作方法接入通用 Skill](evidence/agent-editorial-upgrade-20261021.json)。可运行的[材质与连续动作模块](../assets/agent-editorial/README.md)已从该工程提炼；新工程沿此颜色关系和质感实现本期画面，再从整个效果库选适合的构图、蒙版、转场和动作，不只检索这一期。正文可用左侧人物／栏目信息、右侧主要内容的基础关系；重要材料、真实操作或大场景可放大全屏，必要时再返回，位置与比例按本期素材设计。

**原片正文认可明确不含开头。** 开头继续按本页开头规则、先前指定参考和新稿单独设计；不把本片三卡榜单式开头当成用户喜欢的固定方案。此前助手将认可归档为“重制开头”的解释已被本条纠正，旧素材和源码保留作历史，旧范围停止生效。此正文样例细化当前 Fred 整体方向，不取消整库动作选择。

## 2. 画面从口播内容决定

通读整稿与上下文，理解观众要看懂的事实、关系、过程或情绪，再选择素材与实现。具体产品、操作优先真实材料；抽象概念、情绪和比喻优先考虑 AIGC。普通情境不锁定素材类别，依据上下文和实际素材质量选择。

- 找不到足够好的对应素材时，可选实拍局部、UI 示意、AIGC 或人物讲述；不强行配图，也不把问题推回用户要求逐镜供图。
- 讲真实划线导出等过程时，条件具备就连续展示“局部内容 → 关键操作 → 结果”，重点放大、其余信息退后。这个例子表达的是清楚的过程，不是永久模板。
- 人物根据内容可全屏、与材料同框、缩小或暂时退场；让素材占满画面后再回来。不固定全片左下圆窗。
- 复用完整设计再适配内容，或先编排事件再组合动作，两种创作方式均可；两者都先让本期材料、过程与结果进入可观看的粗剪，再展开整片精细包装，不让易用模板代替缺失材料。

具体方法只在 [口播选材](script-visual-planning.md) 维护。

## 3. 动作、开头、节奏与声音

- **有开头人物原片时，保留人物完整原构图和全屏场景。** 素材在实测空白处展开，右侧有真实空白才放右侧；避开脸、身体、移动手势与字幕，不为塞特效先把人物缩小或裁成头像。用动作期间的保护范围约束叠加，不能只量一张静帧。没有开头人物素材时，可按当前内容设计全屏 UI 开头。这是有无素材的分支，不是两套审美。随后按内容进入正文或素材全屏；不改原声顺序，不虚构结果。
- 开场素材先建立主体，再用前后错峰、尺寸与短暂聚焦让观众看清重点；实体边缘、接触阴影和局部厚度服务材料本身。切入正文时可由当前材料展开真实下一场，也可按内容选择其他转场，不插无意义空白，不强制每期同一种交接。当前可复用实现见[本期源码提炼模块](../assets/agent-editorial/README.md)，其中 opening 实际保留完整源画面并执行保护区裁剪；原片空白、安全区、动作时窗由本期工程传入。旧[开场与材质组件](../assets/presenter-opening/README.md)保留为可选实现，不以旧样片作为质量标准。
- 动作力度与变化贴近认可原片：该动时连续变化，重点和结果出现后留稳看清。放大、缩小、蒙版、遮挡、转场、拆分、展开、镜头与层次变化都可按需组合。
- 转场按观感自由选择，不要求对象接力、强制形变或始终一镜到底；转场不要抢走正在解释的内容。
- 音乐存在感明显一些，剪辑跟随节拍，动作音效更丰富。原声仍清楚，阅读重点不为卡点强切；没有固定 BPM、音效数量或每镜必加声音的要求。

旧“无全局声音偏好”“没有本期新增需求就不加 BGM”不能覆盖本次已确认声音方向。已有明确只改画面的续作仍按其范围保留原音频。

## 4. AIGC 的画风与内容

使用用户认可的柔和手绘画风。问卷 D 的工作室图更接近；E 的问题是背景繁复、像风景插画，主体事件不清楚。不是从中推导禁止暖色，也不是只允许空背景。

参考女孩、工作室和现有场景图用于画风与表达参考；角色、场景、道具按本期口播重新设计，明确要求固定 IP 时才继承身份。AIGC 的画风与场景用色按此认可范围处理，不由 UI 的强调色覆盖。

AIGC 要让观众看见与句意相关的事件、动作及结果；动作利落，结果可辨认，与 UI 衔接自然。静图推拉不能冒充已生成角色动作；具体接口、资产和节奏条件见 [AIGC 导演](aigc-directing.md) 与 [画风/身份边界](style-profiles.md)。

## 5. 反馈怎样影响选用

| 反馈 | 应采取的动作 | 不应扩张的范围 |
| --- | --- | --- |
| 用户喜欢整个动作库 | 保留整库检索与改编选择，按当前内容选用 | 不宣称每个源码都能立即运行或每条参考都完整看过 |
| 设计与动作喜欢，配色不喜欢 | 保留设计和动作，调整包装色彩 | 不把结构/动作一起剔除 |
| 某片整体不喜欢 | 查实际画面问题并按维度修正，保留原反馈 | 不设整类动作禁令，不把“换色”当作必然能修好 |
| 历史样片局部认可 | 学习对应方法与范围 | 不把旧人物、题材、秒点和配色带入所有新稿 |
| 技术检查或源码调用成功 | 如实记录能运行与实际接入的位置 | 不当作视觉满意、完整视听或新片认可 |

已反复否定的是同款卡片机械换字、泛素材与句意无关、静图推拉冒充连续表演、只换颜色却没有内容表达、把片段参考缩成固定模板。这里针对实际成片表现，不禁止卡片、阅读停留、某种镜头或任何动作门类。原反馈与更早记录继续见 [历史](history.md)。

方木正文源码的既有认可与本轮材料剪辑补充共同适用。旧读书样片只保留历史实现与反馈，明确不是当前质量基线；新模块的技术验证也不替用户认可新的成片。
