# 剪辑时沿用的审美

整体采用 Fred Talk 的材料剪辑与 AE 动作感。具体 UI 继承「十款 Agent」正文 15–300.04 秒的字级、配色和动效，开头单独按本期内容设计。各投稿片分别负责构图、交互、叙事或动作。整稿决定哪些职责落在同一段、怎样衔接。

## 1. 统一视觉与用色

剪辑窗口对照[完整 UI 参考图集](../assets/reference-atlas/index.html)中标注 UI 的条目。以「十款 Agent」获认可的 15–300.04 秒正文为直接基准，再看 Fred 的 Argon、JEV、AI 周报以及 L/M/N/O 的设计细节。[逐项认可范围](aesthetic-details.md)说明各条参考可以沿用哪些部分。配色以当前 A 版为准。在[共用 UI 样张](../assets/agent-editorial/ui-preview.html)核对浅边、深边、字体层级和组件形态，再用于本期镜头。

| 画面对象 | 共用画法 |
| --- | --- |
| 舞台、白纸、浅色资料卡 | 舞台用白 `#FFFFFF` 或轻灰 `#F3F3F5`。白纸、浅卡和亮色窗口用 `#DBDBE0` 细边。纸面圆角较小，配短接触影。 |
| 深色窗口、编辑器 | 近黑 `#0B0B0F` 实体面，外框及内部分隔线用 `#393840`。白色主字，`#C4C1CE` 次字。窗口用比纸面更明显的圆角、厚度和远一层的阴影。 |
| 标签、选中、进度 | 短标签用圆角胶囊。A 紫 `#D6C2FF` 用于焦点、选中与进度，实色紫底配近黑字。浅底重点字用 `#594277`。 |
| 主标题、解释、字幕 | 使用随包同一份 Noto Sans SC 可变字体。主标题用 800，解释正文用 550，短标签用 700，UI 字幕用 600。浅底次级说明用 `#62616C`。字号按画幅与内容调节，先给长中文留宽。 |

[共用色值](../assets/agent-editorial/palette.json)和[画面组件入口](../assets/agent-editorial/README.md)供新工程复用。框形跟随对象用途，纸面、窗口和短标签各用其自身形态。框线随表面明暗选择。使用真实录屏、照片、品牌或印刷材料时保留素材原色。横屏可把说明放在材料侧边，竖屏让材料接在标题下方。

## 2. 正文画面、AIGC 与取材

通读本期原稿。产品和操作优先用本期真实界面或录屏，先交代对象，再放大具体操作，保留看清结果的停顿。比较用同一标准，材料各有对应的出处。人物可全屏、同框、退场或返回。阿闰提供整片叙事与比较的做法，秋芝及问卷 D 提供柔和手绘、主体动作和结果的参考。角色、道具与场景跟随本稿，明确固定 IP 时沿用其身份。问卷 L/M/N/O 同时认可设计和动作，包装色沿用本期 A 配色。

## 3. 动作、开头、节奏与声音

开头保留人物完整原构图、手势、字幕和原声。按人物动作全过程量保护区；没有开场人物素材时可从全屏 UI 开始。先在实测空白区让本期材料错峰出现，必要时让素材全屏。用裁切、遮挡、聚焦、展开或返回帮助观众跟住变化，看清结果后再切。音乐有存在感，动作音效与节拍服务口播，原声始终清楚。已有明确的局部修改沿用当期范围。

## 4. 反馈与原片依据

实景做主画面时保留原色，让动作占主要面积，去掉资料编号、模板边框和栏目角标。按手机大小检查整段动作的活动范围。主画面有人脸时收起人物小窗。主画面没有脸且口播表情有用时，才把小窗放到主体和字幕以外。企业、项目、动作都有可核对的出处时才用现场画面作证。实景缺证据就留口播。

动效按原句里的关系编排。列举技术层级时，每说到一层才出现一层，说到重点后让焦点停在那一层。讲协作时要看得出谁向谁交付什么，以及接手后发生的变化。可执行例子见[逐镜验收](shot-acceptance.md)。

当前镜头用 `direct -- resume` 取回对应参考的动作与时间依据。指定复刻、用色冲突或需要原话时查[逐项依据、原片范围与对照](aesthetic-details.md)。
