## 应继承的画面关系

当前黑紫质感的具体构成以[方向合同](../evidence/fred-reference-approved-20261015.json)为唯一维护处：深黑实体主体、醒目的紫色重点、清楚的字级与前后景层次共同起作用。白底可作为舞台，重点和章节可切黑底；不把旧“白画布＋局部淡紫”摘要当作充分条件。原片锚点、适用条件及反例均随合同跨窗口传入。

标题、对象标题、字段和字幕有明显尺度与 400/700 字重差异。窗口内有能读懂的对象、字段和状态，容器边界、明暗与阴影服务内容层级。每句重新画一个空白面板或只保留标题，不属于这套风格的继承。

连续动作由同一对象完成：建立对象、强调当前项、收拢为结果、进入新窗口、退焦并提取结论。先查看 A01 的入场、中间变化和停稳状态；起步明确、减速干净，关键信息留稳可读。每期按口播重新设计对象、窗口组合和路线，不固定套用面试内容、四卡归并、18 秒时长或原坐标。

新片的字体须实际接入并覆盖本期字形。A01 的 Noto Sans SC 字体文件是样例字形子集；不能仅复制子集后假定新口播不会缺字。字体路由见[字体模块](../qiaomu-typography.md)。人物、实拍、AIGC 与 UI 按句意组合，不从参考克隆作者身份或声音。
