# 阿刁风格档案

版本：2026.10.13.1。用于明确的阿刁内容或已属于阿刁系列的工程。通用导演约定见[主入口](../../SKILL.md)，本档案只补充账号习惯与已确认案例。

## 外观与人物

- 白 `#FFFFFF` 留白，近黑 `#101112` 主字与结构，中性灰 `#F3F4F5` 次级区域；淡紫 `#CDB7F5` 局部选择，深紫 `#7451B8` 白底重点。真实产品与品牌保留自身颜色。
- 黑色是结构和对比的一种选择，不要求大面积黑底。亮背景人物镜头先利用原场景，必要的信息可以使用小白色浮层、轻边框和柔影；是否需要容器由当前内容决定。
- 开头保留人物原比例与存在感，按实际构图利用可用空白，常见为右侧；检查整段动作中的头发、脸、手、前臂与字幕。正文通常左下小圆窗，大小按素材可读性与安全区域决定，语义需要时恢复全屏。
- 继承字体、质感与运动语言，每期重新设计主事件和镜头路线，不复用固定卡片轮播、固定品牌集结或上一期故事。

## 阿刁动漫 B-roll 主人公

2026-10-13 用户明确：本次选定的女主只用于阿刁的视频。沿用已确认的女主参考，保留长棕发、酒红色发夹、白色长袖上衣及参考中的面部特征；具体身份与整体画风以已确认图片为准，不能仅凭文字重新发明人物。同一项目跨镜保持角色、道具和场景画法一致。参考与确认原话见[样片反馈证据](../evidence/anime-semantic-feedback-20261013.json)。

此设定适用于阿刁的动漫 B-roll，不自动替换真人口播或数字人素材。其他 IP 使用各自确认的主人公与画风，不把这位女主当作全局默认角色。抽象口播的具象解释方法可以共用，具体身份和参考素材按 IP 选择。

## 素材与声音偏好

真实素材尽早建立主题，图形、漫画、实拍和人物共同讲清口播。前后对比先让观众认出比较的两边，再突出差异。用户指定“直接展示这张图”时，以原图为素材，不擅自用新生成图替换。

表情包只在对应情绪中出现，避开主要信息；不固定间隔轮播。音效对应可见的出场、交接、点击和确认，保留人声清楚，没有新增配乐要求时不自动加入 BGM。已有声音和人物素材优先复用。

## 本期认可与适用边界

《失业手册》v3 去掉开头大黑底、保留原亮背景和局部白色浮层后，用户随后回复“可以的”，接着要求总结经验并升级 Skill。可记录这次修订获接受；不能由此断言用户认可每个技术参数、全部正文细节或已完成全片听审。

v3 案例支持：先判断是否需要大容器；按人物动作范围避让；旧文字先让出阅读区域；开头末态与正文初态共享对象和几何。它不支持全局禁用黑底，不规定固定窗口位置、50 fps、7.4 秒开头或某个缩放值。历史检查报告保留当时状态，后来的用户接受另行记录。
