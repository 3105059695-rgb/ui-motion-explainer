# 每条参考视频能教这期什么

正常用法是给这期的口播和已有素材。Skill 先保留原句，在导演简报里写出每段适合借哪条参考、借哪个动作、用本期什么材料执行。可以跨作者组合，也可以在一段中只沿用一个完整设计。所有镜头共用[当前正文的配色、字级和材质](aesthetic-preferences.md)。

## 例如一条讲工具选型的视频

| 这句要说清什么 | 借哪条视频 | 画面怎样接下去 |
| --- | --- | --- |
| “以前我要在三个工具里反复复制同一份资料。” | 女孩手绘「人工搬运」 | 让同一份资料在三个工具之间走一遍。角色接到资料，动作停稳，再切界面里有同一标记的文件。 |
| “我用同一道题测了三款服务。” | 阿闰会员横评 | 留住题目与预算，依次换入三次实测结果。展示完差异再下结论。 |
| “这个细节只有放大原图才能看清。” | Fred 的 Argon 评测 | 在同一窗口里放大刚才那张图，保留来源，讲完回到可比较的位置。 |
| “配置改坏了，可以回滚到上一版。” | 秋芝的 Claude Code 教程 | 镜头留在同一文件同一行，让错误、撤销操作和恢复结果在同一位置可见。 |

这四段可以出现在同一片里。每次交接要让观众认得刚才那份资料、同一道题、同一张图或同一行代码。具体时长跟本期原声走。

## 从来源找到实际实现

新窗口可直接说「用 $ui-motion-fusion 剪这段口播，从我给过的参考里逐段选合适的剪法」。已有工程运行 `direct -- prepare` 后，打开工程的 `director-brief.md` 看逐句建议。`director-context.json` 的 `video_sources.units` 保留原句、字符位置、来源、绑定说明、证据定位和调用命令。主建议与备选都可以按材料质量调整；未命中的句子可以保留人物或实拍。

下面的命令从安装目录执行。单独查片和写入可编辑的参数文件不需要账户、联网或原片。

```powershell
python -B -X utf8 scripts/ui.py videos list
python -B -X utf8 scripts/ui.py videos match --query "改坏配置后，回滚到上一个版本"
python -B -X utf8 scripts/ui.py videos inspect --id claude
python -B -X utf8 scripts/ui.py videos use --id claude --capability method:Q-C04 --out my-rollback.json
```

最后一条会用已有动作程序创建本期的绑定文件，同时返回对应的构建命令。填入本期元素、前后状态、素材和口播时机后调用该命令。不同条目沿用自己的实现格式，有的使用场景文件，有的操作已有的 HTML 元素。`videos use` 省略 `--out` 时只查看实现与绑定要求。

## 哪些材料能借

| 目录 | 收录和用法 |
| --- | --- |
| `focus` | 逐片整理的全片、手绘原素材、局部样段和有明确反馈的历史试样。可以按片名或来源 ID 找用途。每条保留认可范围，纠错片只供查看。 |
| `prompt-motion` | 每个案例都有单独的标题、适用线索和对应的重建入口。有具体分镜时可以读它的动作顺序。原作、重建和当前稿件各自标识。 |
| `fredtalk` | 按片段查原有动作链和输入对象。例如「保持窗口滚到卖点」和「把几个分论点收成一句」分别服务不同句子。归档项仍可按 ID 查看。 |
| `collect-ui` | 实际留下观察的作品。可看到滑动确认、状态切换、失败定位等动作及对应预设。只有静态图的记录只用于构图。 |
| `discovery` | 历史站点清单里的未观察视频和待核对条目，按媒体身份合并跨分类的重复发现。获得画面前只作定位线索。 |

用 `videos list --collection fredtalk --query 交接` 等命令检索。页尾的 `pages` 是该次查询的总页数。`videos summary` 给出本安装的实际数量。访谈中的 Frame by Frame、Spotify、SaaS 与案例库里的同一作品可从两边找到，认可范围以访谈为准。

### 最容易混用的几条

- **十款 Agent** 提供正文外观以及任务分组、材料展开、跨设备交付等十套设计。整片的前 15 秒在认可范围以外。
- **Fred 三片** 各有分工。Argon 适合追溯生成结果再看细节，JEV 适合把模型、机器与运行条件对应起来，周报适合在多条消息间更换材料并交回上下文。
- **秋芝四片** 分别处理工作流输入汇合、创作资产确认、关系迁移与教程回退。可按方法跳到相应原句、观察时间与镜头编号。
- **微信原参考** 对应 16 种已有动作。讲“卡在谁身上”和讲“资料如何从一个界面过渡到下一个”分别走 R03 与 R05。
- **最早的豆包、Codex、Token 三片** 各自保留原片、拆解页与截取区间。豆包讲任务归并和协作，Codex 讲检索、高亮和新会话交接，Token 讲步骤灰化与关键词提取。
- **竖屏编辑参考** 借清晰截图的特写、分层和返回全貌。**小王子**借实机成果先行的开头，**API 奶茶**借实物交接，**汽车拆解**借同一对象从整体到计量单位。
- **手绘完整样片与三条原素材** 分别登记。人工搬运、Agent 接手和资料交到下游各有不同的动作目的。实体摄影样片只借衔接；阿刁的角色身份限其本人项目。
- **14 秒印刷校样**由本 Skill 制作，需要校对紫色、纸边与字重时再看；本期的剪法从上述来源选择。

公开包自带逐片用法、可公开的证据和生产实现。制作时绑定本期内容。要剪入某段私人原片或研究其完整原声时，按[跨电脑安装与私用参考包](../docs/install.md)连接本人持有的文件。新增参考时在原图集或对应库登记来源；有单独偏好、纠错或完整剪法的片子在 `references/video-uses.json` 补上触发条件、动作、绑定对象与真实能力 ID，然后运行 `videos check`。
