# 公开包与本机资源的边界

公开 GitHub 包提供当前 UI 的可运行实现、方法组合、保留工程源码、逐场景独立实现，以及 13 条原片的可携带图集（13 张总览、72 页细图）。包括十款 Agent 去除私人讲述人区域的正文 UI、Fred 三条、阿闰、秋芝四条和女孩 AIGC 四条。来源与认可范围逐条标明；图集可直接打开，不需要作者的 E 盘或本地服务器，原完整视频不因此公开。私人历史原图、原片与项目媒体仍只通过本机映射或获授权的私用包提供：`references/resources.pack.json` 和 `references/private-media/` 被 Git、公开 manifest 与普通 ZIP 排除，公开更新保留它们。

公开代码安装成功不代表当前参考齐全。`ui.py references check --require` 分别检查 20 条已有参考和 16 项完整设计媒体；原本缺失的三条外部历史视频单列。普通 `direct prepare` 直接加载当前审美与能力候选，不读取全部原片或历史研究。`ui.py capabilities check --require` 检查生产必需文件；历史原片缺失只影响对应研究与指定原片对照。所选能力缺实现或素材仍须明确处理，不能用空素材冒充。

本版只有 `ui-motion-fusion` 一个调用入口，内含基础、融合、导演、编辑式UI引擎，语义/逐句研究工具，保留的3张历史 UI 参考图（当前标准见[审美偏好](aesthetic-preferences.md)），以及历史 AIGC 的2张参考图、8张场景和可播放女孩样片/实现（按适用范围选择）。现有Python、Node、FFmpeg与浏览器优先复用。

逐句研究的6条原片、R库微信参考、外部230案例的原片/历史重建媒体，以及作者私有音色/数字人和账号工程不随包。早期O库的3条原片位于 `assets/base-skill/docs/source-videos/`，按各自来源和许可边界保留。230条外部索引保留来源；228条保留工程或原有起点已随包恢复，另2条提供完整预览独立实现。运行使用本期绑定素材，原参考电影不作为执行依赖。会员条目提供独立实现，不包含会员源码。

`local-only/`是未随包的历史出处占位。可在本机私有 `references/resources.local.json` 映射真实文件：`schema_version:1`、`modules:{reference:目录}`、`files:{资源ID:{path:路径,sha256:可选哈希}}`。此文件被Git忽略，不含密钥，不随公开包发布。公开工程首先使用包内源码与共享资源；追查历史缺件或明确使用私有原工程时，才采用已配置映射或 `--module-root` 覆盖。映射不改变任何账号风格或渲染底座。

`scripts/resource_inventory.py report` 分别报告目录、源码入口、原片、图片和研究文件；哈希未读取时明确 `not-verified`，`--verify-hashes` 才校验内容。`overlay-check` 核对全部映射存在性及已声明哈希，缺件或不匹配返回失败；不把目录/源码存在当作可运行或审美认可。阿刁/方木的规则保留且隔离，私人资源由对应工程提供；不会改用通用女孩。作者本机原始项目、研究和归档保留原址，不复制媒体或依赖。

新制作无需重复确认包内已选方向；新的账号身份、实质不同的审美、额外费用仍按当前任务处理。安装或结构检查通过不等于已完成实际视觉/听审，也不能保证每一条新稿无需修改。

图片保留为画风参考与历史证据，不是未来每期固定使用的素材库。旧皮肤与反例保留可追溯；统一生产导出检查当前风格计划，历史演示必须明确使用 `--demo`。

全片分格总览目录是 `references/reference-atlas.json`，入口是 `assets/reference-atlas/index.html`，`ui.py overviews --brief` 解析可用图片。默认 `direct prepare` 已列出图集与本期 `materials-plan.json`：前者让新窗口认识原片外观，后者引导通过 ego 去 X、B站、抖音取得适合新稿的视频和截图。UI、阿闰剪辑、秋芝/AIGC 等认可范围分别标明；总览太密时看细图，具体运动看动态事件。日常制作调用所选能力，[192 条独立场景播放器](../assets/rebuilt-library/index.html)只是动作实现及示意内容，不代替原片图集或本期材料。旧四张图仅补充局部细节。联系表按时间采样，不等于全帧记录或已完成整片视听。

总览与细读图沿用各自来源的分发边界：含私人人物、账号或项目资料的图集使用本机资源映射，不因做成拼图就自动上传公开仓库。公开安装缺少这些图时必须列明，不能用四张旧图或另一条视频冒充；原片、图集和本期创作素材仍是不同用途。

方木十款 Agent 的提炼模块与保留源码随包；原片、完整原工程、交付 ZIP 和本机验证产物不随包。对应证据中的 `local-only/` 只记录历史出处，`resource_id` 可在本机资源映射解析；保留源码与原制作手册内的历史路径不是新工程运行依赖。
