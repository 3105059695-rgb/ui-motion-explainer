# 公开包与本机资源的边界

本版只有 `ui-motion-fusion` 一个调用入口，内含基础、融合、导演、编辑式UI引擎，语义/逐句研究工具，保留的3张历史 UI 参考图（当前标准见[审美偏好](aesthetic-preferences.md)），以及历史 AIGC 的2张参考图、8张场景和可播放女孩样片/实现（按适用范围选择）。现有Python、Node、FFmpeg与浏览器优先复用。

逐句研究的6条原片、R库微信参考、外部230案例的原片/历史重建媒体，以及作者私有音色/数字人和账号工程不随包。早期O库的3条原片位于 `assets/base-skill/docs/source-videos/`，按各自来源和许可边界保留。230条外部索引保留合法原来源网址、文本和海报，另附2个通用starter；未附逐例历史工程会明确报缺失，不会把starter伪装成该例复刻。

`local-only/`是未随包的历史出处占位。可在本机私有 `references/resources.local.json` 映射真实文件：`schema_version:1`、`modules:{reference:目录}`、`files:{资源ID:{path:路径,sha256:可选哈希}}`。此文件被Git忽略，不含密钥，不随公开包发布。文件资源优先用包内现有版本，仅缺件才采用显式映射；原reference命令自动接续已配置历史库，另可用 `--module-root` 明确覆盖。映射不改变任何账号风格或渲染底座。

`scripts/resource_inventory.py report` 分别报告目录、源码入口、原片、图片和研究文件；哈希未读取时明确 `not-verified`，`--verify-hashes` 才校验内容。`overlay-check` 核对全部映射存在性及已声明哈希，缺件或不匹配返回失败；不把目录/源码存在当作可运行或审美认可。阿刁/方木的规则保留且隔离，私人资源由对应工程提供；不会改用通用女孩。作者本机原始项目、研究和归档保留原址，不复制媒体或依赖。

新制作无需重复确认包内已选方向；新的账号身份、实质不同的审美、额外费用仍按当前任务处理。安装或结构检查通过不等于已完成实际视觉/听审，也不能保证每一条新稿无需修改。

图片保留为画风参考与历史证据，不是未来每期固定使用的素材库。旧皮肤与反例保留可追溯；统一生产导出检查当前风格计划，历史演示必须明确使用 `--demo`。

方木十款 Agent 的提炼模块与保留源码随包；原片、完整原工程、交付 ZIP 和本机验证产物不随包。对应证据中的 `local-only/` 只记录历史出处，`resource_id` 可在本机资源映射解析；保留源码与原制作手册内的历史路径不是新工程运行依赖。
