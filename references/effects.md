# 动效库

共 **33 个参考观察动作（O01–O33）+ 23 个原创扩展（X01–X23），合计 56 项**。A01 单独记录用户已认可短样的组合。

## 使用规则

- **O 类**：在三条参考中确认的视觉动作；时间为对应源片时间，边界未密集抽帧时为约值。
- **A 类**：用户已认可短样中的具体组合。并不表示已逐像素复刻原片。
- **X 类**：依据相同视觉语言提出的原创兼容扩展，未宣称出现在参考里。X01–X08 见本页；需要口播强调、追问、因果、类比或总结时，读 [X09–X20 配方与带配音示范](narration-effects.md)；资料归档、连续推镜与文件交付见 [X21–X23 配方](motion-lab.md)。
- 表中实现方式和时长是重建建议，不是原作者工程信息。先确定语义，再选择动作。
- D = 豆包工作；C = Codex 上下文；G = GPT6 Token。完整来源见 [参考证据](reference-evidence.md)。

## 卡片、对象与连续布局

|---|---|---|
| O01 分批建立 | 一组项目逐项被提及；空场 → 对象陆续出现 → 总览 | 小位移、透明度、轻微缩放；按口播落点而非均匀撒点。D 19–21 秒；G 5.4–10 秒 |
| O02 当前对象放大 | 从一组文件中选择一个；保留邻居边缘，选中项移到中心 | 横向位移与比例同步，0.45–0.7 秒；不把其他文件全抹掉。D 13–17 秒 |
| O03 景深堆叠 | 表达文件多、步骤繁；原窗口缩小让位，额外文档带轻角度堆叠 | 2–4 层、约 2–6°，近层稍大；不能用来展示多页正文。G 32–33.5 秒 |
| O04 多卡归并 | 多项工作成为一次任务/统一结果；同一组卡片向同一目标收拢 | 目标结果卡在收拢途中展开，0.45–0.7 秒，避免先全黑再换页。D 20.9–21.3 秒 |
| O05 结果脱离容器 | 个人对话产物转成可共享对象；旧窗口收窄左移，结果脱离并在右边展开 | 结果要保持身份连续，容器与内容分层。D 28.4–28.95 秒 |
| O06 同一窗口换内容 | 同一工作空间输出多种结果；保留外壳，替换内部内容和标题 | 0.2–0.4 秒淡出/进入；不让整个场景重复飞入。D 32–40、47–51 秒 |
| O07 网格积累 | 概念逐项组成一个集合；先一格，后完整网格 | 坐标预留或平滑重排，保持对象大小与阅读顺序。G 92–94、184–186 秒 |
| O08 连续扩列 | 流程增加下一站；旧列让位，新列进入，最后形成三列链条 | 先算新布局，旧对象移动与新对象入场重叠 0.1–0.2 秒。D 59–63 秒 |

|---|---|---|
| O09 分支生长 | 一个主题对应多个方面；主节点 → 连线 → 子节点 → 说明 | SVG strokeDashoffset；线头到达后节点出现，0.3–0.55 秒。D 160–166 秒；G 86–89 秒 |
| O10 分支焦点交接 | 逐项讲复杂分支；新分支打开时旧分支收起副文案、压成标题窄卡 | 先淡出旧说明，再变卡高并重排；不隐藏已讲标题。D 163.25、164.5–165 秒 |
| O11 字段贯穿链条 | 同一信息从记录到任务再到群聊；多端保留同一关键字段 | 同色选区与一致短语建立连续性；不需要额外粒子飞行。D 58–63 秒 |
| O12 文档外加新容器 | 文档被新会话或系统继承；文档保留位置，背后展开新窗口 | 新窗口横向遮罩揭示，文档独立层，0.35–0.6 秒。C 168.6–169.2 秒 |
| O13 并置比较 | 原文/摘要、主任务/支线、方案 A/B；从单对象扩展为双栏 | 对齐共同基线，保留对应字段，焦点交替。C 11.5–12、49–51.5 秒；G 150–160 秒 |
| O14 数量级对比 | 比较容量、成本、比例；灰色旧值与更显著的新值并列 | 用字号、位置、紫色和下划线；数值必须有依据，不默认数字滚动。C 54–57 秒；G 20–24 秒 |

## 控件状态与注意力

| 编号 / 动作 | 适用语义与状态变化 | 实现起点 / 证据 |
|---|---|---|
| O15 开关和进度 | 能力启用、剩余额度、步骤状态；状态改变可见 | 开关柄位移、条宽变化、对应标签同步；图示要标清。G 0–5、7–10 秒；C 87–99 秒 |
| O16 完成勾选 | 任务确实完成或清单逐项核对 | 勾线绘制或短渐显，0.2–0.35 秒；确认后停留。D 21.6–21.7、47–51 秒；G 193–196.3 秒 |
| O17 背景退焦 | 当前场景仍是上下文，但读者应看一句结论 | 后景 blur 8–16px + 轻微缩放，前景保持清晰；0.4–0.65 秒。D 18 秒；C 9.5–10 秒；G 114.5–117.5 秒 |
| O18 关键词提取 | 从窗口里抽出真正重要的一句/一个概念 | 非重点淡化或模糊，重点重排为大字卡；避免同时展示两份可读重复文字。C 50.5–51.5 秒；G 95–96、185–186 秒 |
| O19 协作接入 | 多角色共同处理同一对象 | 先结果/标题，再人物节点、短连线、选区或身份光标；按角色落点。D 29.15–30、41–46 秒 |
| O20 窗口内缩放滚动 | 长文档需要逐段阅读；窗口固定，正文放大并滚到当前字段 | 外层 overflow:hidden，内层独立 scale/y；读完缩回总览。C 108–117.5 秒 |
| O21 累积荧光笔 | 多条约束都要保留；文字不动，底色从左向右扫出 | 独立底层 scaleX 0→1 / width 增长，旧高亮保留。C 112.0–112.4、113.3–116 秒 |
| O22 搜索逐字输入 | 检索过程和查询词本身有意义 | 固定搜索栏逐字揭示，光标跟随，建议 60–140ms/字。C 126.1–126.8 秒 |
| O23 过滤并上移 | 从多个结果中找到匹配项 | 不匹配行淡出，匹配行移动到首位，输入栏不动。C 128–128.5 秒 |
| O24 原文重排强调 | 找到记录后解释真正关键的一句话 | 在原卡内重排成小出处 + 大重点；最后细底线渐显。C 130.5–133 秒；其底线为整条渐显，不是左向右生长 |
| O25 消失或灰化 | 解释信息丢失、步骤取消或旧做法降级 | 删除/灰化对应内容，保留其他上下文；状态变化后给结论。C 15–15.5 秒；G 179–183 秒 |
| O26 状态标签切词 | 流程状态更新但对象位置不变 | 固定圆角遮罩内文字纵向切换，0.25–0.4 秒。C 163–167 秒 |
| O27 选中文字再替换 | 提示词、按钮标签或规则被修改 | 先出现选区，再更新文字，最后稳定显示结果。G 29–31.5 秒 |
| O28 条目升格为主结论 | 某一行规则值得重点解释 | 条目变成宽色条、移到中心，阅读后进一步推大。G 15.8–18.2 秒 |

## A01 用户已确认的组合

[短样工程](../assets/approved-demo/index.html) 的时间轴可直接查找相应选择器，学习状态与节奏。复用前复制到新输出目录并改写新脚本。

| 短样时间 | 组合 |
|---|---|
| 0–6 秒 | 四类文档依口播出现；当前卡片短暂抬起，总览稳定 |
| 6–8 秒 | 标题切到旧耗时，原卡组略缩小 |
| 约 8–10.36 秒 | 四张卡归并为一次任务，结果标题与完成勾线出现 |
| 10.36–14.3 秒 | 对话与团队 UI 连续展开，箭头、头像、表格和选区陆续建立 |
| 14.3–18.0667 秒 | 已有 UI 退焦，前景出现“结果，走出对话框。”，保留阅读时间 |

这是一个“建立 → 归并 → 展开 → 聚焦”的有效组合。新片可以改为“搜索 → 筛选 → 原文 → 高亮”或“主节点 → 分支 → 折叠旧说明 → 总览”，不用机械重复这四步。

## 兼容扩展

以下 X 类没有作为原片已观察效果来背书。它们适合用户希望增加变化时使用，仍应保持黑白紫、动作简洁和对象连续。

| 编号 / 扩展 | 使用条件 | 动作与边界 |
|---|---|---|
| X01 遮罩揭字 | 标题包含需要按语义分开的两三部分 | 每行从底部遮罩揭示，0.35–0.5 秒；完整显示后静止，不做全篇逐字弹跳 |
| X02 保位排序 | 优先级、排名、筛选顺序实际变化 | 先读旧顺序，行沿各自路径平滑换位；ID 与内容绑定，不能只更换标签假装移动 |
| X03 局部放大镜 | 必须同时保留整体位置和一个微小字段 | 主屏不动，带细连接线的放大框显示同一原图区域；只出现一个放大框 |
| X04 图解匹配到实录 | 简化 UI 讲完，接下来要证明真实操作 | 匹配相同按钮/窗口的边界和位置，短交叉淡化到真实录屏；界面示意不可冒充证据 |
| X05 分段步骤条 | 有明确顺序且需要让用户记住当前步骤 | 顶部 3–5 段细条逐段点亮，当前步骤结束后再推进，不伪造百分比 |
| X06 差异层切换 | 比较修改前后同一个区域 | 两层同位置局部擦除揭示差异，改动处短暂高亮；避免整页强闪 |
| X07 局部跟随聚焦 | 同一区域中的目标连续移动，例如拖动排序 | 相机平滑跟随目标，移动范围受画布限制；转回稳定视角再读文本 |
| X08 轻微纵深翻面 | 正反面本身有意义，如问题与答案、输入与输出 | 仅单卡一次浅角度转向，在侧面最窄时替换内容；无语义时用 O06 即可 |

### 口播驱动扩展 X09–X20

以下均为原创扩展。先判断讲解关系，再按 [详细配方](narration-effects.md) 和 [实际口播时间表](../assets/narration-demos/assets/narration-timing.json) 安排动作；示范的每段 6 秒不是新片时长限制。

| 编号 / 扩展 | 使用条件 | 主动作 |
|---|---|---|
| X09 重音接力 | 一句话里的两三项重点 | 完整句保留，当前词升格，上一词归位 |
| X10 追问递进 | 从表面问题追到真正需求 | 已知条件缩小保留，新一层追问接管中心 |
| X11 因果传导 | 有依据的原因到结果 | 单个焦点沿因果关系推进，结果最后点亮 |
| X12 误区纠正 | 常见说法需要准确替代 | 划去错误关系，在原位置建立新说法 |
| X13 句子拆步骤 | 将口头说明转成行动清单 | 同一句中的短语逐一移入编号步骤槽 |
| X14 层层剖开 | 一个概念包含多层组成 | 保留外壳，内部层错位展开，当前层拉开 |
| X15 类比变形 | 用熟悉物件解释抽象关系 | 对象简化成同色比喻物，交接后重新展开 |
| X16 数值尺量 | 数量或步骤确有变化 | 可数单位和括尺同步收缩，旧值变新值 |
| X17 时间折叠 | 当前执行与后续按需处理 | 当前节点保留，后续折成可再展开的分组 |
| X18 证据落点 | 结论需要追溯原文 | 脚注连接到对应句，只定位和高亮该句 |
| X19 首尾回扣 | 解释后回答开头问题 | 原问题收为书签，结尾从同一标识拉回 |
| X20 结论拼句 | 多个要点需要归纳 | 原关键词移动组合，形成完整结论并留读 |

### 连续对象扩展 X21–X23

三段各 9 秒、1080p、50 fps 无声示意；[27 秒总览](../assets/motion-lab/preview.mp4)、[工程入口](../assets/motion-lab/index.html)与[实现配方](motion-lab.md)对应同一组场景。实际导出及检查范围见[验证记录](../assets/motion-lab/verification.md)。

| 编号 / 扩展 | 使用条件 | 动作与边界 |
|---|---|---|
| X21 资料纵深归并 | 多个来源最终进入同一份可编辑资料 | 来源窗口依次接管前景，再收成原文件中的引用条；外壳、内容与阴影分层，来源不凭空消失 |
| X22 仓库窗口连续推镜 | 从总览定位关键条目，再交代整体位置 | 固定外壳与裁切视口，同一 DOM camera 连续推近、选区停读、回到总览；真实录屏保持 1× |
| X23 数据文件曲线交接 | 同一份数据交到下一步，成为可读报告 | 文件沿确定性曲线移动并落稳，随后以 inset 遮罩展开；前后字段与数值一致，不另换一份报告 |

运动模糊只覆盖快速移动且内部样式稳定的对象。上游组件会缓存子节点样式：X21 用 `--shutter-opacity` 配合 `timeline.set`，在 5.12 秒隐藏本场景的模糊副本，折叠阶段只显示原对象。接入参数、时间轴注册与这项限制见 [motion-lab](motion-lab.md#接入运动模糊与时间轴)，不要直接套到内容持续改变的节点。

## 可复用组合

1. **搜索教程**：O22 → O23 → O24 → O21，过程说明与原文出处都看得见。
2. **团队工作流**：O05 → O19 → O08 → O11，始终保留同一字段或成果。
3. **三项原则**：O09 + O10 → 总览，讲第三项时仍能看见前两项标题。
4. **错误做法纠正**：O13 → O25 → O18，旧状态退下，结论留在前景。
5. **产品功能教学**：O06 → X04 → O30 → O16，示意到实录再确认结果。
6. **交接与继承**：O26 → O08 → O12 → O21，同一文档成为新阶段的输入。
7. **口播原理讲解**：X10 → X11 → X14 → X20，由追问进入解释再收束结论；详见 [口播配方](narration-effects.md)。
8. **从资料到交付**：按语义选择 X21 归档、X22 定位或 X23 交付；可独立使用，每段保留同一对象的前后身份，不为了用齐三种动作重复移动。

组合没有固定时长。每个动作前后都要回答“观众因此理解了什么”；回答不出来时移除该动作。
