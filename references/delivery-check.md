# 成片交付检查

只检查实际产物，报告做过的项目。脚本输出成功不等于效果获得用户认可。

1. 查看开头稳定帧、转场中间帧、交接尾帧与正文代表段：有可读的实际对象与状态变化，没有沿用大数字+漂卡、只有字幕、整页轮播等被否定方案。
2. 比较可取得的最近2–3期；记录本期主事件、路线、对象交接的实际差别。没有历史就注明未知并继续设计，不编造历史比较。
3. 核对字体真实加载、无缺字、图像未被误裁、脸/头顶/手势未被UI覆盖。圆窗缩小后检查最终坐标而非CSS原坐标；字幕不挡关键操作。
4. 查看真正编码的运动中间帧：只在快段存在模糊，无残影、透明黑边、双层文字、闪白和粗硬矩形裁切。对应源视频1×且不因放大交接重置时间。
5. 口播不漏句、不重播，人物嘴型时间一致；源BGM按本期要求保留/不用。只有配音不代表自动合好了BGM。完整播放/解码与时长检查相符。
6. 交付实际MP4、可编辑工程、字幕和素材来源。内部示范/占位镜头不能冒充用户成片；人工没看的段落不要声称已全片视觉审核。

渲染器提供 `--stills-only` 检查布局、`--start/--end`检查小段、默认完整范围导出。它记录编码信息与截图；代理仍须看图/看片。输出目录包含 `verification.json` 是技术记录，不是主观品质认证。
