# 本机统一调用

菜单名称：**我的 UI 动效剪辑**。唯一稳定调用标识：`$ui-motion-fusion`。

当前本机入口：`SKILL.md`。技能属于用户级目录，资源按技能所在目录的相对路径解析，不随项目工作目录改变，也不需要为其他对话复制一套。

```text
使用 $ui-motion-fusion，按统一入口的四层导航处理这次剪辑任务。
```

四层入口为[主流程](workflow.md)、[账号风格](style-profiles.md)、[可用效果库](library.md)、[参考与历史](history.md)。先读 [SKILL.md](../GUIDE.md)，再按当前任务逐层、按需读取；具体规则只在对应层维护。

## 跨项目与旧入口

`ui-motion-explainer`、`ai-ui-director`、`adiao-ui-editing`、`apple-kinetic-promo`、`prompt-motion-replica`、`editorial-ui-motion` 作为兼容名称保留，模块资源与脚本仍在原目录。旧名称的职责和资源见[兼容映射](module-map.md)，不要将各旧入口的完整规则并行叠加。

用户级可调用不表示所有无关任务都套用剪辑规则，也不覆盖当前项目的明确要求。另一台电脑、其他系统用户、自定义 `CODEX_HOME` 或独立远程环境应使用各自安装的技能目录。

## 已有对话刷新

磁盘上的更新不会自动替换其他正在执行的对话已读入的文本。继续旧对话时，让 Agent 重新读取当前本机的 `SKILL.md`，再按其中链接读取此次任务需要的层。不要依靠旧菜单描述或旧聊天摘录继续制作。

```text
重新读取 SKILL.md，按当前四层导航继续这个项目，沿用工程已确认的设置。
```
