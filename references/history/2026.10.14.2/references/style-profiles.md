# 第二层 · 账号与项目风格

这一层只决定当前视频的外观、人物身份、接续样片和适用范围。通用制作与授权阶段见[第一层](workflow.md)，选择优先级见[主入口](../GUIDE.md)，具体实现见[效果库](library.md)。其他账号不必继承阿刁身份、配色或画风。

## 先确定属于谁，再读取一个档案

| 当前任务 | 读取与接续 |
| --- | --- |
| 明确是阿刁，或工程已标记为阿刁 | [阿刁档案](profiles/adiao.md)：配色、人物条件、最新系列接续及认可范围。长棕发女主仅属于阿刁；调用动漫前核对档案的角色参考 |
| 明确是方木，或工程已标记为方木 | [方木档案](profiles/fangmu.md)：先读其中本机样片与实现索引。已授权后续直接沿用认可基线；最新实现、开头认可、17 秒样片认可和整片未认可分别看 |
| 已有其他账号／工程规范 | 读取该工程的适用档案，不套用上述两个账号；新反馈保存到该账号或项目 |
| 未指定账号 | 结合素材、受众与表达目的设计本期外观。“我的 UI”不自动代表阿刁；只有主人公或风格确实影响结果且无法推断时才问一个必要问题 |
| 忠实复刻 | 原片约束决定外观，账号档案只用于用户明确允许替换的部分；差异按[参考复刻模块](reference-replication.md)记录 |

方木普通换题材、换文案、重新设计镜头不撤销已定风格授权。其内部样片对照属于制作检查；本次用户要求先看样片则照办。不同 IP 使用各自主人公和素材，不把私有角色／音色搬到通用包。

## 档案保存什么

- 配色、字体气质、材质、明暗层次和容器使用条件。
- 人物身份、出现时机、构图条件、角色／场景参考；位置根据实际动态素材测量。
- 账号开头、表情与声音习惯，以及哪些要求仅限某一期。
- 认可样片文件、具体版本／段落、确认原话和范围；负面反馈与未认可版本另列。
- 本期分辨率、帧率、源音轨、坐标等留在项目；不因一条样片认可而升级成所有视频默认。

在已有项目说明记录 `档案名及版本 / 适用范围 / 视觉值 / 人物条件 / 节奏与声音 / 认可片段 / 本期覆盖项`，不新增审批或配置系统。字体选择同处记 `pairing ID / title / body / latin / 字重 / effect / 回退`，实际字体文件与搭配见[字体模块](qiaomu-typography.md)。

## 落实与保留

现有渲染器没有 `--profile` 参数；档案是需要落实到代码、布局和素材的导演约束，读取文档不等于模板已自动换色。黑白淡紫、174px 圆窗、暖白橙等只能在对应账号／案例条件下使用，不能跨账号成为全局默认。

本次四层整理保留两份已有档案的内容与其样片、源码、证据链接，不改认可范围。私人素材、音色 ID 与账户凭据留在原项目；跨机器仍需按[资源映射](module-map.md)检查实际依赖。追溯出处时读[第四层](history.md)，不同时加载多个旧账号入口争夺规则。
