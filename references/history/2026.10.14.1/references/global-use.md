# 在本机其他 Codex 对话调用

菜单显示名：**我的 UI 动效剪辑**。稳定调用标识：`$ui-motion-fusion`。

本机主目录位于当前用户的 `.codex/skills/ui-motion-fusion`，属于用户级技能，供同一台电脑、同一用户环境下的 Codex 对话调用。完整模块保持同级目录，通过当前技能的相对路径解析，与对话的项目工作目录无关。不要为了另一个对话再次复制一套技能或另建相同名字的入口。

在其他对话中输入：

```text
使用 $ui-motion-fusion（我的 UI 动效剪辑），根据口播和素材自主判断怎么剪，保持口播原样，按适用的风格档案，先做开头和代表性正文给我看，确认后完成整条与可编辑工程。
```

也可以在技能菜单搜索“我的 UI 动效剪辑”并选择。已有窗口可能仍展示旧名称或已加载的旧文本；重新打开菜单或重启 Codex 后再调用。当前任务需立即加载最新规则时，直接读取当前用户目录下的 `.codex/skills/ui-motion-fusion/SKILL.md`。

有一份或多份口播稿，希望自动判断素材与表达方式时，可以说：

```text
用 $ui-motion-fusion，根据这些口播稿判断每段该用什么素材、怎么演示，缺素材主动补齐，先交开头和代表性片段。
```

收到稿件后按[口播理解与素材选择](script-visual-planning.md)和[本用户 B-roll 偏好](broll-preferences.md)先分析句意、上下文、人物情绪与段落任务，再决定保留人物、加入什么 B-roll、对象怎样变化以及怎么接续。如用户只要选素材方案，则交对应方案。该能力适用于不同视频类型，不指定每句统一的漫画、手机或桌面模板。

2026-10-12 校准版已将两轮人工标注、49 个问卷选择和未答项放在本技能相对路径内。其他窗口无需读取原聊天、E 盘旧项目或运行问卷网站。需要立即刷新已有窗口的旧规则时，可说：

```text
重新读取当前用户目录里的 ui-motion-fusion/SKILL.md，以及 references/script-visual-planning.md 和 references/broll-preferences.md。沿用已保存的标注规则，先分析口播句意、上下文与人物情绪，再自主编排 B-roll 和动效；以后根据实际视频反馈完善。
```

新窗口调用会读取磁盘上的版本；本机修改不会自动替换另一个正在执行的对话已加载的文本，该窗口应重新读取上述文件。问卷只保存文字偏好，没有把未答 Q34 或未拍成样片的方案写成已通过。

阿刁任务可加“沿用阿刁风格”，其他账号按对应[风格档案](style-profiles.md)处理。若本次明确需要直接做完，可写“跳过样片，一次完成整条”；既有风格确认无需重复获取。档案当前由导演读取并落地，不是已新增的 CLI 参数。

方木已有[固定风格档案](profiles/fangmu.md)和关联的实际样片、源码。后续说“用我的 UI Skill，按方木风格制作这一期”即可；已属于方木的工程也应自动选择该档案，不要求用户背诵提示词。先从档案进入本机资源索引，核对认可片段与后续要求，复用实际实现，再编排新口播。已授权直接沿用的风格不重复审批；新片检查由制作方先完成。它是有明确读取入口的制作约定，未新增能自动修改渲染器的参数。

全局可调用表示技能不依赖某一个项目，不表示所有无关对话都强制套用 UI 剪辑规则，也不覆盖各项目已有明确要求。另一台电脑、其他系统用户、自定义 CODEX_HOME 或独立远程环境使用各自的技能目录，应分别安装。

本机技能更新不会自动改写已发布的 GitHub 安装包。需要共享新版时按发布请求另行打包，不把本机版本说成已经同步到远程。
