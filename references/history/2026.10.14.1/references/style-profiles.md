# 通用导演与风格档案

2026-10-12 确认：通用剪辑判断与账号外观分开保存。其他账号可以使用同一套导演方法，不必继承阿刁的人物、配色或身份。

## 选择档案

优先顺序：本次明确要求 → 当前工程确认的配置 → 对应账号的最新档案 → 按内容选择的本期视觉 → 旧模板。忠实复刻按原片约束处理。

- 明确提到阿刁，或当前工程已属于阿刁系列时，使用[阿刁风格档案](profiles/adiao.md)。仅说“我的 UI”而上下文没有账号依据时，不据此假定人物身份。
- 明确提到方木，或当前工程已属于方木系列时，使用[方木风格档案](profiles/fangmu.md)。先读档案关联的项目资源索引、认可范围及实现说明；后续方木视频默认接续该基线，不再从头确认已定风格。方木档案中的本机索引只是定位入口，具体私人素材路径保存在项目里。
- 其他账号有现成规范时使用它；没有时，导演从素材、受众和表达目的提出适合的外观，在样片中供确认。只有确实会改变结果且无法推断的缺口才问一个问题。
- 对新账号已确认的风格，保存到该项目或独立档案；不覆写阿刁档案。换账号不等于另造一个同类 Skill。
- 2026-10-13 用户明确：不同 IP 调用不同主人公；本次确认的长棕发女主仅属于阿刁。生成角色图或动漫前，先核对当前 IP，再读取其角色与场景参考。其他 IP 不得默认套用阿刁女主或整套画风；项目和素材仍无法确定主人公时，只问一个必要问题，期间可继续句意与分镜分析。

## 两层分别保存什么

| 通用导演判断 | 账号／项目风格 |
| --- | --- |
| 保留原口播；先样片确认，再完成整片 | 配色、字体气质、材质和明暗层次 |
| 前 5 秒抓人；全片跟着内容起伏 | 人物位置、出现时机、素材与画幅条件 |
| 具体操作用真实界面；概念允许重绘 | 品牌素材、开头偏好、表情包及音乐习惯 |
| 连续语义、轻量阅读动势、一个阅读中心 | 可参考的已认可片段及其具体确认范围 |
| 抽象口播转成可见事件、动作和因果过程 | 对应 IP 的主人公身份、角色参考图与整场画风 |
| 主动补素材，交代来源；检查脸、手及过渡 | 该期的分辨率、帧率、时长、裁切与声音要求 |

表左列是本 Skill 当前默认，用户本次要求可覆盖；表右列不能越过账号或版本自动继承。确认过的效果保留其作用原理，下一期按新主题设计镜头。

## 保存方式与迁移

在已有项目说明中记录 `档案名／版本、适用范围、视觉值、人物条件、节奏与声音偏好、认可片段及确认原话、本期覆盖项`。不要求新增配置系统，也不强制用户填写表格。已有渲染器没有 `--profile` 参数；档案是导演读取并落实的规则，不宣称选择档案会自动改模板或代码。

选用[字体模块](qiaomu-typography.md)时，同处记录 `pairing ID / title / body / latin / 字重 / effect / 回退`；它们是文字角色和选择记录，不是所有渲染器通用的配置字段。实际接入与本期文字预览在样片阶段完成。

通用规则与[避坑手册](editing-lessons.md)使用相对链接，可单独阅读。私人素材、音色 ID、账户凭据和本机绝对路径留在项目中，不随通用档案复制。跨机器调用原有渲染器仍需按[资源映射](module-map.md)检查依赖，文档可迁移不等于所有后端已物理打包。
