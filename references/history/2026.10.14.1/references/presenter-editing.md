# 人物讲解、真实素材与语义剪辑

适用于人物口播搭配真实 UI、B-roll、文档、漫画和表情包的片段或整片。
先应用主入口的视觉标准；本模块不指定账号身份、固定人物尺寸或生成服务。
当前请求决定制作范围，已有素材可用时直接进入对应剪辑步骤。

## 先锁定声音和源时钟

1. 确认口播母带，以及每份人物素材实际覆盖的句子和源片时间。
2. 两份视频可能是开头加完整口播，也可能是连续两段；用声音和内容核对，不靠文件编号推断。
3. 原口播只保留一次、默认原速，内容与顺序保持原样；先明确母带来自独立音频还是人物视频，避免重复叠音。不通过删掉铺垫、重排句子或再造声音改善视觉开头。
4. UI 动画时间与源媒体时间分别保存。镜头加速、运动模糊采样不能带动嘴型或字幕漂移。
5. 本次明确允许剪口播或换音频时，同步更新字幕、人物源区间、镜头时点和结果停留。
6. 素材不足时说明缺口；不能冻结尾帧补足缺少的有效人物动作。

已有成片只改 UI 时，保留对应原声和源片映射；不顺手重做声音或换人物。
有真实音频按实际发声编排；仅有文字时，明确镜头时点仍是估计值。

## 按口播含义安排画面

先按[口播理解与素材选择](script-visual-planning.md)判断哪些段落需要补充素材、哪些适合保留人物表达，再用本节编排人物与画面。无需每句话都插素材；漫画、手机和软件窗口都按本期内容选择。

同时读取[本用户 B-roll 偏好](broll-preferences.md)，结合前后文、段落任务以及实际人物的重音、停顿、表情和情绪选择镜头。态度、判断或有表现力的原人物可以保留；需要补充情绪情境且要求最终动漫时，按[动漫视频生成](anime-video-generation.md)制作同角色连续动作视频。多动作拆图切换／叠放可用于明确选择的漫画表现或分镜预览，不能用单张表情图反复推拉替代动漫表演。样片与文字方案的确认范围分别保存。

每段记录：`片内起止 / 口播 / 观众要看懂什么 / 素材ID / 触发 / 状态变化 / 结果 / 阅读停留`。
涉及录像再记录：`源文件 / 源内入出点 / 播放速率 / 裁切区域 / 人物安全区`。
信息表是制作依据，不代替最终画面与声音检查。

| 语义 | 适合的主要画面 | 推进方式 |
| --- | --- | --- |
| 产品是什么、从哪里进入 | 官方名称、真实 Logo、官网或应用入口 | 从可辨认身份定位到具体入口 |
| 怎么操作 | 真实界面与有依据的录屏；截图只证明实际可见状态 | 定位→点击→完整选项→输入→执行→结果 |
| 文件、任务或结果怎样流转 | 真实材料与 UI 对象 | 同一对象跨窗口保留身份、位置或方向线索 |
| 为什么会卡住、如何解决 | 文档、对照、漫画情境 | 问题→关键动作→反馈→理解 |
| 工作、客户、生活中的具体场景 | 与句子相关的 B-roll | 展示具体行为，再接回 UI 中对应的对象或结果 |
| 困惑、惊讶、完成 | 短暂表情或角色反应 | 由语义触发，避开主要阅读区域 |

不按固定几秒换镜，不让每句都变成一张新卡片。
动作快慢服从信息：动作启动利落，关键输入完整出现；结果进入阅读阶段后用轻推镜或局部高亮引导，文字保持清楚，不在阅读时继续强透视或大幅弹跳。

## 人物与 UI 的构图

- 先检查人物整段的脸、头发、手、前臂和主字幕范围，再决定图形工作区。面板、阴影及入场路径都要避让，不能只按首帧空白摆放。
- 开头用真实可识别对象尽早说明主题；一次明确的大尺度变化后，由同一对象承接下一状态。
- 不为了塞更多界面把人物和材料一起缩到看不清；先减少并列信息，再调整景别。
- 大人物转入画中画时保持源时钟连续，让位置、比例或遮罩变化可追踪。
- 圆窗、横窗、全屏材料都按当前内容选择；圆窗不是所有账号默认，尺寸也不是历史常量。
- 主阅读中心保持一个；人物自然口播不能被点击光圈、浮层或装饰反复遮挡。
- 透视只服务短暂空间交接，正文读字回正；检查遮罩白边、被裁阴影和界面边缘。
- 修订开头构图后，正文承接的共享对象从同一位置、尺寸与状态起步；同时检查交界前、交界点与交界后。

## 素材真实性与清晰度

每项素材保存 `ID、实际文件、来源URL或用户附件、取得日期、真实/生成/操作示意、用途`。
产品身份和操作依据优先使用真实官网、软件、文档、原仓库及实际成果。
录屏默认 1×；可以剪去等待。关键动作回看可注明“重放／慢放”，重复过程压缩注明“加速演示”；保留真实耗时口径，不能伪装产品响应速度或不存在的完成结果，不能改变原口播与人物源时钟。
解释概念与逻辑时允许重绘，标注“示意”或“讲解重建”，标注出现在对应画面中。具体操作教学遵循[真实操作边界](software-production.md)，不能仅加一个示意标签就把缺失的真实操作补造成教程证据。
真实品牌与手机系统界面保留自身颜色，外层包装遵循当前风格档案，不整体染紫。
材料必须足够大且清晰；低清截图放大或套精致外框仍是低清素材。
优先重新采集高分辨率材料，或推近关键区域并保留必要上下文。
价格、数量、权益等时效事实按本期核实；历史截图不自动成为当前产品承诺。

## B-roll、漫画与表情包

B-roll 对准当前句子的动作与对象；随机办公室、键盘或城市镜头不能代替具体解释。
真实材料负责事实和操作，生成图形负责比喻、故事与情绪，不设机械比例或素材数量配额。
漫画先有情节，再安排全景、细节、反应和结果；可以多镜推进，不规定固定四格。
从漫画或实物接回 UI 时，用同一文件、任务、动作或结果建立联系。
表情包由困惑、返工、理解、庆祝等情境触发，不定时轮播，不占据关键按钮或字幕。
用户给的素材优先复用适用部分；历史素材只作可选资源，不强制每期全部出现。

## 仅在账号匹配时启用阿刁约束

明确制作阿刁内容时，读取[阿刁风格档案](profiles/adiao.md)；需要历史依据再读[早期已确认规则](../../adiao-series-guide/references/approved-style-20261004.md)，后来的直接反馈优先。
继续旧集时再读[项目指针](../../adiao-series-guide/references/latest-project.json)，核对实际文件与日期，避免把旧指针当成本期。
开头保留原比例人物、优先利用实际可用的空白，正文小圆窗及表情包位置服从该账号最新规则。
可按需读[构图与材料细则](../../adiao-ui-editing/references/creative-direction.md)，不回跳旧编辑 Skill 入口。
只有本次需要生成该账号声音或人物时，才使用[账号生产链](../../adiao-workflow/SKILL.md)。
确认状态属于具体账号、集数和素材版本；不把历史确认、技术通过或索要文案当本期审美批准。
不复制私人身份、音色、人物 ID，也不把阿刁构图施加到其他账号。样片流程统一遵循[制作流程](workflow.md)，不另外沿用旧账号的重复确认环节。

## 声音与交付检查

点击、展开、撞击和确认音效对应可见动作，力度有区别，不铺满、不盖口播。
沿用本次声音要求；没有新增配乐需求时，不因切换引擎自动添加 BGM。
检查最终编码的开场连续动作、人物交接、转场中间态、重要文字和尾音。
分别记录技术解码、实际观看/试听范围、平台检查及用户审美认可；未完成的明确标出。
交付当前授权范围的 MP4 与可编辑工程；独立开头仅在需要时附上，使用新版本文件名。
