# 高保真桌面与手机联动的产品演示动效

## 用户确认的风格

2026-10-09，用户基于提供的 iPhone Use 视频确认了以下描述：**高保真 UI 产品演示动效，结合桌面与手机的连续交互**。核心是“很丝滑、UI 界面很真实，再加上手机的 UI 界面”。当时指定的视觉基底是黑白淡紫；新任务按当前[风格档案](style-profiles.md)，不将这个历史色盘套给所有账号。

用户确认的是这套风格表达。当天首版重建的质感与颜色被明确否定，第二版没有审美确认；不能把技术导出成功或用户同意更新技能当作认可这些样片。

## 颜色与材质

开始设计时查看适用账号的实际样片；需要基础参考时再查看所选基础技能的 `assets/approved-demo/contact-sheet.jpg` 或实际视频，以及 `references/style-system.md`。底座用于校准质感，当前风格档案决定外观。

默认色值、圆角、字重与层次统一读取 [视觉与质感标准](visual-quality.md)，本模块只补充设备和联动要求。

手机壁纸、品牌图标和真实应用保留原色。使用细边框、合理圆角、克制的柔和阴影和统一字重；不把整个画布、手机与窗口染成紫灰色，不用厚重发光代替材质。高保真由结构、内容、比例和细节共同建立。

## 界面真实感

- **桌面**：保留可信的顶栏、导航、工具栏、输入框、执行记录和结果容器。按语义精简信息，关键内容使用真实可读文字，字号和边距有稳定层级。
- **手机**：机身、屏幕圆角、状态栏、底部手势条、应用图标、键盘和页面结构互相匹配；采用对应设备的结构，不混用不同系统特征。设备与内容保持等比，原素材的边框和键盘不被裁断。
- **素材**：具体操作教学使用真实界面与有依据的过程；概念和逻辑演示可精细重绘并标“界面示意／讲解重建”。缺少实操素材时先采集或说明缺口，不能用拟真重建充当证据；方块占位应用、泛化手机轮廓只用于内部布局，不作为高保真交付。
- **来源**：参考片提取素材属于素材复用，记录来源和区间；不能把裁出的原片画面称作独立重建或本次实际操作。视觉逼真也不等于功能已经验证。

## 丝滑的运动逻辑

同一个窗口、同一部手机和同一份内容贯穿相关镜头。先确定总览、操作点、结果这几种稳定构图，再连接位置、尺寸、遮罩和视角。

1. 对象先出现，随后有可见的点击、输入或其他触发。
2. 操作后更新对应状态，结果在完成后出现。设备两端使用同一任务和内容，不能各演各的。
3. 快速到位、柔和减速，稳定后留出阅读时间；轻微运动模糊只服务于快速位移，静止文字保持清晰。
4. 镜头从整体推近当前操作区，完成后拉回或自然移交给下一对象。窗口外壳、界面内部操作和镜头分层控制，避免同一内容重复缩放。
5. 窗口展开时保持文字比例；跨镜头保留设备位置线索和内容身份。弹簧回弹、景深、透视只按需要少量使用。

“丝滑”不要求整段匀速漂移，也不意味着每个对象都弹跳或逐字飞入。一个时刻保持一个主要阅读中心，短标题负责提示当前动作。

## 桌面与手机联动

典型状态链为：**桌面输入指令 → 执行反馈 → 手机打开应用／滚动／输入 → 结果确认**。F07 组织操作与反馈，F01 负责聚焦，F03 负责对象交接，F05 负责内容揭示。具体动作与时长根据内容安排，不固定套用原片或测试片的秒点。

手机 UI 承担可见结果与实际操作，桌面 UI 承担指令和过程；内容在两端对应。打开、输入、滚动等关键动作有前后状态，不能用几个无关手机截图轮播代替过程。真实操作视频保持 1×，等待可剪；若省略中间过程，要通过明确剪辑或说明交代，不假装完整实录。

产品演示可以无人物；已有口播或系列人物规则时按当前任务融合。只有桌面内容时，不为套风格强行添加手机。用户只要风格描述或更新技能时，不额外生成样片。

## 可直接采用的制作描述

> 制作一段高保真 UI 产品演示视频，按当前素材选择桌面与手机。采用连续镜头和对象保位转场，让窗口展开、设备移动、局部推近和视角拉回自然衔接。具体操作用真实界面，概念重绘标示意。呈现本期实际的输入、反馈和结果；阅读时保持轻推镜或局部高亮，文字清楚。外层包装按选定风格档案，真实产品素材保留自身颜色。

## 交付前的针对性检查

按任务范围检查稳定帧与主要过渡中间帧：对照适用风格的明暗层次和强调色用量；确认字体、控件、设备比例、手机边框与键盘完整；输入、执行与结果顺序一致。导出含视频界面的内容时，确认手机画面实际推进而非停在首帧，且源媒体时间不被运动模糊采样改变。确认推近后仍可读，阅读时没有残影或遮挡。

复用所选基础的生产与验收流程。技术检查、实际观看与用户审美认可分别报告；新规范本身不证明任何新成片已通过验收。
