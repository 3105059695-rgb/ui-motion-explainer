# 阿闰 AI 会员对比：动效拆解与迁移

用户本次原话：**“详细学一下这个特效来，我很喜欢这个的动效设计的，所以得，除了颜色，其他都很喜欢。”**

学习范围：整片的材料组织、空间层次、动作、转场和解释节奏。保留当前正式 Skill 的 Fred 黑紫 UI；不继承本片蓝色舞台、按品牌切换整片底色，也不固定套用排行榜。原片是 191.70 秒、1920×1080、30 fps 的纯画面讲解；本片没有提供真人避让方法，方木真人安全区仍遵守现有要求。

## 1. 这条的设计骨架

三个产品从开头到结尾有稳定身份：**会员卡 → 对应作品 → 品牌标识 → 榜单位置 → 单产品细节 → 更新榜单 → 按需求做选择**。主信息在中心展开，已解释的总览缩为右上导航；每个大章节都在同一个空间体系里继续。

因此，复用时先决定“这一段要让哪一个对象发生什么变化、变化后留下什么结果”。只拷贝卡片圆角、放大、弹跳，得不到这种连贯感。

## 2. 开头要学的具体动作

| 原片时段（近似） | 看得到的动作 | 讲清了什么 | 下次如何用 |
|---|---|---|---|
| 0–5.9s | 同尺寸会员卡横排，上方统一价格；高亮与光标在候选间转移，问号承接选择 | 同一预算下的三个候选 | 新内容先建立共同条件和对象身份，信息量随原稿决定 |
| 5.9–8.8s | 会员卡一起缩小下移；三份对应作品错峰向上展开；“亲测”印章落在证据旁 | 产品与作品一一对应 | 实际素材从所属对象附近出来，不能无来源地四处飞入 |
| 8.8–9.45s | 作品退走；会员卡收成品牌标识到右边；背景中的榜单接管主位 | 从介绍候选进入评价框架 | 当前对象保留身份，转场同时完成下一场布局 |
| 12.6–16.9s | 首尾档变问号和名次；虚线弧形箭头连接第一、最后 | 整体排名不代表每项都强 | 用状态/位置变化呈现矛盾，后文需要兑现 |
| 约17.9–18.3s | 大榜单缩入右上角；会员卡接入中间并落稳 | 进入分项讲解，同时保留总览 | 同一个总览缩成导航，不做一张无关联的新截图假接力 |

在 5.5–9.5s 的 8fps 补充序列中，可以确认三份作品先后进入，移动时出现方向性拖影，随后稳定可读。约 8.8–9.45s 和 17.9–18.3s 的主场切换短而明确。以上是近似观察窗口，不是原作者工程关键帧或精确曲线。

## 3. 正文动效为什么能帮助小白

**对象腾位，证据展开（19.5–26.3s、34.1–38.4s）。** 产品卡缩到边上，真实界面成为主位；用量、价格、积分等结论贴在对应证据旁。需要读字段时放大截图内部，而不是让整页小字一直挂着。

**一句转折变成一次动作（26.3–30.5s）。** “舍不得放弃”配合会员卡、取消订阅按钮、移近的光标和短促强调；接着收起会员卡，Google 标识接位并展开生态节点。按钮明确标了“示意”，不能将概念演示当真实产品操作。

**同一对象反复归拢（28.6–32.3s、49.7–52.7s）。** 产品节点从中心展开，随后回到会员卡，最后重新连接整套产品。观众能把零散功能理解成同一份权益，而不是记一串名称。

**抽象问题变成可见后果（约74–94s）。** 任务开始、时间变化、额度下降、工作半途卡住，再出现黑箱与等待。应借用“过程被阻断、结果不可见”的因果，而不是把黑箱作为每期常驻装饰。

**只改变被讨论的变量（约111–119s）。** 三根额度条保留位置，仅 Codex 那根耗尽，其他继续可用。“额度分开计算”通过差异直接成立。示意数值和来源真实数值应分开标记。

**结论推动状态更新（约62–69s、129–134s、156–168s）。** 同一榜单随比较口径或限制条件重新判断，不把每一段都清空重新搭图；结论是画面的最终状态。

**最后按需求交付答案（约168–186s）。** 三个产品归队，然后把“写代码”“日常综合任务”“AI视频/生态”等条件逐项连接到对应产品。对照结构复用，具体判断仅属于原片作者，本次不验证其产品结论。

## 4. 可执行的动作设计约束

1. **给对象固定身份和起终点。** 同一产品、文档、成果跨场保持同一个可追踪对象。变成缩略图、导航、标识时让观众看见交接。
2. **布局要对新材料作反应。** 新证据进场，旧对象先让位或同步让位；旁边一直多叠一张卡容易累积拥挤。
3. **动作有接力顺序。** 主对象启动，附属材料跟上，最后才落结论标签。错峰由口播逻辑决定，不把本片约三列结构和秒点固定成模板。
4. **快速阶段负责换位，稳定阶段负责阅读。** 起落有速度差；可有轻微转角、尺度回落和方向性运动模糊。落位后文字与边缘清楚。不能只把全片播放加速来追求丝滑。
5. **主位与背景分工。** 当前证据大而清楚，其余退小、降对比或退出；细小导航只负责定位，不承载本句要读的详细内容。
6. **材料随解释任务切换。** 真实界面证明、实际作品展示、图解解释机制、数字/进度表现变化。真实录屏不能被凭空重画的 UI 替代；示意图应表明性质。
7. **图章、光标、圈线有各自任务。** 圈线定位字段，光标表现动作，印章给短判断，箭头讲关系；不在同一时刻抢同一个焦点。
8. **动效换色时保留结构。** 大实体黑色窗口、白字与亮紫重点承接这些动作；原始产品截图、照片和官方标识保留本色，不把真实素材一并染紫。
9. **接回方木真人。** 只有需要作品/过程接管视线时才切全画面图解；人物、脸、手、字幕的空间由本期原素材决定，不因参考无真人而取消真人或开头提前缩角。

## 6. 证据与未确认项

- 整个原视频已送入 Higgsfield 视频分析，得到 20 段场景报告；完整原音轨本地转写 105 段并保留词时码。两者与本地视觉证据相互对照，工具报告中的数量/对象名/时段误差不直接继承。
- 本地核对覆盖 0–191.7s 的顺序视觉采样，并对关键动作增加密集序列。这些证据用于补查视频分析，不等同于人工逐帧、正常速度完整音画听审。
- 未单独核实音乐节拍、每个音效种类与落点；不声称听到了特定齿轮、点击或冲击音。今后实现时按具体动作选择声音，而不凭空复刻原音效表。
- 不知道原作者采用的 AE 插件、源码、生成模型、字体精确名称和贝塞尔参数。文中的实现建议是适配方案，不是反推出来的原作者工程。
- 价格、能力、额度、排名和产品版本均为原片内容，不属于本次实测或最新购买建议。

原片路径、SHA-256、完整工具报告、ASR、视觉证据、逐句对应和观看页都保存在同一研究目录。正式 Skill 只接入文字研究与索引，不复制原视频和环境。
