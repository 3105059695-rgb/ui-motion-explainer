# F01–F08：对象与状态的融合动作机制

第三层「可用效果库」的实现配方；在 [效果总目录](library.md) 选中 F01–F08 后按需读取。本文件把 `adu-motion-video` 中可复用的动作拆成对象、触发、状态变化和阅读停留。阶段、口播母带、实操证据与交付以 [制作流程](workflow.md) 为准；外观取 [账号风格](style-profiles.md)，技术接口取 [引擎合同](engine-routing.md)。`ui-motion-explainer` 是底座资源，不是另一个规则权威。

F01–F08 是八种融合示范机制，均可重排内容、镜头与时间，不替代 33 项观察动作与 23 项原创扩展。下文保留的白灰工作台、近黑结构、淡紫选区／紫色重点是早期黑白紫示范的配色例子，使用时映射到当前账号的角色色；不表示全库都已改版。原仓库的蓝色、黑色舞台、时间表、人物位置和营销数字也不成为新片默认值。

## 共用实现约束

- 一段只设一个主动作。对象先出现，鼠标/输入/口播给出触发，再改变状态，最后停稳给观众读结果。
- 用当前内容建立 `objectId`、字段、数值、单位与前后状态。同一文件、行、任务跨容器保持名称与身份；变成报告等新对象时说明转换关系。
- 配色和人物构图取当前账号档案，真实素材保留自身颜色。下文历史色彩例子说明状态层级，不写死新项目色值。
- 中文字体须实际加载当前工程选定的可交付字库，按正文/标题的真实显示尺寸排版。先完成稳定状态，再调运动，不依赖原库的 Mac 系统字体回退。
- 主过渡约 0.35–0.8 秒、错峰约 0.04–0.12 秒可作初始值；阅读停留由文案长度、画幅和口播决定，不能机械固定每段 6 秒或复用原库绝对时码。
- DOM／Fusion 实现使用可回拖的确定性 `render(t, mediaTime)`；其他后端遵循 [引擎合同](engine-routing.md) 的实际接口。每次写入完整的 transform、opacity、clipPath、颜色和文字状态，不在上一帧状态上累加，不以 `Date.now()`、随机数或定时器决定画面。
- 源媒体时钟与实操证据遵循 [制作流程](workflow.md)。运动模糊只采样动画时刻；各机制下的“时间与证据”补充本动作的具体陷阱。
- 音效在触发、交接、完成等有意义的落点使用，音量让位于口播。原始音频展示可作选型参考，当前任务决定使用哪些声音；没有实际试听就不报告全部听过。
- 人物位置、取景和大小按 [账号风格](style-profiles.md)；左下 174px 圆窗是历史 1080p 案例参数。真人交接不擅自替换成 Q 版；明确选用动漫／漫画表演时按对应模块制作。装饰性粒子、持续晃动、闪白和每字弹跳按语义选用，不作为默认填充。

## F01：从列表聚焦到同一对象的详情

**适合语义：** 找到目标文件、挑选方案、进入关键结果。可与主技能 O22–O24、O30、X22 联用。

**状态链：** 资料列表可读 → 鼠标定位目标行/缩略图 → 点击并选中 → 其他对象退后 → 同一目标变大 → 详情在其右侧或下方展开 → 阅读。

**源码出处：**

- anim4 S2 用 `exit` 保留中心项、其余退出：[scenes.js 216–217](../assets/adu-reference/source/packs/anim4/scenes.js#L216)。
- anim4 S3 建立 `hero`：[scenes.js 252](../assets/adu-reference/source/packs/anim4/scenes.js#L252)；`g` 从网格位置长大，`L` 让对象移到左侧，同时插值位置与缩放：[283–289](../assets/adu-reference/source/packs/anim4/scenes.js#L283)。原库是两个场景对象之间的视觉匹配，融合版应明确保持同一内容身份。

**实现要点：** 主对象从既有窗口中推近；详情是原对象的解释，不再弹出一个无来源的巨型数字卡。窗口顶栏和选中名称在交接期间保持可追踪。历史示范以白灰工作台、近黑侧栏、淡紫选区区分层级，实际色值取当前档案。

**参数起点：** `focusDuration=0.6s`，`detailDelay=0.1s`，镜头缩放约 `1.08–1.25`；目标最终宽度由当前文字与剩余详情区决定。背景可轻降对比，但保留足够总览信息。禁止直接把原库 372/1440 尺度、718/514 坐标或全屏 170px 标题硬编码为新布局。

**时间与证据：** 使用 `selectedId` 决定目标，依据当前点击时刻重设 `focusStart`。如果焦点内有真实视频，视频仍按自身固定媒体时间播放。示例文件和自动选择均是示意，不能声称已打开用户真实资料。

## F02：分组高亮与注意力转移

**适合语义：** 对比分类、检查某组、指出字段、解释当前选择。可与 O13–O14、O20–O21、X12 配合。

**状态链：** 总览 → 明确说明筛选条件/目标 → 目标集合高亮 → 其他集合降低视觉权重 → 更新说明 → 回到总览或进入 F01。

**源码出处：** anim4 S2 的 `litG`、`litC`、`modLit` 和 `dim`：[scenes.js 208–214](../assets/adu-reference/source/packs/anim4/scenes.js#L208)。分类标签每帧完整赋背景、文字、边框，避免回拖串状态：[224–229](../assets/adu-reference/source/packs/anim4/scenes.js#L224)。

**实现要点：** 选中行/单元格使用当前主题的选区和强调色，正文保持清楚；历史示范使用淡紫背景、深紫边缘或短强调线、近黑正文。其他信息降低权重但仍可读。高亮条件与界面筛选条件或口播名词一致。

**参数起点：** `focusFade=0.3–0.45s`；建议通过颜色、背景与轻微对比变化降低权重，若用整体透明度，普通文字区起点约 `0.7–0.85`，最终仍需看实际阅读效果。`selectedIds` 支持一项或一组；每次渲染同时复位上一组的颜色和边框。

**时间与证据：** 当前筛选/选中事件触发状态，自动讲解切组须交代选择条件。高亮不改原数据，不用换色暗示没有依据的性能排名。真实品牌的 logo、示例作品和录屏保持原色。

## F03：同一文件沿路径交接

**适合语义：** 资料迁移、任务流转、输入成为可编辑文件、CSV 数据进入报告。可与 O08、O11–O12、O26、X23 联用。

**状态链：** 起点容器内识别文件 → 提取同一文件 → 路径建立 → 文件沿路径移动 → 目标容器接住并停稳 → 展开正文/结果 → 阅读。

**源码出处：** anim3 S4 的轨道与账户对象：[scenes.js 152–154](../assets/adu-reference/source/packs/anim3/scenes.js#L152)；`L`、分段索引与正弦弧线 `ax/ay`：[166–171](../assets/adu-reference/source/packs/anim3/scenes.js#L166)。二次贝塞尔路径公式可参考 S6 `p0/c/p1` 与 `bx/by`：[270–272](../assets/adu-reference/source/packs/anim3/scenes.js#L270)。`template/lib.js` 没有名为 `curve` 的独立助手，不虚构其 API。

**实现要点：** 文件名称和类型从起点到终点保持一致，以结构色和当前路线强调色区分状态（历史示范为灰／紫）。使用一条有目的的低弧度路径，不照搬设备四连跳、鸟飞过、多个对象乱飞。若文件变成报告，文件先作为数据源进入报告头部，再展开报告内容，保持转换关系。

**参数起点：** `travelDuration=0.65–0.9s`，`arcHeight=12–40px`（1080p 初始值），`arrivalHold=0.15–0.3s`，`revealDuration=0.45–0.65s`。位置从当前布局读取。二次路径 `P(u)=(1-u)^2P0+2(1-u)uC+u^2P1`，`u` 由确定性缓动控制；交接完成后位置与终点容器锚点相同。

**时间与证据：** 若路径穿过多阶段，阶段完成和字段更新使用同一进度，不提前显示最终结果。资料迁移和报告生成是流程示意；没有真实输出文件时不能写“已完成迁移”或给出未经核验的摘要。

## F04：多任务交接、暂停与回收

**适合语义：** 多角色协作、任务并行、上下游依赖、等待与结果汇总。可与 O01、O04、O09–O11、X11 联用。

**状态链：** 工作台创建任务 → 角色节点依次接入 → 当前任务沿连线传递 → 节点进度变化 → 暂停时相关任务停止 → 恢复或结果返回 → 工作台展示完成项。

**源码出处：** anim3 S6 连接线、数据粒与节点：[scenes.js 243–248](../assets/adu-reference/source/packs/anim3/scenes.js#L243)；冻结时间 `tf=Math.min(t,FZ)`：[257](../assets/adu-reference/source/packs/anim3/scenes.js#L257)；连线与节点进度：[265–268](../assets/adu-reference/source/packs/anim3/scenes.js#L265)；粒子沿二次贝塞尔路径移动：[270–272](../assets/adu-reference/source/packs/anim3/scenes.js#L270)。

**实现要点：** 节点、连线和当前任务标识统一层级；历史示范为白灰工作区、近黑文字、灰线及局部紫色数据点。角色名称写当前具体职责，状态清楚写“待处理/处理中/等待/完成”。结果回到同一个任务入口，避免网络图演完又跳成无关标题页。

**参数起点：** `nodeStagger=0.08–0.12s`，`packetDiameter=6–10px`，同时显示约 3–6 个有解释作用的节点。减少原库多色发光、虚线持续流动和节点漂浮。暂停时保留稳定进度与对象，不靠全屏红字/强击打表现等待。

**时间与证据：** 建立共享 `effectiveTime`，扣除截至当前时刻的暂停时段；粒子位置、进度与节点状态全从它计算。等待提示可轻微呼吸，但任务进度不能继续增长。示意进度须标注，真实任务进度使用实际日志/状态，不能套用动画时钟伪造完成。

## F05：遮罩揭示内容与结论

**适合语义：** 展开详情、输入后出现回答、纠正一句话、从文档提取重点。可与 O17–O18、O21、X01、X09、X12、X20–X23 联用。

**状态链：** 原内容稳定 → 点击展开/完成输入/口播落点 → 容器保持 → 内容沿遮罩出现 → 关键词局部强调 → 完整结论停留。

**源码出处：** `template/lib.js` 的 `show()` 入出场：[42–59](../assets/adu-reference/source/template/lib.js#L42)，其中 `mask` 分支：[54](../assets/adu-reference/source/template/lib.js#L54)；`words()/wordsAt()` 的分段内容与时间：[63–78](../assets/adu-reference/source/template/lib.js#L63)。anim3 S4 标题横向 clipPath：[scenes.js 163](../assets/adu-reference/source/packs/anim3/scenes.js#L163)。

**实现要点：** 在同一文档或详情窗内揭示短句、整行或完整信息块。关键词交接用于讲解重音，长字幕稳定呈现。原句替换以整行遮罩避免半旧半新拼接；不默认逐字 slam、170px 巨字或高幅模糊。

**参数起点：** `maskDuration=0.35–0.6s`，内容位移约 `8–24px`，可选短时模糊约 `0–4px`；原库 `slam` 的大幅缩放、`blur` 18px 属于来源例子，非用户默认。中文短关键词可错峰 `0.05–0.1s`，长句按语义块分组。

**时间与证据：** 输入框逐字写入与点击发送具有因果关系，回答须在发送后出现。原始长文本没有内容依据时只能展示示意内容。清理上一状态的 clipPath、文字与模糊副本，回拖不得残留；字幕和人物不参与动画模糊采样。

## F06：数字、比例与时间线同步变化

**适合语义：** 前后用时、数据变化、任务完成进度、制作流程对比。可与 O13–O14、O25、X16–X17 联用。

**状态链：** 先显示数值含义和单位 → 旧状态建立 → 新状态增长/流程合并 → 数字与几何同步 → 停稳读差异 → 展示依据或结论。

**源码出处：** anim3 S8 读取两组值及共同最大值：[scenes.js 345–346](../assets/adu-reference/source/packs/anim3/scenes.js#L345)，文字与条长设置：[353–355](../assets/adu-reference/source/packs/anim3/scenes.js#L353)。anim4 S7 旧流程条增长后收缩：[scenes.js 583–587](../assets/adu-reference/source/packs/anim4/scenes.js#L583)。通用 `counter()` 插值：[template/lib.js 107](../assets/adu-reference/source/template/lib.js#L107)。

**实现要点：** 旧状态与新状态使用可分辨的层级，数据区保留标题、基准和来源。历史示范为旧灰／新紫、近黑正文与单位。流程压缩表示步骤或用时关系，不能仅用“更小更快”暗示没有证据的倍数。计数属于画面表达，最终展示当前真实数值或明确的示意值。

**参数起点：** `counterDuration=0.65–1.0s`，`barDuration=0.7–1.1s`，两者共享 `progress`；`valueMax=max(a,b,1)`，条长为 `value/valueMax`。当数值为负或类别不兼容时改用合适的图表，不能继续套正向条形比较。标签保留足够宽度防止位数改变时跳动。

**时间与证据：** 32GB/512GB、30 分钟、1 小时、粉丝、成本等原库默认值是示例，不能带入当前稿。数字依据使用当前资料；价格、产品指标、Star 等可能变化的事实在制作当期核验。真实录屏播放速度不随条形/计数动画改变；anim4 S7 的压缩视频时间表不作为操作教程默认值。

## F07：滑杆、开关与结果反馈

**适合语义：** 修改设置、开启能力、选择模式、输入参数后更新结果。可与 O30、X12–X13 及主技能设置类 UI 结构联用。

**状态链：** 先读控件名称和当前值 → 鼠标定位 → 按下/拖动/点击 → 手柄与数值同步 → 松开/确认 → 控件状态稳定 → 结果区域响应并停留。

**源码出处：** anim4 S2 推理滑杆 DOM 和 `rf/rk/rv`：[scenes.js 189–194](../assets/adu-reference/source/packs/anim4/scenes.js#L189)，填充、手柄、标签更新：[233–234](../assets/adu-reference/source/packs/anim4/scenes.js#L233)。anim4 S6 开关结构：[512](../assets/adu-reference/source/packs/anim4/scenes.js#L512)，控件引用：[516](../assets/adu-reference/source/packs/anim4/scenes.js#L516)，开关位置和底色：[535](../assets/adu-reference/source/packs/anim4/scenes.js#L535)。

**实现要点：** 控件位于可信设置窗内，以当前主题区分轨道、激活和关闭状态（历史示范为淡紫／紫／灰）。中文标签、当前数值、范围、单位清楚；官方软件确有名称时按真实名称。原库多数控件跟口播自动变化，融合版须补上鼠标触发与后续效果。

**参数起点：** `cursorTravel=0.25–0.4s`，`dragDuration=0.5–0.8s`，`toggleDuration=0.2–0.35s`，`feedbackDelay=0.1–0.2s`。滑杆 `fillWidth`、`thumbX` 与 `valueText` 共用规范化值；离散档位在同一阈值切换，回拖完整复位文字和颜色。

**时间与证据：** 先触发后反馈，不在鼠标点击前写“已开启”。真实软件操作以录屏为依据，重建控件保留“界面示意”。演示交互不实际调用费用、安全或账号设置服务；当任务要求真实操作时另外依照用户授权执行。

## F08：大人物交接为正文画中画

**适合语义：** 开头人物建立主题后，转入真实软件/成果讲解。可与 O05、O08、O19 及主技能开头/正文配方联用。

**状态链：** 开头原构图大人物 → 在安全区域建立软件/素材对象 → 人物向正文位置交接并变小 → 主界面接管阅读中心 → 当前账号约定的画中画继续同一句声音和人物时间 → 操作及结果。

**源码出处：** anim4 S5 `toSmall`、`hand`、大人物与小圆窗透明度交接：[scenes.js 445–449](../assets/adu-reference/source/packs/anim4/scenes.js#L445)；软件窗创建：[426](../assets/adu-reference/source/packs/anim4/scenes.js#L426)，窗口入场与录屏帧选择：[456–460](../assets/adu-reference/source/packs/anim4/scenes.js#L456)。人物取景 `camAt()`：[template/lib.js 153–167](../assets/adu-reference/source/template/lib.js#L153)。

**实现要点：** 大人物保留当前原片构图与脸/手安全区；终点形状、位置和取景读取账号档案，正文材料接管主要面积。早期阿刁示范采用左下头肩胸像圆窗、无桌子、淡边缘，其他账号不继承该布局。原库右下 1745/880 坐标、面部追踪比例与 Q 版替身均是来源例子；当前真人交接不自动换成替身，动漫任务另按其选型实现。

**参数起点：** `handoffDuration=0.55–0.8s`，`windowInDuration=0.5–0.75s`；大小与取景根据当前人物、画幅、字幕和界面确定，历史 1080p 圆径 174px 只供对应案例参考。优先一个人物节点持续运动并变化遮罩；确需两个容器时用互补透明度和相同 `mediaTime`，不得看到双脸。

**时间与证据：** 同一人物跨容器保持同一 `mediaTime`，运动模糊不能导致嘴型抽帧。原库 S5 [458–459](../assets/adu-reference/source/packs/anim4/scenes.js#L458) 含约 2.4× 录屏压缩，不可直接继承为教程播放速度；速度及省略标注按 [制作流程](workflow.md)。没有用户原片时展示明确的人物占位/示意，不伪造本人或克隆音色。

重点看同一对象的身份与路径、触发前后状态、回拖复位、错句、人物双影、遮罩截阴影和数值错位。通用导出、声音与验证记录统一执行 [制作流程](workflow.md)；本配方本身不证明新场景已通过检查。
