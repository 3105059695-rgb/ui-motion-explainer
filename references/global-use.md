# 统一调用与跨机器接续

唯一入口 `$ui-motion-fusion`，实际安装位置以安装结果为准，默认当前用户的 `~/.codex/skills/ui-motion-fusion`。不依赖作者盘符、用户名或旧对话。

```text
使用 $ui-motion-fusion，按这套已确认的风格剪辑这份口播和素材，交付完整成片及可编辑工程。
```

每次制作或续作，Agent 重读当前入口与档案。普通新稿不重复询问已确认风格。账号负责身份与习惯，`user-ui`、阿刁、方木的普通正文共用当前 Fred UI；明确工程例外须有用户原话或认可依据。目录名和旧 profile 字符串不让正文自动退回旧皮肤。未知账号保持未确定。

`direct prepare` 带独立的 UI、AIGC 依据及按稿 `selection` 候选。查看实际参考再决定采用、原创或保留人物，理由和实现留在同一计划中。正式预检用 `direct -- check --plan <计划> --production`，未生产就绪返回失败；普通 `check` 保留旧计划结构诊断。检查不评判美丑、不代替播放、不直接生成视频。

AIGC 人物图与场景图均默认仅为画风参考。每期按口播新设计人物、道具、场景与动作；已明确固定 IP 的工程保持身份。不得自动将例图用作成片或视频首帧。

包内引擎优先，旧兄弟 Skill 不自动覆盖当前风格。已配置的 `references/resources.local.json` 可自动接续本机历史参考源码和原片，公开安装不带作者路径；也可显式指定 `--module-root`。已有工程保留有效引擎，可选插件缺少时明确报告。

账号人物、声音和 IP 独立，通用女孩不覆盖它们。摄影写实等本期 AIGC 要求不修改 UI。公开包不包含作者的私人声音、数字人和账号影片；本人机器的原工程与索引继续保留。

更新磁盘不代表正在运行的旧对话已经刷新缓存。Agent 继续时重读当前入口，菜单缓存必要时由应用刷新。安装检查与桌面客户端测试的范围分别记录。

安装器只管理明确文件清单，不删除其他 Skill、用户工程或自加文件；不会在别人的电脑自动执行作者历史菜单归档。见[安装说明](../docs/install.md)。
