# 跨窗口使用

只调用 `$ui-motion-fusion`。每个新窗口先读实际安装的 [SKILL.md](../SKILL.md)，执行 `python -B -X utf8 scripts/ui.py requirements --part 1`，按页末命令依次读到最后一页。[全文清单](requirements.json)的全部正文都要读，不能以摘要、目录、关键词检索或旧窗口记忆代替；同一窗口要求未变时不重复加载。

读完后查看[当前认可 UI 的真实图像和连续动作](../index.html#current-ui)，再从整库选择本期设计与源码。参考、当前要求和实际实现的职责见[规则归属](module-map.md)，身份与历史范围见[参考使用](style-profiles.md)。

`direct prepare` 的 `requirements.documents` 带入完整现行正文与来源；新建工程记录当前版本内容及全页读取命令。内容可用不代表 Agent 已读懂或执行，准备工程不代表已生成视频。实际制作仍按主入口与[主流程](workflow.md)持续完成。

其他电脑要安装完整发布包和可用依赖；只转发 SKILL.md 不会带上源码。私人原片、音色及账号影片通过本机映射接续，不随公开包上传。旧工程不会因更新 Skill 自动换掉它的运行时；明确续作按工程范围接续。
