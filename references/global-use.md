# 统一调用与跨机器接续

唯一入口 `$ui-motion-fusion`，实际安装位置以安装结果为准，默认当前用户的 `~/.codex/skills/ui-motion-fusion`。不依赖作者盘符、用户名或旧对话。

```text
使用 $ui-motion-fusion，按这套已确认的风格剪辑这份口播和素材，交付完整成片及可编辑工程。
```

每次制作或续作，Agent 重读当前入口与档案。普通新稿不重复询问已确认风格。无账号覆盖时自动接续 `user-ui`；明确账号和项目设置优先，冲突或未知设置不由默认值掩盖。

`direct prepare` 带当前风格绑定、Fred校准图、女孩原图与8张场景。查看真实画面再设计，计划保留 `style.binding`。`direct check` 检查资源与绑定是否仍为当前版本；它不评判美丑、不代替播放、不直接生成视频。

包内引擎优先，旧兄弟 Skill 不自动覆盖。需要完整历史库时显式指定 `--module-root`；已有工程可以保留原引擎。可选插件按已安装位置发现，缺少时明确报告。

阿刁/方木独立，通用女孩不覆盖它们。公开包保留规则，不包含作者的私人声音、数字人和账号影片；本人机器的原工程与索引继续保留。

更新磁盘不代表正在运行的旧对话已经刷新缓存。Agent 继续时重读当前入口，菜单缓存必要时由应用刷新。安装检查与桌面客户端测试的范围分别记录。

安装器只管理明确文件清单，不删除其他 Skill、用户工程或自加文件；不会在别人的电脑自动执行作者历史菜单归档。见[安装说明](../docs/install.md)。
