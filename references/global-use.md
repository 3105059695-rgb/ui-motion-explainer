# 跨窗口使用

只调用 `$ui-motion-fusion`，先读实际安装的 [SKILL.md](../SKILL.md)，再按其读取顺序继续。Fred Talk 整体视觉与剪辑语言默认跨窗口保持，UI、AE 感、开头和禁忌一起从[审美偏好](aesthetic-preferences.md)继承，用户不用再次选择风格。

新工程使用自己的工程目录。旧账号文档、历史笔记、父目录的 `project.json` 和旧“Fred 仅中段”范围不自动决定本期风格。指定旧工程续作时从那个工程根目录进入；其中有来源的局部例外只作用于声明范围，正文例外不能抹掉开头与禁忌。

通常提供数字人口播视频和稿件；保留原声、原稿、字幕、本期人物及已有工程。私人声音、数字人和原片不随公开包复制。阶段、接口、检查均从主入口定位，本页不维护第二套制作流程。

新连续 UI 工程按主入口加载[实际制作模块](../assets/agent-editorial/README.md)，再从完整效果库选用能力；读取目录或运行 prepare 不等于已经使用源码。每期重新设计场景与事件，不默认套排行榜。其他电脑需要安装完整发布包及可用制作依赖，仅转发一个 SKILL.md 无法获得实现；私人原片通过本机映射接续，不属于公开载荷。
