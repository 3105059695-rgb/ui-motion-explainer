## 新参考也必须走这一条路

1. **完整识别来源。** 清点原视频/原稿，登记时长、原文件校验值和转写版本。按完整音轨识别口播，保留原始文本、词或句时码与不确定处；不要先选几个漂亮截图归纳整个作者。
2. **逐句和画面一一对应。** 从头到尾查看每句覆盖的画面，记录原句、素材类别、对象身份、可见动作和对应时段。跨镜的一句话记录多个区间；跨句的连续动作保留同一事件关系。没有 B-roll 就写人物或原操作，不漏掉过渡句、静默结果、片中对白与字幕纠错。
3. **补足决定性证据。** 对短蒙版、转场、遮挡、运镜和动作交接缩小查看间隔；要判断切点/节奏/音效则播放相应音画段。ASR 空洞和长句必须复查，不能拿转写行数代替完整覆盖。无法看清、无法听到的留待核查。
4. **区分观察与推论。** 先写原片确实发生了什么，再写这如何帮助理解。可见工具操作可以记录；没有证据不得填写作者使用的生成模型、提示词、种子、曲线或音乐节拍。负面示范显式标记。
5. **最后才提炼与接入。** 按观众理解缺口整理可迁移方法，附实际来源行、时段、动作链、使用条件和禁用条件。写清哪些可借现有组件、哪些需要定制或生成；保留原始对照，不能用摘要替换。将候选目录接入主流程，并实际验证一次普通调用能读到它。

这是学习完整性的要求，不强制每条新稿重新分析全部原片。新稿只阅读相关方法和来源段；当来源未被充分研究时才补研究。

## 怎样自动用于一份新口播

`direct prepare` 默认把 [来源方法目录](source-study-methods.json) 的精简条目、来源位置和本文件放入上下文。Agent 不调用 prepare 时，也按下面步骤读取同一目录。`study find` 只是文字检索辅助；没有文本匹配不等于没有适合的语义方法，更不能硬套第一条结果。

- 先通读本稿及上下文，写明“观众哪里不明白、需要看见什么变化”。再选人物、真实操作、图解、连续 AIGC 或混合载体。纯讲述已经足够的段落可不选参考方法。
- 比较候选的 `semantic_use / viewer_gap / state_chain / avoid`，读取对应来源行与镜头记录，理解其成立条件。来源里一段使用多个效果时，保留它们的因果次序，不截出一个孤立缩放套用。
- 改编为本稿的主角、物件、空间、触发、动作与后果；在 Fred Talk 默认内选择材料形态、构图和窗口组织。整体风格跨窗口保持，具体人物、对象与一部原片的镜头顺序不固定；原口播顺序仍按本期授权保留。
- 在本期分镜保留“本稿原句→为什么借这个方法→来源 ID/行→本期动作→实现入口与缺件”。已具备授权的制作继续落到画面。未实现的图形、未生成的 AIGC、未查过的素材如实保留状态，不能把目录读到当作完成制作。
- 检查本期观众是否看懂了原句，再看画面连续性、焦点、进入/退出和音画。结构检查不替代实际观看，用户审美认可仅绑定具体版本与范围。

### 五类学习怎样落地

| 任务 | 学到什么 | 对本期制作的要求 |
| --- | --- | --- |
| 口播到 B-roll | 理解关系、行动成本、障碍、后果与情绪，连续事件贯穿多句 | 人物/对象有初态、触发、行动、结果；不按单个名词贴图 |
| 蒙版、转场、运镜等剪辑 | 局部聚焦后归位、旧层标题留存、对象交接、翻页揭幕、讲述者回位 | 明确每一步让观众多懂什么；组件只提供原语，卷页等未实现细节需单独制作 |
| 素材展示 | 先定位，再按理解依赖逐层揭示；同条件比较；真实输入—操作—反馈—结果 | 保留足够阅读时间与真实证据，不用生成界面伪装操作 |
| AIGC 自然接入 | 同一角色连续行动；同物件、方向和空间连接前后场景；图形/实录接手精确信息 | 为本稿准备角色参考、动作拍点、首尾状态、失败检查与合成方案；生成出来后实际看 |
| 开头 | 结果、问题、反差、受众与承诺形成可验证入口 | 根据这篇原稿选择；后文必须兑现承诺，不固定每条同一时长或结构 |

### 来源方法不是作者的生成秘方

`production.known` 记画面可确认的事实，`unknown` 记无法反推的生产信息，`adaptation` 是我们为当前工程设计的实现方向。做 AIGC 时将动作链写成具体提示词，先决定哪些部分适合生成、哪些需代码或真实素材，再接 [既有生成通道](anime-video-generation.md)。没有生成/预算授权不自行计费；占位、静态推拉、请求文件和 MP4 扩展名都不能证明连续表演完成。

方法目录保留秋芝与 Fred 例证及明确反例，并与 S 配方及 O/X/F/R 相互引用；同类语义方法补实例而不按视频另起编号。当前总数以目录为准，尚无对应原语的操作明确留作宿主工程定制。`Q-*` / `F-M*` 用于追溯观察，`S*` 用于制作配方，都不是渲染器 `--scene` 参数。已选参考方向不等于来源方法已逐条重建或新样片已认可。
