# 由文案选择 UI 素材

**没有电脑录屏或截图，也可以直接制作。** 从当前文案提取对象、关系和变化，合成静态 UI 或模拟操作片段；无素材不是阻塞条件，不默认向用户索要录屏。界面可覆盖各类任务，不局限于资料工作台。

本页是**布局配方目录**，不是已经渲染了十二套新示范的交付清单。按语义选用，不凑数量；静态图只需呈现最有解释力的状态，动态片段再连接前后变化。

## 选择与搭建

1. 把一句话写成“谁 / 处理什么 / 怎么变 / 得到什么”。选一个能让这层关系看得见的布局。
2. 给主要对象安排可读内容和稳定 ID；缺少业务数据时使用明确的示例数据。先排好前后两个稳定状态，再连接动作。
3. 画面沿用黑白紫层级，只保留相关菜单和控件。每段选一个主动作，结果出现后留出阅读时间。

## 十二类候选布局

| 布局 | 适用语义 | 可见对象 | 前状态 → 动作 → 后状态 |
|---|---|---|---|
| 对话 | 提问、追问、反馈、生成一个产物 | 请求、回复、附件或结果对象、输入区 | 请求待处理 → 回复或结果逐段出现 → 可继续使用的产物保留 |
| 搜索 | 从很多内容中找一个答案或原文 | 固定搜索栏、查询词、结果列表、匹配字段 | 全部结果 → 输入与过滤 → 匹配项上移并展开原文 |
| 文档编辑 | 改写、提炼、补充约束、整理长文 | 章节、段落、光标或选区、修改结果 | 原段落 → 选中相关文字并修改 → 新段落在原位置完整停留 |
| 文件管理 | 归档、分类、交接材料、导出结果 | 文件夹树、文件名、类型、目标位置 | 文件散列 → 同一文件移动或分组 → 目标目录呈现清楚归属 |
| 表格 / 数据对比 | 比较方案、发现差异、筛选记录 | 表头、同口径数据、关键列、选中行 | 可比较的记录 → 高亮差异或重排行 → 当前结论及对应依据保留 |
| 看板 | 任务推进、状态更新、负责人接手 | 状态列、带 ID 的任务卡、负责人 | 卡片在原列 → 同一张卡移入下一列 → 状态与负责人同步更新 |
| 设置 | 启用能力、切换模式、调整规则 | 设置分组、开关或选项、相关说明 | 原选项 → 控件状态改变 → 标签与受影响的设置同步变化 |
| 日历 | 先后安排、改期、冲突、按需执行 | 日期轴、事件块、时间段、当前项 | 原安排 → 同一事件改期或展开 → 新时间位置与关联事项清楚可见 |
| 收件箱 / 协作 | 消息分流、评论处理、角色交接 | 列表、当前消息、评论、角色与处理状态 | 待处理消息 → 选中、分派或回复示意 → 对应条目的协作状态更新 |
| 代码 / 终端 | 解释一段逻辑、命令输入、错误与修正 | 文件名、少量可读代码、当前行、输入与输出区 | 原代码或输入 → 聚焦相关行并修改 → 对应结果或示例输出呈现 |
| 流程节点 | 因果、步骤、条件分支、一个概念的组成 | 主节点、连接线、子节点、当前状态 | 已知节点 → 连线带出下一节点或分支 → 路径与结果共同保留 |
| 多窗交接 | 从一个工作空间进入另一个、继承上下文 | 来源窗口、同一文档或任务、目标窗口 | 产物在来源中 → 容器让位、对象移出 → 目标空间接住同一对象 |

## 组合与边界

- 例如“查资料后写成文档”可用搜索 → 文档编辑；“审核后排进日程”可用表格 → 日历。只在文案确实包含这两个阶段时组合。
- 鼠标、输入光标、选区和状态反馈用于解释操作。表格行、文件、任务在前后画面中保持身份，不能只换标签伪装移动。
- 合成界面或模拟操作标为“界面示意 / 讲解重建”；动画中的运行、发送、保存、完成不等于真实操作已经执行。
- 需要证明真实产品功能、按钮路径或实际结果时，使用真实依据。依据不足时保留明确示意范围，不替产品编造功能；按 [UI 设计指南](ui-design.md) 区分复现、重建与原创示意。
- 交静态素材时导出 PNG 与可编辑源码；交动态素材时导出 MP4、源码及必要资产。GIF 是可选预览，不能替代要求的成片。
