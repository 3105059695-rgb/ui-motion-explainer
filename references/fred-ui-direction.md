## 先理解这一条完整链

原片约00:36–01:14：同题输入 → 多个模型结果 → 从选中位置放大一份网页 → 在窗内看局部 → 旧网页缩小让位给对照 → 对照接成主图 → 多例轮播 → 收成缩略图 → 保留旧结果输入修改意见 → 原结果换成修改后。

同一个材料在多句间保持身份，是本次最重要的接续依据。设计时先确定本稿的前态、触发、可见操作、后态和下一句如何接手，再选效果；不是按名词各找一张图。此链仅为学习例子，不要求新稿逐步照搬。
